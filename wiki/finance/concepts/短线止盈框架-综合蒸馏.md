## 一、利弗莫尔 — 关键点移动止损/翻越止盈

### 出场哲学

利弗莫尔的出场哲学建立在**顺势而为**与**危险信号识别**之上。他认为出场不仅是止损，更是对趋势是否持续的验证。核心信条：**"在获利的情况下，钱会越变越多；对待损失不能听之任之。"** 他的止盈本质上是"移动止损止盈一体化"——不设目标价，让趋势自行决定终点，但用危险信号作为离场触发器。

### 具体规则（可操作清单）

**止损规则：**

1. **第一笔损失是最便宜的损失** — 如果第一手试仓就赔钱，绝不执迷不悟地第二手
2. **不可摊平成本** — 价格下跌时追加仓位摊平是致命错误
3. **追加保证金是最危险信号** — 收到追加保证金通知时关闭账户，不要回应
4. **6点原则（30美元以上股票）** — 从极值点发生6点幅度的异常下挫，视为危险信号
5. **起步就亏钱的交易立即结束** — "能赚钱的交易往往是一起步就显示有利可图的买卖"

**止盈规则（关键点移动止损法）：**

1. **翻越止盈** — 价格突破关键轴心点后，将止损上移至该轴心点下方（做多）；价格继续新高，再上移止损
2. **危险信号离场** — 出现以下三种危险信号之一时无条件离场：
   - 异常价格行为：上涨途中突然出现从未有过的大幅下挫（从极值下跌6点以上）
   - 成交量背离：上涨过程中成交量大幅减少
   - 板块背离：龙头股不再引领涨势，或相关品种走势背离
3. **利润提现规则** — 每完成一笔成功交易，提取一半利润存入银行不再动用
4. **反常行为优先** — 股价突破关键点后若不能快速拉升，即视为危险信号

### 典型案例

**安那康达铜业**：股价突破100美元时买入，几分钟内飙升至105美元；突破200美元时重演；突破300美元时仅到302.75美元即止——反常行为构成危险信号，利弗莫尔迅速清仓，随后股价跌至225美元。此案例展示了"关键点翻越止盈+反常行为离场"的完整逻辑。

## 二、克罗 — 移动止损=止盈，留强汰弱

### 出场哲学

克罗将利弗莫尔的直觉系统化为可执行规则。他的出场哲学极简：**"不妨坐等市场自动把你带出场。"** 克罗不使用任何目标价，只用移动止损作为出场触发器。核心原则"留强汰弱"贯穿整个体系——**"凡是有损失的，都要卖掉；有利润的，都要留着。"**

### 具体规则（可操作清单）

**止损规则：**

1. **以交易所保证金一定比率设定止损**（50%-100%）— 远离大众止损位，避免被"猎杀"
2. **浮亏到影响睡眠就是"太过分"了** — 减仓到能安睡为止
3. **第一笔损失是最便宜的损失** — 立即认赔，不要"熬下去"
4. **成功者的亏损仅为失败者的1/8~1/13** — 控制亏损幅度是关键

**止盈规则（移动止损法）：**

1. **移动止损=止盈** — 不设目标价，随着市场有利不断前移止损点，直到被碰到出场
2. **留强汰弱** — 赚钱的仓位留着，亏钱的仓位砍掉（与大多数人做反）
3. **面对保证金催缴**：减仓，清掉亏损最大的仓位，保留赚钱的仓位
4. **仅趋势反转才离场** — 用客观分析确认趋势已反转，行动要快
5. **加仓部分同样使用移动止损** — 正金字塔加仓（量递减），每个加仓头寸独立设止损

### 典型案例

**小麦多头（1974年）**：在3.60建仓，3.85附近回调加码，4.40附近再次加码，最后在4.90反弹失败时全部出清（移动止损被触发）。全程没有预设目标价，纯粹由市场带出场。

**糖多头持仓5年+**：1967年在2.00买入，经历跌到1.33（浮亏1/3），最终涨到60.00。克罗没有在中间任何位置止盈，而是用移动止损一路保护到顶部。

## 三、威廉姆斯 — 分批止盈（1/3+1/3+1/3）

### 出场哲学

拉里·威廉姆斯将出场视为交易系统中**占比30%的关键环节**（仅次于资金管理的40%）。他的核心哲学是**概率思维**：没有人能预测顶部和底部，因此通过分批出场来平衡"让利润奔跑"和"锁定利润"的矛盾。他指出："真正的秘诀在于仓位管理和出场。"

### 具体规则（可操作清单）

**分步止盈规则（1/3+1/3+1/3体系）：**

1. **第一目标（1:1盈亏比时）** — 平仓1/3仓位，锁定初始利润
2. **第二目标（2:1盈亏比时）** — 平仓1/3仓位，锁定中期利润
3. **第三目标（3:1盈亏比时）** — 剩余1/3仓位用移动止损保护，让利润奔跑至趋势结束

**波动性止盈（基于ATR）：**
- 日线级别：目标 = 入场价 ± 2×ATR
- 小时级别：目标 = 入场价 ± 1.5×ATR

**移动止损（分形移动止损）：**
1. 初始止损设于入场价 ± 1~2个ATR
2. 价格每创新高/新低一个ATR幅度，移动止损一次
3. 止损只向利润方向移动，绝不后移
4. 当止损价跨过入场价后，该笔交易至少不亏

**时间止损（威廉姆斯独创）：**
- 日内交易：进场后2~3小时无利润 → 平仓
- 隔夜交易：持仓2~3天无利润 → 平仓
- 突破交易：突破后30分钟内未快速脱离成本区 → 信号可能失败

**硬止损：**
- 每笔交易最大亏损不超过账户总资金的1%~2%
- 日内止损：0.5%~1%的波动幅度
- 隔夜止损：1%~2%的波动幅度

**"反脆弱"出场原则：**
| 情况 | 行动 |
|------|------|
| 进场后快速盈利 | 保留仓位，移动止损 |
| 进场后窄幅震荡 | 时间止损退出 |
| 进场后快速亏损 | 立即止损 |
| 消息公布前后 | 减仓或平仓 |

### 典型案例

**1987年罗宾斯冠军交易**：胜率仅38%，但平均盈亏比8:1。威廉姆斯通过"1/3分批止盈+让剩余仓位奔跑"的策略，用低胜率实现了11,477%的年收益。最大连续亏损9笔，但单笔盈利远大于单笔亏损。

## 四、趋势交易法（鹿希武）— 浪5反转概率85%出场

### 出场哲学

趋势交易法建立在**概率论和数理统计**基础上。核心思想是**亏小赚大，追随趋势，用概率取胜**。出场逻辑系统化——不依赖主观判断，而是基于趋势线、拐点线、分界点A和波浪结构的客观信号。**"浪5后反转概率85%"** 是其最具特色的出场依据。

### 具体规则（可操作清单）

**趋势反转出场（主出场信号）：**
1. **价格突破趋势线** — 突破绘制的上升/下降趋势线
2. **价格突破拐点线** — 突破绘制的转向拐点线
3. **价格突破分界点A** — 突破设定的最低/最高点（转向准确率>80%）

**浪型结构出场：**
1. **出现5浪结构 → 启动转向操作**（反转概率85%）
2. **3浪结构 → 反转概率仅34%**，重心守住支撑/阻力，不做转向
3. **大5小5反转** — 大级别5浪+小级别5浪回调，在78.6%区域卖出

**加仓部分退出规则：**
1. **出现3根连续阴线**（做多时）
2. **价格突破5根临时拐点线**

**防御型退出：**
- 先行退出，待价格回升（如启明星出现）再补回
- 适用于趋势不明显但有潜在风险的场景

**K线反转形态确认出场：**
- 启明星/黄昏星（准确率80%）— 最重要、最可靠的出场信号
- 阴抱阳/阳抱阴（准确率53%）
- 十字星（准确率35%）

**关键数据：**
| 工具 | 转向准确率 |
|------|-----------|
| 趋势线 | >70% |
| 拐点线/分界点A | >80% |
| 启明星/黄昏星 | 80% |
| 浪5后反转 | 85% |
| 浪3后反转 | 34% |

### 典型案例

**箱型顶部反转**：价格经过5次以上震荡，第2或第4次破高后快速回箱体，反转概率>80%。此时结合浪5结束信号和黄昏星确认，执行转向出场。

**2007年上证预测**：鹿希武用趋势交易法预测上证将跌至1768点（实际1664.93点），展示了趋势线+分界点A系统在A股市场大趋势反转的验证能力。

## 五、专业投机原理（斯波朗迪）— 123/2B反转出场

### 出场哲学

维克多·斯波朗迪的出场哲学是**在胜算有利时下注，在胜算不利时收手**。他提出了两个经典的反转判定工具——123法则和2B法则，完全基于价格本身，不依赖任何技术指标。核心观点：**"你能控制的只有风险，利润是市场给的。"** 出场即是对"趋势是否还在"的回答。

### 具体规则（可操作清单）

**123法则（趋势反转判定）：**

趋势反转需要**三个条件全部满足**（不一定按顺序）：

1. **趋势线被突破** — 价格穿越绘制的趋势线，这是趋势变动的第一个征兆
2. **不再创新高/新低** — 上升趋势中价格回升未能突破前高；下降趋势中价格下探未能突破前低（试探高点/低点失败）
3. **价格穿越先前的短期反弹高点/回档低点** — 上升趋势中向下穿越先前的短期回档低点；下降趋势中向上穿越先前的短期反弹高点

**2B法则（假突破识别与提前出场）：**

- **多头市场中**：价格创新高后回落，再次尝试突破新高但失败，随后跌破前高 → 趋势可能反转，出场
- **空头市场中**：价格创新低反弹，再次下探新低但无法持续，随后突破前低 → 趋势可能反转，出场
- 2B法则比123法则**更早发出信号**，可提前建立出场头寸
- 止损设于假突破高点/低点附近，盈亏比理想

**资金管理出场：**
- 每笔交易风险不超过总资金的3%
- 一旦月度亏损达到特定比例，强制停止交易
- 严格执行鳄鱼原则：市场证明你错了就迅速认赔

**技术出场信号：**
- 200天移动平均线由上升转为平坦/下降，且价格由上往下穿越 → 主要卖出信号
- 10周均线下穿30周均线 → 卖出信号

### 典型案例

**1987年美股崩盘预测**：斯波朗迪成功预测1987年美股崩盘，使用的正是123法则识别趋势反转——道琼斯指数在突破长期上升趋势线后，未能创新高，随后跌破前低，三个条件触发全面出场。这一案例证明了纯价格行为出场规则在大级别趋势反转中的有效性。

## 六、亚当理论（威尔德）— 镜像对称目标位出场

### 出场哲学

亚当理论的出场哲学可以浓缩为一句话：**"让市场自己告诉你它要去哪里。"** 威尔德认为所有预测方法都是武断的，真正可靠的预测来自市场自身的对称性。出场目标不是由交易者设定的，而是通过**第二映像（透明胶片翻转法）** 让市场"画出"它最可能走到的位置。核心原则：**"认赔小钱，坐赚大钱。"**

### 具体规则（可操作清单）

**镜像对称目标位出场（第二映像法）：**

1. **透明胶片映射操作术**：
   - 取透明胶片盖在K线图上，描出最近一段价格走势
   - 将胶片左右翻转（关于时间轴的对称）
   - 再将胶片上下翻转（关于价格轴的对称）
   - 把胶片上的第一天与K线图的最后一天（"现在"时刻）重叠
   - 胶片上的线条即为市场对未来走势的预测目标位

2. **目标位的使用**：
   - 胶片预测线触及的价格区域即为**止盈目标区**
   - 预测线越接近"现在"时点越准确
   - 趋势越陡峭，对称性越强，目标越可靠

**止损规则：**

1. **进场前就必须设定止损** — 只在入场前才能做出客观决定
2. **止损只能朝操作方向移动，绝不后移或取消**
3. **单笔或单日亏损不超过操作资金的10%**
4. **绝不让小损失演变成大损失** — 情况不对立即退场
5. **绝不在亏损部位加码**（绝不摊平）

**其他出场规则：**
- 操作不顺时缩手休息 — 离开市场去度假
- 亏损部位绝不再加码
- 保持弹性 — 记住这只是概率，不是绝对

### 典型案例

**第二映像预测案例**：假设某股票从100元涨到120元，趋势陡峭上涨。用透明胶片描出最近10根K线走势，翻转后得到的预测线显示目标位约在135-140元区域。当价格运行至该区域时，即达到亚当理论定义的"目标位"，可在此区域分批出场。如果价格突破该目标继续上涨，则需要重新描绘新的映射。

## 七、高胜算操盘（林克）— 风险报酬比止盈

### 出场哲学

马塞尔·林克的出场哲学建立在**期望值**之上。他指出：**"出场的重要性往往胜过进场，因为出场才是决定输赢的关键。"** 林克认为高胜算交易不是高胜率，而是**风险/报酬比合理且期望值为正**的交易。他提出了"1/3+1/3+1/3分批出场+时间止损"的体系，并将出场与风险报酬比计算紧密结合。

### 具体规则（可操作清单）

**核心出场原则：**

1. **认赔要快** — 亏损部位的持有时间应明显短于获利部位
2. **获利要让其奔跑** — 不急着获利了结
3. **分批出场（1/3+1/3+1/3）**：
   - 1/3先获利了结（锁定初始利润）
   - 1/3正常出场（中期目标）
   - 1/3留做最后一击（用移动止损保护，让利润奔跑）
4. **时间止损** — 45分钟后部位仍然没有结束且亏损 → 强迫出场
5. **动机消失就出场** — "只要进场动机不复存在，就应该出场"

**风险报酬比止盈：**

1. 入场前即计算风险报酬比（R:R）
2. **最低要求**：R:R ≥ 1:3（即预期盈利至少是风险的3倍）
3. 第一出场目标 = R:R 1:1（锁定部分利润）
4. 第二出场目标 = R:R 2:1
5. 第三出场目标 = R:R 3:1 及以上（让利润奔跑）

**技术位出场：**
- 基于ATR设定出场位
- 多重时间框架确认出场信号
- 较高时间结构（日线/60分钟）提供前提信号
- 较低时间结构（1/5分钟）提供精确出场点

**资金管理相关的出场：**
- 每笔交易风险不超过账户净值2%~5%
- 总风险不超过风险资本的30%~50%
- 连续亏损3笔 → 仓位减半
- 连续亏损5笔 → 停止交易，休息1~3天

### 典型案例

**林克的45分钟时间止损**：在日内交易中，如果进场后45分钟内没有出现预期走势（即使没有触及止损），也要平仓出场。这是防止"磨死的交易"——价格不上不下但在消耗时间成本。

**分批出场示例**：账户100万，某笔交易预期盈利是风险的3倍。入场后：
1. 盈利达到止损距离的1倍时，平仓1/3
2. 盈利达到止损距离的2倍时，平仓1/3
3. 剩余1/3设移动止损，让利润奔跑
4. 如果45分钟没盈利，全部平仓

## 八、期货大作手风云录（肖遥/刘强）— 中国版出场规则

### 出场哲学

《期货大作手风云录》作为中国版的《股票大作手回忆录》，将利弗莫尔的出场哲学与中国期货市场的特殊环境相结合。核心哲学：**"会开仓的是徒弟，会平仓的是师父，会空仓的是大师。"** 出场不仅是技术问题，更是修行的体现。特别强调中国市场的特殊风险（三板强平、政策干预、坐庄文化）。

### 具体规则（可操作清单）

**止损规则（中国版）：**

1. **入场后三天之内不能盈利，毫不犹豫地平仓出来**
2. **永远不要给自己的账户补缴保证金** — 错就是错，绝不能错上加错
3. **"向前看"止损**：如果持仓方向和市场实际走势相反，不用问原因，砍仓出来是唯一明智的选择
4. **浮亏不是亏？— 典型的自欺欺人**（第三十五节）
5. **砍仓是一种说不出的痛，但不砍会更痛**
6. **仓位过重的判断标准**：如果睡不着觉，说明仓位过重了——减仓到能安然入睡为止

**止盈规则（中国版）：**

1. **绝不让自己盈利的单子变为亏损**：止盈点设在最近一次加仓点之上
2. **放鱼头、弃鱼尾、吃鱼肚**：
   - 鱼头行情（趋势初始）：不吃，难分反转还是反弹
   - 鱼肚行情（趋势已成）：重仓持有，大口吃肉
   - 鱼尾行情（末端逼空）：不吃，随时反转或巨幅震荡
3. **倒金字塔加仓+移动止盈**：试仓5%→盈利加仓10%→再盈利加仓20%...每个加仓层设独立止盈
4. **盈利是持仓勇气来源**：只有浮盈才能加仓，亏损时绝对不加仓

**特殊风险出场（针对中国市场）：**

1. **政策风险出场**：政府出台重大政策时，无论盈亏先减仓
2. **三板强平风险**：连续涨停/跌停时的强制平仓机制，在趋势末端必须提前出场
3. **内幕消息陷阱**：听到利好消息时反而要考虑是否该出场（消息可能是主力出货用的）
4. **坐庄识别出场**：价格涨势异常流畅但量能萎缩 → 可能是庄股，随时可能断崖式下跌

**资金管理出场：**
- 四分之一制度：本金分四份，一份投机、一份生活、两份稳定收益
- 投机部分亏损超30% → 暂停反思
- 盈利曲线越陡峭越应警惕（"快就是慢"）

### 典型案例

**大豆爆仓教训（第三十四至三十七节）**：肖遥重仓做空大豆（90%仓位），方向对但遭遇反弹，补缴保证金、死扛，最终爆仓亏损超过50%。教训：永远不要补缴保证金；一开始出现浮亏的持仓最终都很难赚钱。

**橡胶三板强平（第五十至五十一节）**：肖遥重仓做多橡胶，从盈利600万到三天后亏损580万，遭遇连续三个跌停板。教训：大资金管理最怕的是重仓单方向；任何内幕消息都不如仓位控制重要。

## 十、与鳄鱼派的衔接

### 10.1 鳄鱼派出场特征回顾

根据[[鳄鱼派-核心体系]]，鳄鱼派的出场特征为：

| 维度 | 鳄鱼派规则 |
|------|-----------|
| **止损** | 短线-5%、中线-8%、长线-12%（固定百分比） |
| **止盈** | 趋势终止信号出现时出场，不做预设目标价 |
| **出场频率** | 极低（每年几次） |
| **核心理念** | 等（潜伏）、准（确认）、狠（一击致命） |

### 10.2 八位大师对鳄鱼派的出场补充

鳄鱼派在出场维度存在几个薄弱环节，八位大师的规则可以为鳄鱼派补上：

**短板一：鳄鱼派只有固定百分比止损，缺乏丰富性**

| 鳄鱼派短板 | 可补充的规则 | 来源 |
|-----------|------------|------|
| 只有短线-5%止损 | 引入时间止损：3天不盈利出场 | 期货风云录 |
| 无分阶止损 | 引入保证金比率止损、技术位止损 | 克罗、威廉姆斯 |
| 无趋势确认止损 | 引入123法则/2B法则确认趋势反转 | 专业投机原理 |

**短板二：鳄鱼派止盈缺乏具体操作方法**

| 鳄鱼派短板 | 可补充的规则 | 来源 |
|-----------|------------|------|
| "趋势终止"太模糊 | 关键点翻越止盈：将止损上移至关键点 | 利弗莫尔 |
| 无分批出场 | 1/3+1/3+1/3分批止盈 | 威廉姆斯、高胜算操盘 |
| 无目标参考 | 镜像对称目标位辅助参考 | 亚当理论 |
| 无浪型参考 | 浪5结构判断趋势是否接近末端 | 趋势交易法 |

**短板三：鳄鱼派"放鱼头弃鱼尾"需要量化**

| 鳄鱼派短板 | 可补充的规则 | 来源 |
|-----------|------------|------|
| "鱼头鱼尾"主观判断 | 3浪(34%反转)vs5浪(85%反转)量化区分 | 趋势交易法 |
| 出场时机模糊 | 2B法则提早识别假突破反转 | 专业投机原理 |

### 10.3 鳄鱼派+八位大师的融合出场框架

将鳄鱼派的"等准狠"与八位大师的出场规则融合，形成以下分层出场体系：

```
鳄鱼派出场框架（融合版）

第一层：仓位判定（先判断是否该出场）
├── 1. 时间止损（期货风云录/威廉姆斯）
│   └── 入场后3天不盈利 → 出场

└── 3. 动机消失（高胜算操盘）

├── 5. 浪型判定（趋势交易法）
│   └── 5浪出现 → 准备出场（反转概率85%）

    └── 异常价格行为/量价背离/板块背离 → 出场

├── 7. 分批出场（威廉姆斯/高胜算操盘）

│   ├── 1/3在2:1盈亏比锁定
│   └── 1/3用移动止损保护
├── 8. 移动止损止盈（克罗/利弗莫尔）
│   └── 随趋势前移止损，直到被碰出场
└── 9. 镜像目标参考（亚当理论）
    └── 透明胶片法辅助判断目标区域
```
