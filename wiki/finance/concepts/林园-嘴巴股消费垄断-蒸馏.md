# 林园 — 嘴巴股+消费垄断

> **浓缩金句：** "只投和嘴巴相关的公司。人天天要吃饭、要吃药，这个需求永远不会消失。"

## 一、战绩概览

- 1989年8000元入市，到2007年据称资产超20亿
- 最著名的标签：茅台最早期投资者之一，从30元拿到2000元
- 片仔癀的长期持有者
- 风格极致：只投消费+医药，有时单票占50%+
- 中国A股最"野"也最真实的民间投资人

## 二、核心理念：嘴巴股

林园把A股5000只股票分成两类：嘴巴相关的、嘴巴不相关的。他只投前者。

```
嘴巴股（林园的核心池）：
  消费类：白酒、调味品、乳制品、肉制品
  医药类：中药、品牌药、糖尿病/高血压/心脏病（老年病三高）
  垄断类：片仔癀（国家绝密）、茅台（不可复制）

非嘴巴股（林园不碰）：
  科技、制造、金融、地产、周期性行业
```

**林园的逻辑：**
> "嘴巴股有定价权。茅台提价你喝不喝？还是要喝。片仔癀涨价你用不用？还是要用。科技公司涨价呢？客户马上找替代品。"

## 三、选股标准（极简但极苛刻）

```
1. 必须和嘴巴相关（消费或医药）
2. 必须是垄断或寡头（没有替代品）
3. 毛利率 > 50%（有暴利才有护城河）
4. ROE > 20%
5. 分红稳定
6. PE不重要（"怕高都是苦命人"）
```

## 四、仓位纪律

- 持股不超过 5 只（极度集中）
- 最看好的可以到 50%+
- 买入后至少持有 3 年以上
- "买了就不卖，除非公司基本面变了"
- 从不看大盘、不择时

## 五、与鳄鱼派融合

| 维度 | 林园 | 鳄鱼派 |
|------|------|--------|
| 选股范围 | 仅嘴巴股 | 不限 |
| 集中度 | 极度(3-5只) | 极度 |
| 持仓期 | 3年+ | 数月-数年 |
| 估值 | 不看PE | 看信号 |
| 矛盾点 | 永不择时 vs 等信号共振 |

**系统注入：** 林园的"嘴巴股垄断清单"可作为消费/医药赛道的专属筛选器——如果一只票同时通过林园筛选+鳄鱼派信号共振，那是最高确信度的机会。

## 六、可量化规则
```python
def linyuan_filter(symbol):
    """通过返回True"""
    sector = get_sector(symbol)
    if sector not in ["食品饮料", "医药生物", "中药", "白酒"]:
        return False  # 不是嘴巴股
    if gross_margin(symbol) < 0.50:
        return False  # 没暴利
    if roe(symbol) < 0.20:
        return False  # ROE不够
    if not has_monopoly(symbol):  # 无垄断特征
        return False
    return True
```
