# 张坤（易方达基金）— 蓝筹+港股消费

> **浓缩金句：** "选择商业模式出色、行业格局清晰、竞争力强的公司，长期持有。"

> ⚠️ **利益冲突声明：** 用户持有易方达蓝筹精选混合(005827)，当前浮亏-22.92%。以下分析基于公开资料，不构成对该基金的任何操作建议。

## 一、战绩概览

- 易方达中小盘/蓝筹精选基金经理，巅峰期管理规模超1300亿（公募之最）
- 2012-2020年，易方达中小盘年化约29%
- 代表作：茅台、腾讯、美团、五粮液、招商银行
- 2021年后因消费/互联网行业下行，业绩大幅回撤（部分基金回撤超50%）
- A股最有争议的"顶流"基金经理——神坛到争议，完整经历了一个周期

## 二、核心理念：买商业模式最好的公司

张坤是巴菲特在A股最忠实的践行者：

```
选股标准（极其严格）：
  1. 商业模式出色——赚钱不辛苦（高毛利、高ROE、轻资产）
  2. 行业格局清晰——不是红海厮杀
  3. 竞争力强——有护城河且护城河在加深
  4. 长期持有——至少看5年
```

**张坤的"三不碰"：**
- 不碰重资产（固定资产/总资产 > 40%）
- 不碰高杠杆（负债率 > 50%）
- 不碰无定价权（毛利率 < 30%）

## 四、张坤体系的风险（对用户最关键的教训）

张坤2021-2024的大回撤揭示了"长期持有"策略在A股的致命弱点：

```
张坤的认知 → "好公司不怕贵，时间会消化估值"
A股的现实 → 茅台从2600跌到1300(腰斩)，腾讯从750跌到180(跌76%)

教训：
  1. 好公司+好价格才是好投资，缺一不可
  2. A股的波动远超美股，"死扛"不是策略是赌博
  3. 行业出清期(如2021-2024互联网)即使最好的公司也会大跌
```

**这与鳄鱼派的"趋势破就走"形成鲜明的对照。**
