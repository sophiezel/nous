# 蒋锦志（景林资产）— 全球深度价值

> **浓缩金句：** "全球范围内寻找被低估的中国资产，买得便宜+拿得久=赚得稳。"

## 一、战绩概览

- 景林资产创始人，2004年成立，中国规模最大的私募之一（管理超千亿）
- 20年年化回报约25%
- 三位一体：港股（最大仓位）+ 美股中概 + A股
- 代表作：腾讯（2006年买入持有至今）、茅台、网易、拼多多、新东方
- 特点：极度重视估值、极度集中、极度长期

## 二、核心理念：全球视野+深度价值

蒋锦志和大多数A股基金经理最根本的区别：**他的比较基准是全球，不是沪深300。**

```
A股基金经理的思维 → 这个股票比A股同类便宜 → 买
蒋锦志的思维     → 这个股票在全球同类中最便宜 → 买
```

**这意味着：**
- 当A股整体偏贵时，他敢把仓位移到港股和美股中概
- 同一个公司（如中芯国际），他买港股不买A股（因为港股便宜40%+）
- 他不被A股的相对估值迷惑，只看绝对估值

> "我不在乎这个市场叫什么名字。我只在乎这个市场里有没有便宜的好公司。"

## 三、选股：三个必要条件

蒋锦志的选股标准比冯柳、邱国鹭更苛刻：

### 3.1 深度低估（必须满足）

```
PE(TTM) < 15（硬条件，消费股可放宽到20）
PB < 2（A股）/ < 1.5（港股）
PEG < 0.8（成长股）
股息率 > 3%（A股）/ > 4%（港股）
```

蒋锦志是真正的"低估值原教旨主义者"：
- 他买腾讯是在2006年PE 15倍时
- 他买茅台是在PE 10倍时
- 他在2015年A股PE>20时就大幅减仓A股换港股

### 3.2 优质公司（必须满足三条以上）

```
1. ROE > 20% 且连续5年 > 15%
2. 毛利率 > 30%
3. 经营现金流/净利润 > 1（利润有现金支撑）
4. 管理层持股 > 5%
5. 行业地位：前3且份额在扩大
6. 有国际化能力或潜力
```

### 3.3 长期逻辑（至少3年）

```
✓ 行业不会在3年内被颠覆
✓ 公司护城河在加深不是变浅
✓ 大股东和管理层利益一致
✓ 政策风险可控（不受打压）
```

## 四、三个市场的比较优势

这是蒋锦志体系对我们最有价值的部分——他天然是跨市场比较的：

### 4.1 市场优劣对比

| 维度 | A股 | 港股 | 美股中概 |
|------|-----|------|---------|
| 估值中枢 | 偏高（PE 18-25） | 偏低（PE 8-15） | 分化大 |
| 流动性 | 极好 | 中等（小票差） | 好 |
| 政策风险 | 中等 | 中等 | 高（中美关系） |
| 定价效率 | 低（散户多） | 中等 | 高 |
| 蒋锦志偏好 | 消费、制造 | **科技、金融、地产** | 互联网平台 |

### 4.2 用户持仓的蒋锦志式诊断

用户当前重仓港股+少量A股，这个结构蒋锦志会认可。但具体标的：

```
信义光能（港股）→ 光伏周期底部，PE已失真，看PB和行业拐点。蒋锦志可能在现在买入。
美团（港股）    → PE亏损/极高，不符合蒋锦志的"PE<15"硬条件。他不会买。
巨子生物（港股）→ PE约25-30，偏高。蒋锦志大概率不会碰。
理想汽车（港股）→ PE约25+，偏高但增速快(PEG可能<0.5)。蒋锦志有可能买。
比亚迪电子（港股）→ PE约15+，接近蒋锦志阈值。可能关注。
华润三九（A股）  → PE约20，防御属性。蒋锦志可能作为防御配置持有。
```

## 五、仓位与风控

### 5.1 极度集中

- 常态持仓 8-10 只（比高毅其他基金经理更集中）
- 前5大持仓占 70%+
- 单票上限 20%
- 最看好的票会买到上限

### 5.2 分批建仓，越跌越买

```
第一次建仓：50%目标仓位
跌10%：加25%
跌20%：加25%（满仓）
跌30%+：评估是否基本面出了问题
```

### 5.3 只减仓不清仓

- 蒋锦志极少完全清仓一只股票
- 贵了→减仓到5%以下但保留观察仓
- 持有周期：5-15年
- 年换手率：< 15%

### 5.4 港股流动性陷阱规避

港股投资的最重要风控——**不碰日均成交<1000万港币的票**：

```
港股小票风险 → 买得进出不来（流动性陷阱）
量化：日均成交额 > 5000万港币
港股通标的优先（有南下资金托底）
```

## 六、与鳄鱼派的契合/冲突点

| 维度 | 蒋锦志 | 鳄鱼派 | 契合/冲突 |
|------|--------|--------|----------|
| 估值要求 | 极度严格(PE<15) | 看信号不看估值 | 🔴 核心冲突 |
| 持仓周期 | 5-15年 | 数月-数年 | 🟢 契合 |
| 越跌越买 | 跌20%加满 | 趋势破就走 | 🔴 核心冲突 |
| 跨市场 | 全球比较 | 偏A+H | 🟢 契合 |
| 集中度 | 极度集中 | 极度集中 | 🟢 契合 |
| 港股侧重 | 主力仓位在港股 | 不限 | 🟢 用户持仓匹配 |

**融合方案：** 蒋锦志的跨市场比较框架（AH比价、全球估值对标）可以作为系统的"估值参考层"。但蒋锦志的"越跌越买"与鳄鱼派的"趋势破止损"是根本性冲突——用户必须自己选择站在哪一边。鳄鱼派的框架里，趋势破坏必须走，这是铁律。

## 七、可落地为系统规则的特征

### 规则1：蒋锦志式估值硬门槛
```python
def jiangjinzhi_valuation_gate(symbol, market):
    """通过返回True，不通过返回原因"""
    pe = pe_ttm(symbol)
    pb = pb(symbol)
    
    if market == "hk":
        if pe > 15 and pe > 0:
            return (False, f"港股PE={pe:.0f}>15，蒋锦志不碰")
        if pb > 1.5:
            return (False, f"港股PB={pb:.1f}>1.5，蒋锦志不碰")
    else:  # A股
        if pe > 20 and pe > 0:
            return (False, f"A股PE={pe:.0f}>20，蒋锦志减仓")
        if pb > 2.0:
            return (False, f"A股PB={pb:.1f}>2.0")
    
    # 港股流动性
    if market == "hk":
        avg_amount = daily_amount_20d(symbol)
        if avg_amount < 50_000_000:  # 5000万港币
            return (False, f"日均成交{avg_amount/1e8:.1f}亿<0.5亿，流动性陷阱")
    
    return (True, "")
```

### 规则2：全球估值对标
```python
def global_valuation_benchmark(symbol, sector):
    """判断当前估值在全球同类中的位置"""
    global_pe_median = get_global_sector_pe(sector)  # 全球同业PE中位数
    local_pe = pe_ttm(symbol)
    
    ratio = local_pe / global_pe_median
    if ratio < 0.7:
        return ("undervalued", f"比全球同业便宜{((1-ratio)*100):.0f}%")
    elif ratio < 1.0:
        return ("fair", "全球合理水平")
    else:
        return ("overvalued", f"比全球同业贵{((ratio-1)*100):.0f}%")
```

### 规则3：AH比价判断
```python
def ah_value_signal(a_symbol, h_symbol):
    """蒋锦志式AH比价"""
    a_pe = pe_ttm(a_symbol)
    h_pe = pe_ttm(h_symbol)
    
    discount = (1 - h_pe / a_pe) * 100  # H比A便宜多少
    
    if discount > 40:
        return ("buy_h_only", "H股便宜40%+，只买港股")
    elif discount > 20:
        return ("prefer_h", "H股便宜20%+，优先港股")
    else:
        return ("either", "AH差价合理")
```
