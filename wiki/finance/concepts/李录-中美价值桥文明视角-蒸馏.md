# 李录（喜马拉雅资本）— 中美价值桥

> **浓缩金句：** "做多中国不是赌政策，是赌14亿人追求更好生活的动力不会消失。"

## 一、补什么缺口

**补：文明级别的长期视角。** 所有操盘手都在说"长期"，但李录的"长期"是真·10-30年级别。他是芒格家族资产的中国管理人，唯一一个芒格把钱交给别人管的中国人。

## 二、核心理念：3.0文明的选择

李录的核心判断框架不是财务分析，是文明演进：

```
狩猎采集1.0 → 农业2.0 → 科技3.0

中国从2.0向3.0文明的转型 → 城市化+市场化+全球化+科技化
这是人类历史上最大规模的经济转型 → 持续50-100年
在这个过程中 → 最优秀的企业会创造巨大价值
```

**所以李录的选股简单到不可思议：**
> "找到在这个文明升级过程中不可或缺、且管理良好的公司，买了就不卖。"

## 三、可量化规则

### 李录式长期持有条件
```python
def lilu_check(symbol):
    """三项全过=可以买，缺一不可"""
    
    # 1. 不可或缺性
    essential = is_essential_to_economy(symbol)
    # 量化替代指标：市场份额>30%+客户粘性>80%
    
    # 2. 管理层质量
    mgmt_ok = (
        insider_ownership(symbol) > 0.15 and  # 管理层持股>15%
        capital_allocation_roic(symbol) > 0.12  # 资本配置能力
    )
    
    # 3. 估值合理（不是低估，是合理）
    pe = pe_ttm(symbol)
    pe_10y_median = pe_median_10y(symbol)
    valuation_ok = pe < pe_10y_median * 1.2  # PE不超过10年中位数×1.2
    
    return essential and mgmt_ok and valuation_ok
```

## 四、系统注入

李录不作为日常交易信号，作为**超长期配置参考**——当用户考虑"这个仓位要不要拿5年以上"时，用李录的三问来检验。

```
李录三问：
  1. 20年后这个公司还存在吗？
  2. 20年后它还会是行业领导者吗？
  3. 管理层值得托付20年吗？
→ 三个"是" → 可以长期持有
→ 任何一个"不确定" → 只做中短期
```
