# 王亚伟（前华夏大盘）— 重组股博弈

> **浓缩金句：** "在别人都不看好的地方，找到被错杀的重组预期。"

## 一、战绩概览

- 华夏大盘精选基金经理期间（2005-2012），6年12倍，年化49%
- 公募史上最传奇的业绩之一
- 核心策略：挖掘冷门重组股
- 2012年奔私后业绩下滑，离职后华夏大盘再无神话

## 二、核心理念：冷门重组股博弈

王亚伟的核心能力是**提前发现重组预期的公司**：

```
选股特征（当年的经典模式）：
  1. 小市值（< 30亿）
  2. 股权分散（大股东持股 < 25%）
  3. 主营业务疲软但壳干净
  4. 有资产注入/借壳预期
  5. 股价长期横盘（无人关注）
```

## 三、A股当前适用性

⚠️ **注册制改革后，壳价值大幅缩水，王亚伟模式的核心前提（壳资源稀缺）已不复存在。** 但他的冷门股挖掘方法论仍可参考：

```python
# 现代版"王亚伟式冷门股筛选"
def wangyawei_screen():
    return screen(
        market_cap < 50e8,        # 小市值
        pe < 20,                   # 不贵
        analyst_coverage < 3,      # 少人关注（冷门）
        revenue_growth > 0.05,     # 有业务（非纯壳）
        major_shareholder > 0.20,  # 有实控人
    )
```

## 四、与鳄鱼派融合

- 🟡 冷门股发现能力可作为补充
- 🔴 注册制下壳价值归零，不适用于当前A股环境
- 系统注入：仅作为"冷门成长股发现"的一个扫描维度
