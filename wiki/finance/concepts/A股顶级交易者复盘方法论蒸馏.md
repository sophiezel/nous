## 一、游资系（短线打板/情绪流）

### 1. 炒股养家（Asking）

**身份定位**：超短线情绪周期理论奠基人，从50万做到数亿。

**核心复盘步骤（每天必做4小时+）**：
| 步骤 | 内容 | 时间 |
|------|------|------|
| ① 涨幅榜扫描 | 所有涨停板逐个看（涨停原因/封板时间/封单量/开板次数） | 15:00-16:00 |
| ② 跌幅榜扫描 | 跌停板/大幅回撤个股，分析亏钱效应扩散情况 | 16:00-16:30 |
| ③ 成交额排名 | 两市成交额前100，感知主力资金主战场 | 16:30-17:00 |
| ④ 昨日涨停表现 | 昨日涨停的票今天怎么走的——连板率/溢价率/炸板率 | 17:00-17:30 |
| ⑤ 板块效应梳理 | 涨停股按板块归类，判断主线和支线，板块梯队 | 17:30-18:00 |
| ⑥ 消息面梳理 | 盘后公告/龙虎榜/政策新闻/行业动态 | 18:00-19:00 |
| ⑦ 写出交易计划 | 次日标的池、买入条件、止损位、仓位分配 | 19:00-20:00 |

**养家心法（最核心的独特方法论）**：
```
1. 情绪周期理论（养家首创A股短线情绪分析框架）：
   冰点→试错→发酵→高潮→分歧→退潮→冰点
   - 冰点期：空仓等待，管住手
   - 发酵期：重仓出击，敢于上仓位
   - 高潮期：持股不追，逐步减仓
   - 退潮期：防守为主，只卖不买

2. 三不原则：
   - 不做不符合模式的票
   - 不在退潮期开仓
   - 不逆势而为

3. 核心心法口诀：
   "别人恐惧我贪婪，别人贪婪我恐惧"
   "买入机会，卖出风险"
   "计划你的交易，交易你的计划"
```

**与A股T+1/涨跌停的适配**：
- 利用涨跌停制度判断情绪：涨停封单量=情绪温度计
- T+1下必须预判次日，打好"先手"
- 烂板出妖股——分歧转一致的典型买点

### 2. 赵老哥

**身份定位**：银河证券绍兴营业部，8年一万倍（10万到10亿）的传奇打板客。

**核心复盘步骤**：
| 步骤 | 赵老哥特色 |
|------|-----------|
| ① 抓龙头 | 每天只盯市场核心高标（最高连板/最强辨识度），不看杂毛 |
| ② 看联动 | 龙头与跟风的互动关系，板块梯队完整性 |
| ③ 判强弱 | 竞价阶段的封单变化、开盘后的承接力度 |
| ④ 龙虎榜 | 研究对手盘是谁，机构/游资/散户结构 |
| ⑤ 仓位纪律 | 根据市场情绪决定仓位：好行情满仓，差行情空仓 |

**赵老哥独特心法**：
```
1. "二板定龙头"：
   一板看不出什么，二板才能确认龙头地位
   打板只打二板以上确认的龙头

2. 新题材法则：
   "有新题材，坚决抛弃旧题材"
   市场永远喜新厌旧，死在旧题材上最冤

3. 市场退潮期的生存法则：
   - 管住手最重要
   - 只有一种情况可以操作：模式内的确定性格局
   - 退潮期空仓不丢人，亏钱才丢人

4. 止损铁律：
   短线-5%无条件止损，不心存侥幸
```

**T+1环境下的核心策略**：
- 打板博弈的是次日的溢价，不是当日的涨停
- 烂板回封=确定性买点（T+1锁定了当日筹码，烂板往往次日超预期）
- 锁仓拉升：强势龙头锁仓不动，利用T+1锁定流通筹码制造稀缺

### 3. 作手新一

**身份定位**：新生代游资代表，南京资金，以题材挖掘和逻辑驱动见长。

**核心复盘步骤**：
| 步骤 | 独特方法 |
|------|---------|
| ① 研报精读 | 每天精读10+份券商研报，建立基本面认知 |
| ② 题材评估 | 新题材空间测算（市场容量×政策力度×情绪热度） |
| ③ 逻辑推演 | 写出完整的投资逻辑链：因为...所以...预期... |
| ④ 竞价观察 | 9:15-9:25的竞价演变=全天情绪的预演 |
| ⑤ 龙虎榜复盘 | 重点看机构席位动向，跟机构票做波段 |

**作手新一独特方法论**：
```
1. "逻辑在前，走势在后"：
   选股不是看K线追涨，而是先有逻辑推演
   逻辑对了，买点自然会出现

2. 题材四维度评估：
   政策高度 × 市场空间 × 产业趋势 × 市场情绪

3. 大题材做法：
   - 大题材=大机会（政策驱动型、产业变革型）
   - 第一波：确认性行情，重仓参与
   - 第二波：逻辑深化，回调低吸
   - 第三波：鱼尾行情，轻仓或不参与

4. 与养家最大的区别：
   养家重情绪，新一重逻辑
   养家追逐市场情绪，新一追求逻辑自洽
```

### 4. 方新侠

**身份定位**：老牌游资，擅长高位接力与情绪拐点博弈。

**核心复盘步骤**：
| 步骤 | 特色 |
|------|------|
| ① 高度表 | 制作市场连板高度表（从首板到最高板的完整梯队） |
| ② 情绪指标 | 炸板率、昨日涨停溢价率、连板晋级率 |
| ③ 筹码结构 | 分析个股的筹码分布，套牢盘/获利盘比例 |
| ④ 拐点预判 | 寻找情绪拐点：极度冰点→拐点向上=最佳买点 |
| ⑤ 仓位递进 | 冰点轻仓试错→确认后加仓→高潮后减仓 |

**方新侠独特心法**：
```
1. "买在分歧，卖在一致"（与养家一脉相承）：
   分歧时买入（大家都不看好时）
   一致时卖出（所有人都看好时）

2. 高位接力纪律：
   - 只接市场总龙头
   - 必须有换手（一字板不接）
   - 必须判断情绪周期处于上升期

3. 政策市应对：
   "在中国做股票不看政策，等于瞎子摸象"
   重大政策出台后第一时间评估影响
   政策级别=行情级别
```

## 二、机构系（价值投资/逆向投资）

### 5. 邱国鹭（高毅资产董事长）

**身份定位**：前南方基金投资总监，价值投资中国化的代表人物。

**复盘框架（月度/季度为主）**：
| 维度 | 复盘内容 |
|------|---------|
| ① 行业比较 | 各行业ROE、估值分位数、景气度变化 |
| ② 持仓检视 | 每个持仓股：当初买入逻辑是否依然成立？ |
| ③ 卖出审查 | 三个卖出条件是否触发：逻辑破坏/估值过高/找到更好标的 |
| ④ 错误反思 | 投资笔记：亏钱的交易比赚钱的更值得复盘 |
| ⑤ 宏观定调 | 货币政策/信用周期/盈利周期所处位置 |

**邱国鹭核心方法论**：
```
1. "数月亮不数星星"：
   选行业龙头，不选小公司
   月亮（龙头）只有一个，星星无数
   行业竞争格局清晰后再投资

2. "胜而后求战"：
   等公司已经证明自己（建立了护城河）再买
   不赌"可能成为伟大公司"的小公司

3. 三问法（每个持仓必问）：
   一问：这公司的生意好不好？（商业模式）
   二问：这公司的护城河宽不宽？（竞争壁垒）
   三问：现在价格合不合适？（估值）

4. 逆向投资时机：
   - 行业遇冷、所有人都在卖出时
   - 关键是判断：是永久性恶化还是周期性低谷
   - 邱式金句："众人夺路而逃时，不挡路、不跟随"
```

**A股特有考量**：
- 政策风险是A股最大的尾部风险（教育双减、互联网反垄断）
- 国企vs民企：治理结构是A股估值折溢价的核心因素
- 散户主导的市场=情绪波动更大=给价值投资者更多机会

### 6. 冯柳（高毅资产，弱者体系）

**身份定位**：从散户做到百亿基金经理，独创"弱者体系"。

**弱者体系复盘框架**：
| 步骤 | 内容 |
|------|------|
| ① 不预测 | 承认自己是弱者，不预测股价方向 |
| ② 风险收益比 | 算赔率：最坏情况跌多少？最好情况涨多少？ |
| ③ 被动择时 | 不是主动判断顶底，而是持仓涨跌自然触发买卖 |
| ④ 组合管理 | 分散+轮动，个股≤10%，以赔率驱动调仓 |
| ⑤ 反思日志 | 每次买卖写清楚逻辑，定期回看逻辑是否被市场验证 |

**冯柳独特方法论——弱者体系精要**：
```
1. 弱者体系的核心假设：
   "我在信息、研究、资源上永远是弱者"
   因此不靠预测赚钱，靠体系和赔率赚钱

2. 冯式选股三标准：
   ① 可理解：商业模式能看懂，在自己能力圈内
   ② 可预期：未来1-3年经营趋势可判断
   ③ 可估值：能大概算出合理价值区间

3. 赔率驱动交易：
   - 上涨空间≥50%，下跌空间≤20% = 值得参与
   - 上涨空间≥100%，下跌空间≤30% = 重仓
   - 不看"会不会涨"，只看"值不值得赌"

4. 卖出的唯一理由：
   赔率不再划算（涨多了赔率变差 / 基本面变了）
   不因为"涨多了"而卖出，也不因为"跌多了"而买入

5. 与邱国鹭的区别：
   邱国鹭：买好公司，等好价格
   冯柳：  买好赔率，赌大概率
```

**弱者体系的复盘哲学**：
- "你不需要比别人聪明，你只需要比别人少犯错"
- 复盘不是证明自己对了，而是找自己错在哪里
- 承认无知的交易员活得最久

### 7. 赵军（淡水泉投资）

**身份定位**：淡水泉创始人，逆向投资中国旗手。

**淡水泉复盘体系**：
| 步骤 | 核心内容 |
|------|---------|
| ① 市场情绪监测 | 自建情绪指标：新开户数/融资余额/成交量/换手率 |
| ② 行业景气跟踪 | 草根调研+行业数据，提前感知景气拐点 |
| ③ 被错杀标的筛选 | 好公司因市场情绪被杀估值=最佳买点 |
| ④ 组合压力测试 | 极端情况下组合最大回撤估算 |
| ⑤ 季度策略会 | 全体投研深度复盘，辩论式讨论 |

**淡水泉核心方法论**：
```
1. "逆向投资不是逆势投资"：
   在市场恐慌时买入优质资产 ≠ 在下跌趋势中接飞刀
   关键是判断恐慌是否过度

2. 能力圈原则：
   - 只做自己研究透的行业和公司
   - 深耕不等于持股不动，而是持续跟踪

3. 淡水泉时钟（自研）：
   经济周期 × 政策周期 × 市场情绪周期
   三者叠加判断市场处于什么阶段

4. A股特色：政策拐点=最大超额收益来源
   政策从收紧到放松的拐点=市场底的前兆
```

## 三、大拿系（传奇交易者）

### 8. 徐翔（泽熙投资/涨停板敢死队总舵主）

**身份定位**：A股史上最具传奇色彩的交易者，3万到200亿。

**徐翔复盘体系（据公开资料还原）**：
| 步骤 | 内容 |
|------|------|
| ① 全市场复盘 | 每天4小时+，所有3000+股票过一遍 |
| ② K线记忆 | 惊人的图形记忆力，能记住关键K线形态 |
| ③ 成交量分析 | 量价关系是核心，不放量的突破不参与 |
| ④ 消息面精细解读 | 同一消息对不同股票的影响权重不同 |
| ⑤ 盘口语言 | 委买委卖、大单流向、撤单速度 |
| ⑥ 心理博弈 | 预判对手的预判：散户会怎么想？游资会怎么做？ |

**徐翔核心方法论**：
```
1. 涨停板战法（徐翔开创）：
   - 追涨停不是目的，判断次日能否继续涨停才是核心
   - 关键看：封板时间（越早越好）、封单量、位置（低位首板>高位连板接力）
   - 不排一字板（买不到=白排，买到了=坑）

2. 止损的残酷纪律：
   "亏3%直接砍，绝不犹豫"
   徐翔的止损速度在圈内是传说级的
   正是因为止损快，所以敢大胆试错

3. 政策敏感度：
   "就是赌政策，赌国家的决心"
   重大政策出台前后是最大的博弈窗口
   提前埋伏+发布后获利了结

4. 仓位管理：
   - 单票不超过20%，但核心标的重仓出击
   - 行情好时满仓滚动，行情差时空仓等待
   - 永不补仓（补仓=承认错误但不愿止损）

5. 信息优势的构建（合法范围内）：
   - 深耕上市公司调研，比研报更早发现变化
   - 重视产业链上下游交叉验证
```

**徐翔的复盘名言**：
- "投资不需要高学历，但需要高悟性"
- "这个市场专治各种不服"
- "每天复盘4小时，坚持10年=与不复习的人差距就是天壤之别"

### 9. 林园

**身份定位**：民间股神，8000元到百亿，专注消费/医药赛道。

**林园复盘方法**：
| 步骤 | 特色 |
|------|------|
| ① 行业垄断性评估 | 只投"垄断+成瘾"型企业 |
| ② 财务指标扫描 | ROE>20%、毛利率稳定、现金流好 |
| ③ 调研实地走访 | 亲自去公司/门店/工厂看 |
| ④ 组合集中 | 极度集中投资（3-5只股票） |
| ⑤ 长期持有 | 以年为周期评估，不做短期择时 |

**林园核心方法论**：
```
1. "买入=持有=买入更多"：
   好公司不卖，跌了继续买
   "怕高都是苦命人"

2. 选股标准（林园三把尺）：
   ① 垄断（独家生意/品牌壁垒/牌照壁垒）
   ② 成瘾（重复消费/离不开/上瘾）
   ③ 嘴巴相关（吃喝+医药=永恒的刚需）

3. 对A股的独特理解：
   - A股熊长牛短，但牛市涨幅巨大
   - 在熊市布局，在牛市兑现
   - 不预测顶底，只判断贵不贵

4. 复盘的重点：
   不是每天复盘，而是每季度/每年做体检式复盘
   关注公司经营是否如预期，而不是股价涨跌
```

### 10. 但斌（东方港湾）

**身份定位**：价值投资传道者，茅台最著名多头。

**但斌复盘框架**：
| 步骤 | 内容 |
|------|------|
| ① 时代主题判断 | 每个时代都有属于那个时代的伟大公司 |
| ② 长坡厚雪筛选 | 好的赛道+好的公司=长期复利 |
| ③ 穿越周期 | 用5-10年的眼光看公司 |
| ④ 历史复盘 | 研究美股百年历史，对标A股发展阶段 |
| ⑤ 组合再平衡 | 伟大的公司跌多了就加仓 |

**但斌核心方法论**：
```
1. "时间的玫瑰"：
   价值投资=买入伟大企业，与时间为友

2. 选股哲学：
   最好的投资是投资一个时代
   找到"皇冠上的明珠"（各行业最优秀的一两家）

3. 对A股的看法：
   A股短期是投票机，长期是称重机
   政策冲击往往是买入良机（如白酒塑化剂/反腐）

4. 复盘的核心：
   检验持仓是否依然是"时代的企业"
   不是复盘股价，而是复盘企业在这个时代的位置
```

## 四、顶级交易者复盘的10条共性铁律

经过对以上10位顶级交易者的方法论交叉分析，提炼出**10条共性铁律**：

| # | 铁律 | 代表人物 |
|---|------|---------|
| 1 | **每日必复盘** | 全部——徐翔4小时/天，养家4小时/天 |
| 2 | **写交易日志** | 养家、冯柳、邱国鹭——把逻辑写下来 |
| 3 | **无情止损** | 徐翔-3%、赵老哥-5%、养家：买入机会卖出风险 |
| 4 | **情绪周期感知** | 养家首创，赵老哥/方新侠/徐翔均深谙此道 |
| 5 | **龙虎榜必看** | 游资系全部——了解对手盘是必修课 |
| 6 | **管住手（空仓能力）** | 全部——不做能力圈外的交易 |
| 7 | **政策敏感度** | 全部——A股本质是政策市 |
