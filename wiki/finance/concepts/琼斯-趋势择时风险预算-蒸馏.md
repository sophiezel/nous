# 保罗·都铎·琼斯 — 趋势择时+风险预算

> **浓缩金句：** "200日均线之上只做多，之下只做空。每一笔交易的风险不能超过总资产的2%。"

## 一、补什么缺口

**补：短线/中线择时+风险预算缺口。** 已有体系里有长线持有（张磊/蒋锦志）和中线趋势（邓晓峰/鳄鱼派），但缺少琼斯这样系统化、纪律化的趋势择时框架。他的200日均线是全世界最简洁有效的趋势过滤器。

## 二、核心理念：趋势为王+风险第一

琼斯连续28年盈利的核心不是选股，是**纪律**：

### 2.1 200日均线铁律

```
价格 > MA200 → 只做多，不做空
价格 < MA200 → 只做空，不做多
价格在MA200附近纠缠 → 不做
```

这是最简单的规则，也是最难执行的规则——因为人性总想在跌的时候抄底。

### 2.2 5:1 赔率门槛

```
每笔交易的预期盈亏比必须 > 5:1
预期盈利 = 目标价 - 入场价
预期亏损 = 入场价 - 止损价
赔率 = 预期盈利 / 预期亏损

赔率 < 5:1 → 不值得做，放弃
```

### 2.3 2% 风险预算

```python
def jones_risk_budget(portfolio_value, entry_price, stop_price, shares):
    """单笔交易最大亏损不超过总资产2%"""
    risk_per_share = entry_price - stop_price
    total_risk = risk_per_share * shares
    max_risk = portfolio_value * 0.02
    if total_risk > max_risk:
        # 缩减股数
        adjusted_shares = int(max_risk / risk_per_share)
        return (adjusted_shares, f"仓位从{shares}降至{adjusted_shares}，2%风控")
    return (shares, "通过")
```

## 三、可量化规则

### 200日均线状态判定
```python
def jones_trend_filter(symbol):
    price = close(symbol)
    ma200 = sma(symbol, 200)
    ma50 = sma(symbol, 50)
    
    if price > ma200 and ma50 > ma200:
        return ("🟢 强多头", 1.0)  # 满仓做多
    elif price > ma200:
        return ("🟡 弱多头", 0.7)
    elif price < ma200 and ma50 < ma200:
        return ("🔴 强空头", 0.0)  # 空仓
    else:
        return ("⚪ 纠缠", 0.3)    # 轻仓试探
```

### 趋势强度评分
```python
def jones_trend_strength(symbol):
    """0-100，琼斯式趋势强度"""
    score = 0
    days_above_200 = count_days_above_ma(symbol, 200, lookback=60)
    score += min(days_above_200, 40)  # 40分：在MA200上方天数
    if ma50(symbol) > ma200(symbol): score += 20  # 金叉
    if adx(symbol, 14) > 25: score += 20  # 趋势明确
    if volume_ratio(symbol) > 1.2: score += 10  # 放量
    if price > ma20(symbol): score += 10  # 短期强势
    return score  # >70做多，<30回避
```

## 四、系统注入

琼斯作为鳄鱼派的**趋势过滤器+仓位计算器**：

```
鳄鱼派选股 → 琼斯200日均线过滤（之下直接pass）
         → 琼斯5:1赔率检查（不够直接pass）

```
