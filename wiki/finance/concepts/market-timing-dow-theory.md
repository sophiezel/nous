# 道氏理论市场择时

## 定义

道氏理论由 Charles H. Dow（道琼斯指数创始人）于 19 世纪末提出，是技术分析的鼻祖。Victor Sperandeo 在《专业投机原理》中将道氏理论进行了**实战化改造**，使之从描述性理论变为具操作性的择时系统。Sperandeo 的核心贡献是将道氏理论与 1-2-3 准则、2B 法则结合，形成了趋势确认→入场时机→风险管理的完整链条。

## 道氏理论的六大假设

### 1. 市场行为反映一切（The Market Discounts Everything）
市场价格已包含所有可知信息——基本面、政治、心理、自然灾害等。交易者不必试图"比市场知道更多"，而应解读价格本身发出的信号。

### 2. 三种趋势（Three Trends）
| 趋势类型 | 持续时间 | Sperandeo 实战对应 |
|---------|---------|-------------------|
| 主要趋势 | 1 年~数年 | 交易方向的最上级约束 |
| 次级折返 | 3 周~3 个月 | 回调幅度 1/3~2/3 原则验证 |
| 日常波动 | 数天~数周 | 仅用于择时入场，不改变方向判断 |

Sperandeo 强调：**永远顺着主要趋势的方向交易**。次级折返是入场机会而非逆势交易的理由。

### 3. 主要趋势的三个阶段
#### 上升趋势（牛市）
- **第一阶段**（累积期）：少数远见者在悲观中开始买入，价格缓慢回升
- **第二阶段**（趋势确认期）：基本面改善被广泛认可，成交量放大，价格稳定上涨
- **第三阶段**（狂热期）：大众涌入，价格加速上涨，但内在价值已被透支

#### 下降趋势（熊市）
- **第一阶段**（派发期）：远见者开始卖出，价格从高位回落
- **第二阶段**（恐慌期）：下跌加速，成交量放大
- **第三阶段**（绝望期）：优质资产被恐慌性抛售，成交量萎缩，筑底开始

### 4. 指数间必须相互确认（Averages Must Confirm）
Industrial Average 和 Transportation Average 必须朝同一方向运动才能确认趋势。Sperandeo 将此原则推广：多个市场/品种的同步确认比单一信号更可靠。

### 5. 成交量确认趋势（Volume Confirms the Trend）
- 上升趋势中：上涨放量、回调缩量 = 健康
- 下降趋势中：下跌放量、反弹缩量 = 健康
- 背离信号（上涨缩量/下跌缩量）是趋势动能衰竭的警告

Sperandeo 实战注记：不要过度依赖成交量绝对值，关注的是**成交量方向与价格方向的一致性**。

### 6. 趋势持续直到明确反转信号（Trend Persists Until Reversal）
一个趋势在给出明确的逆转信号之前，应假定其继续有效。Sperandeo 用此原则反驳"抄底摸顶"——等待反转确认而非预测反转。

## Sperandeo 的市场择时方法

### 步骤一：判定主要趋势（What）

通过道氏"更高高点 HH / 更高低点 HL"或"更低低点 LL / 更低高点 LH"结构判定：

```
上升趋势：HH↓ + HL↓ 序列
          HH
         /\
        /  \  HL
       /    \/\
      /        HL
     /
    HL

下降趋势：LL↓ + LH↓ 序列
    LH
    /\ LH
   /  \/
  /    LL
 /      \  LL
/        \/
         LL
```

**Sperandeo 规则**：当前主要趋势的方向就是唯一允许下单的方向。严禁在主要上升趋势中做空，严禁在主要下降趋势中做多。

### 步骤二：趋势线绘制规则（How）

不同于一般技术分析的自由绘制，Sperandeo 对趋势线有严格要求：

- **上升趋势线**：连接至少两个依次抬高的回调低点
- **下降趋势线**：连接至少两个依次降低的反弹高点
- **有效突破标准**：价格收盘跌破/升破趋势线，且突破幅度达到价格区间的 3% 以上（或持续高于/低于趋势线 2 天以上）
- 被触及次数越多的趋势线，突破信号越重要

### 步骤三：1-2-3 反转确认（When to Enter）

当趋势线被突破后，使用 1-2-3 准则确认反转（详见 [[sperandeo-trading-system]]）：

```
上升→下降反转的 1-2-3：
     high ← 原上升趋势的顶点
     /\
 1  /  \     ← 趋势线突破
   /    \
  / 2    \   ← 反弹失败（无法创新高）
 /        \
/          3 ← 跌破前回调低点 = 确认反转
           ↓
```

### 步骤四：2B 法则抓取最优入场（When to Enter Best）

在 1-2-3 准则的第 2 步（极点测试失败）阶段，**若同时存在 2B 信号**（假突破后立即折返），则这是一个极高概率的反转入场点：

```
上升趋势末端的 2B：
     B ← 前高
    /|  ← 短暂突破后立即回落（2B触发）
   / |
  A  |  ← 收盘跌回前高之下
 /
/
```

此时入场风险最低（止损紧贴）且潜在回报最大。Sperandeo 称这是"最低风险的反转入场方式"。

### 步骤五：成交量过滤

真正的趋势反转通常伴随以下成交量特征：

| 阶段 | 成交量特征 |
|------|-----------|
| 趋势线突破 | 放量突破有效 |
| 极点测试失败 | 测试方向缩量 → 动力衰竭 |
| 中继点突破 | 放量确认 |

## 实战示例：道氏+1-2-3 完整择时流程

```
1. 判定主要趋势：HH+HL 结构 = 上升趋势 → 只做多
2. 等待次级折返：价格回调，绘制上升趋势线
3. 若趋势线被跌破（放量）→ 预警
4. 等待反弹测试前高：
   a. 若创出新高 → 趋势延续，重新绘制趋势线
   b. 若反弹无力（缩量）且形成 2B → 高概率反转
5. 若随后跌破回调低点（放量）→ 1-2-3 确认反转
6. 趋势方向变更 → 转为空头策略
```

## 道氏理论的局限性及 Sperandeo 的改进

| 道氏理论的局限 | Sperandeo 的改进 |
|---------------|-----------------|
| 信号滞后（趋势确认时已走出一段）| 2B 法则提前捕捉反转，降低滞后性 |
| 主观性（趋势线怎么画？）| 明确 3% 或 2 天规则，降低主观性 |
| 没有具体入场/出场点 | 1-2-3 准则给出确切入场和止损位置 |
| 没有仓位管理 | 补充 1-2% 单笔风险上限和金字塔加仓 |
| 仅适用于大盘指数 | 推广到个股、期货、外汇等多种市场 |

## 与相关体系的对接

Sperandeo 的道氏择时体系与以下概念紧密关联：

- Howard Marks 的 [[market-cycles-theory]]：道氏三阶段与 Marks 的周期位置判断异曲同工——都强调识别"当前处于什么位置"比预测"会到哪里"更重要
- [[sperandeo-trading-system]]：1-2-3 准则和 2B 法则的完整操作规范
- [[risk-and-return-cycles]]：趋势不同阶段的风险收益比系统性变化——趋势末期（道氏第三阶段）追高的风险回报比最差
- [[trading-psychology-fundamentals]]：道氏第三阶段的"狂热"和"绝望"本质上是群体心理的极端表现，参见 [[pendulum-of-psychology]]

## 核心金句

> "道氏理论不是预测市场的工具，而是理解市场的位置和方向的地图。" — Sperandeo

> "The trend is your friend until the end when it bends." — 市场谚语，Sperandeo 用 1-2-3 和 2B 来判定 "when it bends."
