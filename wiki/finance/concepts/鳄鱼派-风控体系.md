# 鳄鱼派风控体系

## 风控哲学 — 农夫与渔夫
**来源**: 文章#68

鳄鱼派风控体系基于两种思维模式：

| 角色 | 类比 | 行为准则 |
|------|------|---------|
| **投资者像农夫** 🧑‍🌾 | 环境合适+估值便宜+有预期→播种；火热成熟→收获止盈 | 等待播种季，耐心持有 |
| **投机者像渔夫** 🎣 | 天气好+风向好+海面平静→出海；波涛汹涌→休息 | 顺势而为，逆势休息 |

> **核心**：投资和投机是两套思维方式，不可混用。
> 傅海棠名言：\"重仓猛干、浮盈加仓、频繁交易、技术分析，基本上没好。\"

## 止损纪律

| 交易类型 | 止损线 | 说明 |
|---------|--------|------|
| 超短线 | -3% | 日内不回头 |
| 短线 | -5% | 1-3天 |
| 中线波段 | -8% | 1-4周 |
| 长线 | -12% | 基本面未恶化 |

**铁律**: 趋势破必须走，不可死扛。
> 越跌越买 vs 止损 → 鳄鱼派：止损。A股极端波动下不可死扛。

## 仓位管理梯度

| 市场状态 | 仓位 | 条件 |
|---------|------|------|
| 全面共振 | 80-100% | 四条件全满足 |
| 两只脚共振 | 50-80% | 科技+金融同涨 |
| 跷跷板 | 20-50% | 一只涨一只跌 |
| 共振下跌 | 0-20% | 两只脚都跌 |
| 恐慌/黑天鹅 | 0% | 强制空仓 |

### 成交量决定下限
**来源**: 文章#76, 文章#87

| 成交额 | 市场状态 |
|--------|---------|
| 3万亿+ | 跌不到哪儿去 |
| 2万亿+ | 正常调整范围 |
| 持续缩量阴跌 | 需警惕进一步下跌 |

> 牛市里被骂不可怕（有人玩），没人骂才可怕（如熊市五六千亿）

### 仓位管理的"越涨越买"反模式
**来源**: 文章#58, 文章#32

常见仓位问题三件套：
1. ❌ 重仓被套 — 高位加仓，一把亏光
2. ❌ 满仓躲牛市 — 大行情来了但仓位没了
3. ❌ 赚钱的越卖越涨，亏钱的越加越跌

**正确做法**：
- 低点有加仓，且加的仓位还没卖完才可做T
- 切勿盲目越涨越买，做好仓位规划
- 止损核心公式：设置好止损，反复尝试横盘后翘头的板块

### 空仓纪律

```
IF基差 > 80           → 减至 30%
两只脚共振下跌         → 减至 20%
热门股双顶             → 清仓
退潮阶段3              → 清仓
```

> 像鳄鱼一样潜伏：绝大多数时间空仓或轻仓观察，只在多重信号共振时出手。

## IF基差风险预警

| 基差 | 风险等级 | 最大仓位 | 操作 |
|------|---------|---------|------|
| > 80 | 🔴 极高 | 30% | 减仓+可做空 |
| 50-80 | 🟡 高 | 50% | 谨慎持仓 |
| 20-50 | 🟢 中 | 70% | 正常 |
| -20~20 | 🟢 低 | 100% | 可重仓 |

## 火车头风险

光通信/元件/SOC是科技板块的火车头。火车头低开下杀 → 整个科技板块大概率走弱。

**规则**: 火车头开盘 > -2% → 立即减仓 50%，不犹豫。

## 声东击西识别

金融拉升 + 科技低走 ≠ 真正的强势。是内资出货科技的手段。

**应对**: 金融拉科技跌 → 观望不追 → 等科技止跌确认 → 再考虑进场。

## 政策调控风险 — "龙哥降温"预警体系
**来源**: 文章#83, 文章#84, 文章#86, 文章#76

### 降温触发前四个可观测信号
1. 成交额持续在3万亿以上
2. 大金融突然大跌
3. 宽基指数ETF持续放量滞涨
4. 股指基差收敛成负数

### 降温组合拳（按严重程度）

| 等级 | 措施 | 影响 |
|------|------|------|
| 1️⃣ 轻度 | 限制融资（保证金80%→100%） | 限制杠杆 |
| 2️⃣ 中度 | 权重蓝筹巨量压单（如中信十几亿压单） | 压制指数 |
| 3️⃣ 重度 | 砸大金融（银行保险证券全绿） | 恐慌传导 |
| 4️⃣ 极端 | 抛售宽基指数ETF | 全面降温 |

### 应对策略
- **短线**：收兵，降低仓位
- **长线**：无碍，不必恐慌
- 降温后进入"老乡别走"阶段：龙哥拉大金融和中字头维稳
- **降温结束信号**：出头鸟板块走震荡或震荡慢跌
- 龙哥降温本质：**"皮鞭加碘伏，边打边消毒"**

## 融资杠杆风险监控
**来源**: 文章#86, 文章#22, 文章#57, 文章 (2026.05.25)

| 监控指标 | 信号 | 风险等级 |
|---------|------|---------|
| 融资余额持续走高 | 最需警惕的信号 | 🔴 高 |
| 融资客连续6日百亿买进 | 获利盘止盈风险加大 | 🟡 中 |
| 融资余额连续两天减少 | 情绪下降确认（2026.5.25新增） | 🟡 中 |
| 融资余额未持续下降 | 牛市还在继续 | 🟢 低 |

- 龙哥降杠杆手段：保证金下限从80%→100%（限制1倍杠杆以上）
- 融资资金特点：短线为主，获利了结的意愿强
- 2015年疯牛教训：融资余额历史新高→必须出手降温防止悲剧重演
- **情绪判断铁律（2026.5.25）**：单日融资余额减少不够，必须连续两天才能下结论情绪下降

## 极端行情与黑天鹅应对
**来源**: 文章#35, 文章#43, 文章#57, 文章#45

### 核心原则
| 原则 | 说明 |
|------|------|
| 技术分析失效 | 极端行情下技术分析胜率极低，做的越多亏的越多 |
| 视为短期噪音 | 段永平：地缘冲突等视为不可控短期噪音，不预测不回避 |
| 好公司加仓 | 危机时对好公司考虑加仓（深度价投逻辑） |
| 参考历史筑底 | 调整空间够了但时间不够时：参考历史筑底时间（如18个交易日） |

### 量化踩踏识别
- 小票主导、跌停激增
- 北证50和微盘股急跌
- 重仓高股息红利（四大银行/移动电信/长江电力）无需担心

### 极端行情仓位决策
> 关键看你持有的品种 + 安全垫 + 风险偏好

> **"降温重拳出击，护盘精打细算"** — 龙哥护盘与降温的节奏

## 心理与纪律规则
**来源**: 方法论提取 §五

### 牛市四大忌
1. **梭哈单押，主动坐牢** — 押注单一板块风险极大
2. **一会儿激动，一会儿恐慌** — 情绪波动导致错误决策
3. **换来换去，两头挨打** — 频繁切换板块，追涨杀跌
4. **道听途说，从不思考** — 缺乏独立研究，盲目跟风

### 长线定力测试
> 一只股票合理估值50元，因恐慌被错杀到25元。但存在利空，可能跌到15元。你选择：
> - **A.** 不做（厌恶下跌，看重短期波动 → 不适合长线）
> - **B.** 做（价值50元只卖25元是"道"，跌到15是插曲 → 适合长线）

### 微笑曲线三条件（长线被套后判断）
1. 微笑曲线是否出现：宽基指数 > 行业指数 > 个股（个股可能退市）
2. 赔率：年化20%才算及格（考虑时间成本）
3. 单笔金额上限：宽基/红利可无上限；行业指数/个股有金额上限

### 独立持仓原则（双卡双待）
> 每个持仓独立对待，互不干扰。可以做多种模式，但如果做不了双卡双待（不同策略），就单独运行一种模式。

### "怕高的是苦命人"
- 短线选手：新高/突破才是强势表现，克服恐高
- 长线选手：看估值，做低位，做安全边际
- 牛市里新高不断的个股是强势表现

## 量化风控规则

```python
def crocodile_risk_check(signals) -> dict:
    """鳄鱼派风控检查"""
    max_position = 1.0
    
    # IF基差
    if signals.if_basis > 80:
        max_position = 0.3
    elif signals.if_basis > 50:
        max_position = 0.5
    
    # 两只脚
    if signals.tech_down and signals.fin_down:
        max_position = 0.2
    
    # 火车头
    if signals.loco_open < -0.02:
        max_position = min(max_position, 0.5)
    
    # 退潮阶段
    if signals.ebb_stage == 3:
        max_position = 0.0
    
    return {'max_position': max_position, 'warnings': [...]}
```

## 长线投资2025年补充规则

### 长线持仓三问
**来源**: article_149 (2025.7.31)
- 你冲着什么去的？(买入逻辑)
- 预期兑现了吗？(持有理由)
- 估值大幅高估了吗？(卖出信号)
- **三个都没变→不恐慌，继续持有**

### 长线增减仓纪律
**来源**: article_145 (2025.7.2), article_149 (2025.7.31)
- "大涨的时候减点，下跌后企稳了买点"
- "大跌的时候慢慢买，大涨的时候慢慢卖"→持仓成本做成负的
- "但行好事，莫问前程，但买好股，莫在意短期波动"

### 长线仓位管理
**来源**: article_145 (2025.7.2), article_148 (2025.7.17), article_172 (2025.4.18)
- 长线不空仓，但仓位不能太重，不超过5成
- 2成防御(红利/现金流/银行) + 2成进攻(科技/成长)
- "异常护盘后，警惕市场出现反噬"
- "做长线的周期"→钢铁/碳酸锂/光伏等周期股的长线布局

### 好人好股策略
**来源**: article_172 (2025.4.18)
- "做好人，买好股，得好报"
- 没时间研究→逢低分批配红利+自由现金流ETF
- "人在经历了大起大落之后，才会明白，稳稳的幸福就已经很好了"

### 资金流向预警（2026-05-27增量补充）

### 融资余额监控
**来源**: article_34 (2026.2.5), article_51
- 融资余额连续5日净买入 → 杠杆看多，市场过热预警
- 融资余额连续5日净偿还 → 主动降杠杆(节前)或被动杀杠杆(强平)
- **关键区分**: 主动vs被动——节前降杠杆是正常的，强制平仓才是危险信号

### 外资(北向资金)预警
**来源**: article_9, article_34, article_79, article_83
- 北向单日净卖出>100亿 → 外资大幅撤退，警惕调整
- 北向持续净买入 → 外资看多，趋势确认
- **注意**: 外资不等于聪明钱，"美股体现外资态度，港股自己人砸"

### 大单/主力资金监控
**来源**: article_69, article_77
- 主力资金持续净流入某板块 → 可能成为新主线
- 主力资金从高位板块净流出 → 退潮信号
- 区分: 游资(短线) vs 机构(中线) vs 外资(长线)

## 2026.5.27–7.15 风控增量

### 护盘三种力度
**来源**: article_544
| 等级 | 目的 | 工具 |
|------|------|------|
| 小维护 | 防全面恐慌 | 大金融、巨型中字头 |
| 中护盘 | 防权重流动性危机 | 50/300/500 ETF |
| 大救市 | 赶快止血 | 多宽基ETF轮番+开会利好 |
- 偏好小维护/中护盘买阶段底；位置过高仍等大救市→远离（2015教训）

### 赈灾粮与地主豪绅
**来源**: article_541–543
- 剔除科技后多数板块已惨 → 该护盘；金融连阳=弱切换引导
- 仅赈灾粮不够，需机构开仓放粮；托而不举=稳住未筑底

### 奖池 / 时间止损
**来源**: article_549, 553
- 飞行员起飞须时间盒：到期不降杠杆 → 不论盈亏离场，压缩股票增现金
- 限购出台=降温信号之一，不代表立即见顶（可双顶/三顶）

### 躲雨纪律
**来源**: article_555–563
- 雷阵雨/巨震期进三剑客躲雨；短线最好休息；7月流动性匮乏尤忌冲动
