# 冯柳（高毅资产）— 弱者体系

> **浓缩金句：** "承认自己是弱者，不与市场争对错，只做大概率和高赔率的决策。"

## 一、战绩概览

- 散户出身，雪球ID"茅台03"，从几万做到几十亿
- 2015年加入高毅资产，管理规模数百亿
- 公开可查的邻山1号基金自2015年以来年化收益约30%+
- A股最传奇的散户→百亿基金经理转型案例

## 二、核心理念：弱者体系

冯柳的整个框架建立在"我是弱者"这个前提上：

```
强者思维 → 我比市场聪明 → 主动预测 → 错了就死扛
弱者思维 → 市场永远比我聪明 → 放弃预测 → 靠赔率取胜
```

**弱者体系的三个支柱：**

1. **放弃预测：** 不判断明天涨跌，不猜顶底。只判断"现在的赔率合不合适"
2. **赔率优先：** 买在赔率（下跌空间小），卖在概率（上涨确定性低）
3. **市场反馈：** 价格走势是市场给我的反馈——涨了说明我做对了但不一定是对的，跌了同理

> "我不去判断市场会怎么走，但我会判断如果市场往某个方向走，我能不能承受。"

## 三、四层认知框架

冯柳把投资标的按"可认知程度"分为四层，决定仓位大小：

| 层级 | 定义 | 时间跨度 | 仓位 | 例子 |
|------|------|---------|------|------|
| **可理解** | 商业模式简单，能看懂 | — | 前提条件 | 茅台、榨菜 |
| **可预期** | 1年内业绩可推算 | 1年 | 基础仓(30%) | 订单确定性高的公司 |
| **可展望** | 3年路径能大致判断 | 3年 | 加仓(30%) | 行业趋势明确的龙头 |
| **可想象** | 10年大方向说得通 | 10年 | 重仓(40%) | 颠覆性创新赛道 |

**可量化规则：**
- 只能到"可理解"层 → 最多 10% 仓位（观望仓）
- 达到"可预期" → 30% 基础仓位
- 达到"可展望" → 叠加30%，合计60%
- 达到"可想象" → 叠加40%，可满仓
- 四个层级都打不到 → 不碰

> 翻译成系统语言：商业模式复杂度评分、盈利可预测性评分、行业趋势确定度评分、赛道想象空间评分。

## 四、三类投资机会

冯柳把机会分为三种，不同机会对应不同操作方式：

### 4.1 基于价值的（Value-based）

**特征：** 公司被低估，市场定价错误
**操作：** 左侧买入，越跌越买，不设止损
**条件：** 必须能算清楚"底在哪里"——即资产价值、清算价值、现金流折现
**可量化：** PB < 1 或 PE < 历史10%分位 + 现金流为正 + 无明显退市风险

### 4.2 基于趋势的（Trend-based）

**特征：** 趋势明确但估值尚可
**操作：** 右侧跟进，趋势破坏即走
**条件：** MA多头排列 + 成交量配合 + 行业景气度向上
**可量化：** MA20 > MA60 > MA120 + 月线MACD金叉 + 量比>1.2

### 4.3 基于博弈的（Game-based）

**特征：** 市场存在明显的认知偏差或情绪极端
**操作：** 逆向买入，等待共识反转
**条件：** 所有人都在卖但价格跌不动了 / 所有人都在说好但价格涨不动了
**可量化：** RSI < 25（极端超卖）+ 近5日跌幅>大盘2倍 + 机构持仓降至历史低位

## 五、仓位管理与轮动

### 5.1 永远满仓

冯柳的核心仓位哲学：**永远满仓，通过轮动而非减仓来控制风险。**

逻辑：
- 现金是"确定性最高的资产"也是"收益率最低的资产"
- 减仓=承认自己知道市场要跌——弱者不预测，所以不减仓
- 觉得风险大→换到更安全的标的（如高股息/防御股），而不是拿现金
- 轮动的本质是：用持仓结构的调整来替代仓位高低的调整

> ⚠️ 这与鳄鱼派的"潜伏等信号"不同。鳄鱼派可以空仓等，冯柳是满仓等——两种不同的风控哲学。

### 5.2 赔率驱动轮动

**轮动触发条件：**
- 持仓A的赔率（上涨空间/下跌空间）降到 2:1 以下
- 候选B的赔率在 4:1 以上
- → 从A轮动到B

**可量化：**
```
赔率 = (目标价 - 当前价) / (当前价 - 硬底价)

硬底价 = max(净清算价值, 股息支撑价, 前低支撑位)
目标价 = 分析师一致预期 × 0.7（打个折）
```

## 六、风控纪律

冯柳的风控不是靠止损，是靠结构：

1. **不单吊一只：** 永远分散到 8-15 只票，单票上限 15%
2. **三类机会配比：** 趋势类50% + 价值类30% + 博弈类20%（动态调整）
3. **行业分散：** 单行业上限 30%
4. **硬止损：** 虽然名义上不设止损，但"趋势类"机会一旦趋势破坏必须走
5. **无退市风险：** 不碰ST、不碰有财务造假嫌疑的、不碰大股东质押率>60%的

> "我不是不止损，我是用仓位结构替代了止损。"

## 七、与鳄鱼派的契合/冲突点

| 维度 | 冯柳弱者体系 | 鳄鱼派 | 契合/冲突 |
|------|------------|--------|----------|
| 仓位 | 永远满仓轮动 | 潜伏空仓等待 | 🔴 冲突 |
| 预测 | 放弃预测，靠赔率 | 放弃预测，等信号 | 🟢 契合 |
| 持仓周期 | 数月至数年 | 数月至数年 | 🟢 契合 |
| 集中度 | 8-15只分散 | 重仓少数 | 🟡 部分冲突 |
| 买点 | 赔率够就买 | 信号共振才买 | 🟡 部分冲突 |
| 核心哲学 | 弱者认输 | 鳄鱼潜伏 | 🟢 高度契合 |

**融合方案：** 在鳄鱼派框架中引入冯柳的赔率判断作为"前置筛选"——先看赔率合不合适，再看信号共不共振。如果赔率不够，信号再强也不重仓。

## 八、可落地为系统规则的特征

### 规则1：赔率门槛
```python
def margin_of_safety_check(symbol, current_price):
    """冯柳式赔率检查 — 赔率<3:1不进"""
    upside = target_price_consensus(symbol) * 0.7 - current_price
    downside = current_price - hard_floor(symbol)  # 净清算/股息支撑/前低
    odds = upside / downside if downside > 0 else 999
    return odds >= 3.0
```

### 规则2：四层认知评分
```python
def cognition_score(symbol):
    """0-10分，分数越高=可认知程度越高"""
    score = 0
    if business_model_simple(symbol):     # 可理解: +2
        score += 2
    if earnings_predictable_1y(symbol):   # 可预期: +3
        score += 3
    if trend_visible_3y(symbol):          # 可展望: +3
        score += 3
    if vision_plausible_10y(symbol):      # 可想象: +2
        score += 2
    return score
# 分数→仓位映射: <2不碰, 2-3=10%, 4-5=30%, 6-7=60%, 8-10=满仓
```

### 规则3：三类机会分类器
```python
def fengliu_classify(symbol):
    """返回机会类型"""
    if pb < 1.0 and cash_flow > 0 and no_delist_risk:
        return "value"    # 基于价值
    elif ma20 > ma60 > ma120 and volume_ratio > 1.2:
        return "trend"    # 基于趋势
    elif rsi < 25 and recent_decline > index_decline * 2:
        return "game"     # 基于博弈
    return None           # 不符合任何类型
```

### 规则4：赔率轮动信号
```python
def rotation_signal(portfolio, candidates):
    """检查是否需要轮动"""
    for pos in portfolio:
        odds = compute_odds(pos)
        if odds < 2.0:  # 赔率降到2:1以下
            best = max(candidates, key=lambda c: compute_odds(c))
            if compute_odds(best) > 4.0:  # 候选赔率4:1以上
                return ("rotate", pos, best)
    return ("hold",)
```

## 九、不适合的场景

- 纯趋势行情后期（赔率都低时冯柳体系无票可买）
- 流动性危机（满仓策略在流动性枯竭时最受伤）
- 需要精准择时的场景（冯柳不择时）
- 小市值垃圾股（四层认知通不过）
