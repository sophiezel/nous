# 王国斌（泉果基金/前东方红）— A股机构生存之道

> **浓缩金句：** "在A股，安全边际不是可选项，是生存必需。A股的波动率决定了你必须买得足够便宜才能扛得住波动。"

## 一、补什么缺口

**补：A股机构老将的"周期生存"视角。** 王国斌在A股20多年，经历多轮牛熊，他的框架核心不是怎么赚最多，而是怎么在A股极端波动中活下来并复利。对用户当前重仓港股+浮亏状态有直接参考价值。

## 二、核心理念

王国斌和陈光明都推崇价值投资，但王国斌更强调"A股的独特性"：

```
美股 → 慢牛长牛 → 可以接受合理估值买入
A股 → 暴涨暴跌 → 必须在低估时买入，否则扛不住回撤
港股 → 流动性陷阱+极端低估 → 必须在极度低估时买入
```

### A股安全边际三原则

```
1. 只能在PE低于历史中位数时买入
2. 永远不要在全市场PE>20时开新仓
3. 单笔投资必须做好"再跌30%我也能扛"的准备
```

## 三、可量化规则

### 王国斌式安全边际检查
```python
def wangguobin_margin_check(symbol, market):
    """A股/港股安全边际检查"""
    pe = pe_ttm(symbol)
    pe_median_5y = pe_median_5y(symbol)
    
    if market == "a":
        # A股：PE必须低于5年中位数
        if pe > pe_median_5y:
            return (False, f"PE={pe:.0f}>{pe_median_5y:.0f}(中位数)，不便宜不买")
        # A股全市场PE>20不新开仓
        if market_pe("a") > 20:
            return (False, "全市场PE>20，停止新开仓")
    
    if market == "hk":
        # 港股：PB<1.5为硬条件
        pb = pb(symbol)
        if pb > 1.5:
            return (False, f"港股PB={pb:.1f}>1.5")
        # PE<15
        if pe > 15 and pe > 0:
            return (False, f"港股PE={pe:.0f}>15")
    
    return (True, "安全边际充足")
```

## 四、系统注入

王国斌作为A股/H股安全边际的**最终把关人**：

```
任何A股买入 → 王国斌PE检查 → 不通过 → 拒绝
```
