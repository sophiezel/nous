# 德鲁肯米勒 — 集中押注+重仓时机

> **浓缩金句：** "当你极度确信时，就把所有鸡蛋放在一个篮子里，然后看好这个篮子。"

## 一、补什么缺口

**补：重仓时机判断缺口。** 鳄鱼派"重仓"是原则，但什么时候从5%加到20%？德鲁肯米勒是这方面的极致大师——索罗斯的操盘手，30年年化30%。

## 二、核心理念：确信度决定仓位

德鲁肯米勒的仓位逻辑极度简单：

```
确信度 50-60% → 小仓位试探（5-10%）
确信度 70-80% → 标准仓位（15-20%）
确信度 90%+   → 重仓押注（30-50%，历史上他做过）
```

**关键：确信度不是感觉，是有客观标准的：**

### 确信度评分表
```python
def druckenmiller_conviction(symbol):
    score = 0
    # 宏观支持(30分)
    if fed_direction() == "dovish": score += 15
    if economic_cycle() == "expansion": score += 15
    # 技术面(25分)
    if price > ma200(symbol): score += 10
    if ma50 > ma200(symbol): score += 8
    if volume_trend(symbol) == "increasing": score += 7
    # 基本面(25分)
    if earnings_beat(symbol): score += 10
    if earnings_upgrade(symbol): score += 8
    if sector_leading(symbol): score += 7
    # 流动性(20分)
    if avg_daily_amount(symbol) > 5e8: score += 10
    if bid_ask_spread(symbol) < 0.001: score += 10
    
    return score  # 满分100，映射到仓位%
```

## 三、集中押注的三个条件

德鲁肯米勒只有在三个条件同时满足时才重仓：

```
1. 宏观顺风 → 央行宽松/经济扩张/政策支持
2. 技术共振 → 突破关键位+放量+均线多头
3. 流动性充裕 → 能买进去也能卖出来
```

缺任何一个 → 降半仓。缺两个 → 不碰。

## 四、系统注入

德鲁肯米勒作为鳄鱼派的**仓位放大器/限幅器**：

```
德鲁肯米勒确信度 > 80 + 鳄鱼派信号共振 → 仓位上限 20%
德鲁肯米勒确信度 < 50 → 仓位上限 10%
德鲁肯米勒确信度 < 30 → 仓位上限 5%
```
