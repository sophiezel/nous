# 邱国鹭（高毅资产）— 数月亮不数星星

> **浓缩金句：** "数月亮不数星星——选已经赢了的公司，不赌谁会赢。"

## 一、战绩概览

- 前南方基金投资总监，管的基金在任期内年化约20%
- 2015年创办高毅资产，目前管理规模超千亿
- 代表作《投资中最简单的事》是A股价值投资入门必读
- 风格：低换手、集中持股、逆向布局

## 二、核心理念：数月亮不数星星

```
数星星 → 从5000只里挑黑马 → 赌谁会成为龙头 → 胜率低、研究累
数月亮 → 只盯3-5个已经确立龙头地位的行业 → 买已经赢的 → 胜率高、研究聚焦
```

**月亮的标准（已确立的龙头）：**
- 市场份额前3且CR3 > 50%
- ROE 连续3年 > 15%
- 有清晰护城河（品牌/成本/网络效应/规模优势）
- 行业发展阶段处于成长期或成熟期（非衰退期）

> "宁可用合理的价格买优秀的公司，也不要用便宜的价格买平庸的公司。"

## 三、品质×估值×时机 三分法

邱国鹭把投资决策拆为三个独立维度，任何一个维度不通过就不投：

### 3.1 品质（Quality）— 一票否决

**四不碰清单：**

```
✗ 商业模式差的公司
  → 重资产、高负债、低毛利、强周期、无定价权
  → 量化：毛利率 < 20% OR 负债率 > 70% OR 固定资产/总资产 > 60%

✗ 管理层有问题的公司
  → 大股东减持、关联交易多、热衷跨界并购、跟风蹭热点
  → 量化：大股东质押率 > 50% OR 3年内有关联交易违规

✗ 行业格局不明的公司
  → 价格战、技术路线未定、政策不确定、CR3 < 30%
  → 量化：行业CR3 < 30% OR 行业增速波动> 20%

✗ 讲故事的公司
  → PPT造车、画饼充饥、没有现金流支撑的成长
  → 量化：连续2年经营现金流为负 OR 研发投入<营收3%
```

### 3.2 估值（Valuation）— 便宜是硬道理

**邱国鹭对估值极度敏感：**

```
PE(TTM) < 行业平均 × 0.8  AND  PE(TTM) < 历史5年中位数
PB < 3（A股）/ < 2（港股）
股息率 > 2%（A股）/ > 3%（港股）
PEG < 1（成长股）
```

> "买得便宜是硬道理。再好的公司买贵了也是烂投资。"

### 3.3 时机（Timing）— 逆向布局

**邱国鹭的逆向不是"越低越买"，是"利空出尽后买"：**

- 不在下跌中接飞刀，等利空消化完
- 标志：利空消息出来后股价不再创新低 + 成交量萎缩到地量
- 可量化：股价从最低点反弹 5%+ 且 成交量 > 前5日均量

> "逆向投资不是跌了就买，是等它跌不动了再买。"

## 四、选股清单（可量化）

### 初选条件（全部满足）：

```
1. 行业地位：市场份额 TOP3 OR 行业内公认龙头
2. ROE：连续3年 > 15%
3. 现金流：经营现金流/净利润 > 0.8（利润有现金支撑）
4. 毛利率：> 行业平均
5. 负债率：< 50%（金融股除外）
6. 股息：连续3年分红
7. 护城河：至少具备1项（品牌/成本/网络效应/规模/转换成本）
```

### 估值的三种买法：

| 买法 | 条件 | 仓位 |
|------|------|------|
| 低估买入 | PE < 历史20%分位 | 重仓(60-80%) |
| 合理买入 | PE 在历史30-50%分位 + 品质极好 | 中等(30-50%) |
| 不买 | PE > 历史70%分位 | 0%，等回调 |

## 五、仓位与风控

### 5.1 集中持仓

- 常态持仓 10-15 只
- 单票上限 15%（极度确信可到 20%）
- 单行业上限 30%
- 前三大持仓通常占 50%+

与冯柳不同：邱国鹭是"精选集中"，冯柳是"分散轮动"。

### 5.2 不择时但控回撤

- 原则上永远满仓（和冯柳一样）
- 但会通过"换仓到更便宜的"来控制风险
- 大盘 PE > 25时开始减仓（整体仓位降至50%以下）
- 大盘 PE < 12时满仓甚至上杠杆

### 5.3 卖出的三个理由

1. **买错了** — 买入逻辑被证伪（基本面恶化、行业格局改变）
2. **变贵了** — PE 超过历史 90% 分位
3. **有更好的** — 发现赔率更好的标的

> 注意：因为"跌了"而卖不在邱国鹭框架里——跌了只会让他想加仓。

## 六、与鳄鱼派的契合/冲突点

| 维度 | 邱国鹭 | 鳄鱼派 | 契合/冲突 |
|------|--------|--------|----------|
| 选股 | 龙头+品质+便宜 | 信号共振+趋势+赔率 | 🟡 不同路径，可互补 |
| 仓位 | 集中10-15只 | 重仓少数 | 🟢 契合 |
| 周期判断 | 看PE分位数 | 看大周期位置 | 🟢 高度契合 |
| 买点 | 利空出尽+低位 | 信号共振 | 🟡 邱更早入场 |
| 行业选择 | CR3>50%的成熟行业 | 不限行业看信号 | 🟡 邱更窄 |

**融合方案：** 邱国鹭的"四不碰"清单可以作为 screener 的初筛硬条件——先把垃圾过滤掉，再用鳄鱼派信号筛选。品质审核（邱国鹭）在前，时机选择（鳄鱼派）在后。

## 七、可落地为系统规则的特征

### 规则1：四不碰过滤（硬条件）
```python
def qiuguolu_quality_filter(symbol):
    """返回不合格原因，全部通过返回None"""
    # 商业模式
    if gross_margin(symbol) < 0.20: return "毛利率<20%"
    if debt_ratio(symbol) > 0.70: return "负债率>70%"
    if fixed_asset_ratio(symbol) > 0.60: return "重资产>60%"
    # 管理层
    if pledge_ratio(symbol) > 0.50: return "大股东质押>50%"
    # 行业格局
    if industry_cr3(symbol) < 0.30: return "行业CR3<30%"
    # 讲故事
    if operating_cashflow_2y(symbol) < 0: return "经营现金流连续为负"
    return None  # 通过
```

### 规则2：品质评分（0-10）
```python
def quality_score(symbol):
    score = 0
    if roe_3y_avg(symbol) > 0.15: score += 3
    if roe_3y_avg(symbol) > 0.20: score += 2  # 额外
    if cashflow_ratio(symbol) > 0.8: score += 2
    if dividend_yield(symbol) > 0.02: score += 1
    if market_share_top3(symbol): score += 2
    return score  # >=5才算通过
```

### 规则3：估值门槛（自适应）
```python
def valuation_gate(symbol):
    """返回仓位建议，0=不买"""
    pe = pe_ttm(symbol)
    pe_pct = pe_percentile_5y(symbol)  # PE在历史5年的分位数
    
    if pe_pct < 0.20: return 0.80  # 低估→重仓
    elif pe_pct < 0.50: return 0.50 # 合理→半仓
    elif pe_pct < 0.70: return 0.30 # 偏高→轻仓
    else: return 0                   # 太贵→不买
```

### 规则4：逆向入场信号
```python
def contrarian_entry(symbol):
    """利空出尽的逆向买点"""
    recent_low = min(prices[-20:])
    current = prices[-1]
    volume_today = volumes[-1]
    avg_volume_5d = sum(volumes[-5:]) / 5
    
    # 从最低点反弹5%+
    rebounded = (current / recent_low - 1) > 0.05
    # 放量确认（非缩量反弹）
    volume_confirm = volume_today > avg_volume_5d
    
    return rebounded and volume_confirm
```

## 八、不适合的场景

- 新兴行业（CR3未形成，不符合"数月亮"）
- 主题炒作行情（品质优先会踏空纯概念）
- 高成长高估值（PE分位数天然排斥）
- 纯技术面驱动的短线
