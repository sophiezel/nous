# 赵军（淡水泉投资）— 逆向投资

> **浓缩金句：** "市场过度反应的地方，就是超额收益的来源。"

## 一、战绩概览

- 2007年创立淡水泉，中国首批百亿私募
- 前嘉实基金基金经理，公募转私募标杆
- 15年年化约15%（费后），擅长在市场恐慌时逆向布局
- A股逆向投资策略最系统化、最机构化的代表

## 二、核心理念：逆向投资的三层确认

赵军的逆向不是"跌了就买"，而是三层确认后才出手：

### 第一层：市场情绪极端

```
可量化信号：
  卖方分析师一致看空比例 > 80%
  社交媒体讨论热度降至冰点（< 3个月最低的20%）
  机构持仓比例降至 2年最低
  换手率降至 1年最低
```

### 第二层：基本面未恶化

```
必须确认：
  行业趋势没有被颠覆（不是柯达式的消亡）
  公司核心竞争力没有受损
  财务指标：营收增速可能放缓但未转负、现金流正常
  管理层未减持、未质押爆仓
```

### 第三层：价格已充分反映悲观

```
估值确认：
  PE 处于 5年最低 10%分位
  PB < 1.5（A股）/ < 1（港股）
  股价距离高点回撤 > 50%
```

**三层都满足 → 买入。只满足一两层 → 继续等。**

## 三、持仓管理

- 分散：20-30 只持仓（比冯柳/邱国鹭分散得多）
- 单票上限 8%
- 逆向买入后通常持有 1-3 年
- 等待"市场情绪修复+业绩兑现"双重催化
- 止盈：PE 回到历史中位数以上开始减仓

## 四、可量化规则
```python
def zhaojun_contrarian_signal(symbol):
    # 情绪极端
    sentiment_extreme = (
        analyst_bearish_ratio(symbol) > 0.80 and
        institutional_holding_pct(symbol) < two_year_low(symbol)
    )
    # 基本面ok
    fundamentals_ok = (
        revenue_growth(symbol) >= 0 and
        cashflow(symbol) > 0 and
        not industry_disrupted(sector(symbol))
    )
    # 价格充分悲观
    price_pessimistic = (
        pe_percentile_5y(symbol) < 0.10 and
        drawdown_from_high(symbol) > 0.50
    )
    return sentiment_extreme and fundamentals_ok and price_pessimistic
```

- 🟡 差异：赵军更分散(20-30只)，鳄鱼派更集中
