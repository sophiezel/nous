## 1.1 鳄鱼派三大支柱

| 重仓一击必中 | 高确定性机会出现时下重注，不做小仓位试探 | 每日推荐上限 5 只 A 股 |
| 简单纯粹的道层面思考 | 拒绝过度复杂的技术指标堆砌，回归本质 | 均线多头排列 + MACD金叉 + RSI>50 |

### 决策准则

```python
def crocodile_three_pillars(signal_score, opportunity_quality):
    """三大支柱决策"""
    if signal_score < 80:
        return '潜伏观望'       # 绝大多数时间空仓
    elif opportunity_quality >= 8 and signal_score >= 90:
```

## 1.2 屠龙到化龙：资金集中度的演变哲学

来源: 文章#1 (2026.05.26), 补充1.1

资金集中度 → 交易拥挤度，如同"屠龙少年→恶龙"的异化过程。

### 演变路径

```
[良性] 资金集中度（屠龙少年）
   → 先涨带动后涨，合力做多
   → 市场资金不杂乱，产生赚钱效应
   ↓
[临界] 百亿成交个股中科技占比 > 85%
   ↓
[恶性] 交易拥挤度（变成恶龙）
   → 先涨吸血其他板块
   → 放量普跌，增量资金单押
```

### 量化阈值表

| 阶段 | 百亿成交个股集中度 | 市场特征 | 操作 |
|------|------------------|---------|------|
| 资金集中度（健康） | < 60% | 合力做多，赚钱效应扩散 | 正常持仓 |
| 预警区 | 60-85% | 开始分化，资金收敛 | 边打边撤 |
| 交易拥挤度（危险） | > 85% | 放量普跌，单押板块 | 只做强的，弱了就走 |
| 极端拥挤 | > 90% | 踩踏风险极高 | 大幅减仓 |

### 规律

- 横有多长，竖有多高：长期被压制的板块一旦化龙，爆发力更强
- 当前(2026.5.25)实测：29只百亿成交个股，科技占27只(93%) → 极度拥挤
- 历史出现拥挤度极值记录：去年2次、今年2月1次、本次(2026.5.26)为第4次

### 滞涨假设（2026.5.25新增）
来源: 文章 (2026.05.25)

鳄鱼派提出"滞涨或者发生不太好的事情"的宏观新假设。即使指数上涨（创业板涨超2%），假设依然成立，需同时观察三个维度：
1. 交易拥挤度（百亿成交29只中科技占27只）
2. 飞行员基差（尾盘再度增仓打压，基差飙升创近期新高）
3. 日债利率（10年期日债利率处于预警区间）

> 核心判断：指数上涨≠假设被证伪。

### 情绪判断的融资余额法（2026.5.25新增）
来源: 文章 (2026.05.25)

判断情绪是否下降，不能只看股价走势，要结合融资余额：
- **确认条件**：杠杆哥们持续减仓 + 融资余额连续两天减少
- 单日减少不够，必须连续两天才能下结论

### 高低切风险（2026.5.25新增）
来源: 文章 (2026.05.25)

资金从科技出来的路径：
```
科技退潮 → 机构先去其他板块打底 → 底部买扎实 → 短线大资金点火 → 新主线形成
```

> **不要指望市场无缝衔接**。过去一年A股从未成功实现一次良性的高低切无缝衔接。
> 解铃还须系铃人：通信和元件不继续涨，短线情绪就不容易继续嗨。

正确做法：等科技退潮确认 → 观察机构打底方向 → 确认新火车头 → 再跟

## 1.5 初始驱动 vs 阶段驱动

来源: 文章#7 (2026.05.20), 补充1.4

### 核心区别

| 维度 | 初始驱动 (Initial Drive) | 阶段驱动 (Phase Drive) |
|------|------------------------|----------------------|
| 驱动力 | 基本面改善 | 情绪和资金面 |
| 持仓策略 | 耐心陪伴 | 及时止盈 |
| 典型场景 | 低估价值股修复 | 题材炒作、热点 |
| 持仓时间 | 月/年级别 | 天/周级别 |
| 止盈目标 | PE回归中枢（如+30-50%） | 情绪高点（如+15-20%） |

### 决策树

```
基本面改善了吗？(现金流/护城河变化)
    ├── 是 → 初始驱动 → 耐心持有，越跌越买(好公司)
    └── 否 → 看资金面和情绪
                ├── 有增量资金 + 故事可讲 → 阶段驱动 → 及时止盈
                └── 无增量资金 → 不做
```

**深度价投核心**：回归第一性原理，问"现金流改变了吗？护城河改变了吗？"

# 第二章：市场信号解读体系

## 2.1 两只脚理论

来源: 文章#4 (2026.5.21), 文章#3 (2026.5.22), 补充2.3

### 核心框架

> 指数不论是上涨还是下跌，看两只脚：科技和金融。
> - 有一个在涨，指数就跌不深
> - 有一个在跌，就涨不高
> - 两个一起涨是最好的盘面
> - 两个一起跌，指数就拉稀

### 量化映射 — 科技+大金融五种排列组合

来源: 文章#12, 补充2.5

| # | 科技状态 | 大金融状态 | 指数方向 | 仓位建议 | 操作 |
|---|---------|-----------|---------|---------|------|
| 1 | ✅ 良性轮动+火车头新高 | 有板块走趋势 | 新高概率大，普涨行情 | 80-100% | 可重仓 |
| 2 | ✅ 良性轮动+火车头新高 | 无板块走趋势 | 震荡，科技吸血其他板块 | 50-80% | 持仓科技 |
| 3 | ❌ 轮动不良性+仅抱团火车头 | 无趋势 | 震荡回调概率大 | 30-50% | 减仓 |
| 4 | ❌ 科技熄火 | 有板块走趋势 | 宽幅震荡，换主线概率大 | 20-50% | 观望换仓 |
| 5 | ❌ 科技熄火 | 无趋势 | 拉稀概率大 | 0-20% | 空仓 |

### 伪代码

```python
def two_feet_signal(tech_state, fin_state):
    """两只脚信号判断"""
    # tech_state: 'bullish_rotation_new_high', 'bullish_rotation', 'poor_rotation', 'dead'
    # fin_state: 'trend_up', 'no_trend'
    
    if tech_state in ('bullish_rotation_new_high', 'bullish_rotation'):
        if fin_state == 'trend_up':
            return 1, '共振上涨 — 可重仓', 0.8
        else:
            return 2, '科技独涨 — 持仓科技', 0.6
    elif tech_state == 'poor_rotation':
        return 3, '轮动不良 — 减仓', 0.3
    else:  # tech dead
        if fin_state == 'trend_up':
            return 4, '换主线概率 — 观望', 0.3
        else:
            return 5, '共振下跌 — 空仓', 0.0
```

### 中证金融观察指数

来源: 文章#5 (2026.05.20), 补充1.3

- 中证金融指数 = 银行 + 保险 + 证券 + 多元金融 + 地产（看一个顶5个）
- **关键法则**：中证金融指数没站上60日均线开启趋势之前，不要期待全面牛市
- **K型复苏**：高新技术修复快（科技涨）、传统行业修复慢（金融弱）

### 大小儿子隐喻（2026.5.25补充）

- **小儿子（科技）**：集万千宠爱于一身，越涨越出利好
- **大儿子（弱势板块）**：不单指金融，也包括地产、消费等低位板块
- 大儿子继续夹缝中生存，越弱越不受资金待见
- 仅极少数长线资金在逢低打底大儿子

## 2.2 交易拥挤度：完整演化路径与临界值

来源: 文章#1 (2026.05.26), 文章#2 (2026.05.25), 补充2.1

### 演化路径

```
资金集中度(正面、初期/中期)
    → 资金不杂乱，合力打造赚钱效应
    → 先涨带动后涨
    ↓ 临界：百亿科技占比 > 85%
交易拥挤度(负面、后期)
    → 资金过度集中于单一板块
    → 先涨吸血其他板块
    → 形成踩踏风险
    ↓
极点 → 缩量 → 震荡 → 退潮
```

### 拥挤度下跌三大征兆

1. **百亿科技占比 > 85%** — 成交额百亿以上个股中科技占比过高
2. **放量但普跌** — 增量资金卖其他、买科技
3. **增量资金单押科技** — 融资客集中买入科技

### 操作规则

```
拥挤 ≠ 立即熄火。但只做强的，弱了就走，边打边撤。
科技情绪在90°-100°之间 → 可做但需边打边撤
情绪降至100以下 = 需配合融资余额持续2天减少才能确认退潮
```

### 飞行员起飞条件

```python
def pilot_takeoff_check(科技龙头_形态, IF基差, 尾盘增仓):
    """判断飞行员（空头）是否大规模起飞"""
    conditions_met = 0
    
    if 科技龙头_形态 in ('双顶', '做头结构'):
        conditions_met += 1
    
    if IF基差 > 97:
        conditions_met += 1
    
    if 尾盘增仓 == '明显增仓打压':
        conditions_met += 1
    
    if conditions_met >= 2:
        return '🔴 飞行员大规模起飞 — 立即减仓'
    elif conditions_met == 1:
        return '🟡 轻度起飞迹象 — 关注'
    else:
        return '🟢 无起飞信号'
```

### 不做空的条件

- 市场热情还在，容易坠机
- 只有博弈阶段，不敢重仓
- 做头至少需要3周结构（下跌→反弹→再下跌）

## 2.4 情绪五级晴雨表

### 情绪分级量化表

| 等级 | 状态 | 量化条件 | 仓位 | 操作 |
|------|------|---------|------|------|
| ☀️ 阳光明媚 | 放心干 | 放量上涨+火车头强+轮动健康 | 80-100% | 积极做多，板块赛马 |

| 🌧️🌧️ 中雨 | 降低仓位 | 放量下跌+基差扩大 | 20-30% | 减仓，等待恢复信号 |

### 恢复信号（小雨→多云）

1. 强反弹到飞行员不敢起飞（基差快速收敛）
2. 火车头强（可换梯队不换板块）
3. 继续放量

### 关键规律

- 市场情绪演化很少直线推进，类似天气：多云转小雨后可能再次多云
- **"秋老虎"效应**：高温不会一场大雨就浇灭—强势行情不会一次调整就结束
- **情绪量化**：科技情绪在90°-100°之间时可做但需边打边撤

## 2.5 火车头三梯队轮动模型

来源: 文章#20, 文章#12, 文章#19, 文章#18, 补充2.4

### 三梯队定义

| 梯队 | 对应板块 | 角色 | 行为特征 |
|------|---------|------|---------|
| 第一梯队（火车头） | 光通信/元件 | 领涨者 | 持续新高→分歧走弱震荡→反弹 |
| 第二梯队 | 半导体/芯片 | 接力者 | 接住第一梯队流出资金接力新高 |
| 第三梯队 | 软件/计算机/应用 | 补涨者 | 最后补涨 |

### 良性切换 vs 不良切换

```
良性切换（行情延续）:
第一梯队分歧走弱 → 第二梯队接力新高
→ 第二梯队反哺第一梯队
→ 第一梯队王者归来再新高
→ 第三梯队加速补涨

不良切换（行情见顶）:
第一梯队新高失败 → 第二梯队震荡
→ 第三梯队补涨结束
→ 整体科技退潮
```

### 量化时序模型


## 4.6 长线调仓三大原则

来源: 文章#58 (2026.3.2), 规则1.9

| # | 原则 | 描述 | 违反后果 |
|---|------|------|---------|
| 1 | 仓位上限原则 | 各板块仓位独立，规划20%上限不打穿 | 单一板块风险暴露过大 |
| 2 | 止盈资金去向原则 | 止盈仓位只能投入原板块或新板块，不能加仓已打满的浮亏板块 | 恶性循环，越加越亏 |
| 3 | 去弱vs加强原则 | 去弱加强适合短线投机，长线应坚持基本面（去强加弱/独立对待） | 短线思维做长线 |

```python
def rebalance_long(板块, 仓位信息):
    """长线调仓"""
    for 板块名, 信息 in 仓位信息.items():
        if 信息.仓位比例 >= 0.20:
            # 板块仓位已达上限
            if 信息.浮盈 > 止盈目标:
                执行止盈(板块名)
                # 止盈资金只能投入原板块或新板块
            elif 信息.浮亏 > 止损目标:
                执行止损(板块名)
            # 不可用其他板块的止盈资金加仓已打满的板块
        
        # 长线坚持基本面，不因短期强弱调仓
        if 信息.基本面未恶化:
            continue  # 持有
```

```python
def crocodile_decision_engine(signals):
    """鳄鱼派综合决策引擎"""
    总分 = 0
    
    # 1. 两只脚评分
    if signals.科技_涨 and signals.金融_涨:
        总分 += 2 * 0.3
    elif signals.科技_涨 or signals.金融_涨:
        总分 += 0 * 0.3
    else:
        总分 += (-2) * 0.3
    
    # 2. IF基差评分
    if signals.IF基差 < 30:
        总分 += 1 * 0.2
    elif signals.IF基差 > 80:
        总分 += (-2) * 0.2
    
    # 3. 拥挤度评分
    if signals.科技百亿占比 < 0.6:
        总分 += 1 * 0.15
    elif signals.科技百亿占比 > 0.85:
        总分 += (-2) * 0.15
    
    # 4. 火车头评分
    if signals.火车头_开盘 > -0.02:
        总分 += 1 * 0.15
    elif signals.火车头_开盘 < -0.02:
        总分 += (-2) * 0.15
    
    # 5. 成交量评分
    if signals.成交额 > 20000_亿:
        总分 += 1 * 0.1
    elif signals.成交额 < 10000_亿:
        总分 += (-1) * 0.1
    
    # 6. 情绪评分
    if signals.情绪 == '阳光明媚':
        总分 += 1 * 0.1
    elif signals.情绪 in ('中雨', '大雨'):
        总分 += (-1) * 0.1
    
    # 仓位映射
    if 总分 >= 3.0:
        return 0.8, '全面共振 — 重仓出击'
    elif 总分 >= 1.0:
        return 0.6, '共振良好 — 积极参与'
    elif 总分 >= -0.9:
        return 0.3, '跷跷板 — 谨慎持仓'
    elif 总分 >= -2.9:
        return 0.1, '共振下跌 — 空仓观望'
    else:
        return 0.0, '强制空仓 — 等待信号'
```
