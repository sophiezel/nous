# Sperandeo 交易体系

## 定义

Victor Sperandeo（维克多·斯波朗迪）的交易体系以**风险管理为核心、道氏理论为框架、趋势跟踪为执行基础**。其著作《专业投机原理》系统阐述了这一方法论。Sperandeo 在 1978-1989 年间创造了连续 12 年盈利（无亏损年度）的记录，平均年化回报率 70.7%。

体系的核心主张：**保本第一、一致性地执行经过验证的规则、将心理学与技术分析融为一体。**

## 体系架构

### 第一层：哲学基石

1. **保本第一** — 资本保全永远优先于盈利。亏损是交易的一部分，但灾难性亏损不可接受
2. **一致性** — 成功不取决于单次正确，而取决于长期一致地执行一套正期望值系统
3. **概率思维** — 不追求完美预测，而是持续寻找概率对自己有利的交易机会
4. **了解自己** — 交易心理是整个体系不可分割的部分，源于 [[trading-psychology-fundamentals]]

### 第二层：分析框架 — 道氏理论实战化

详见 [[market-timing-dow-theory]]。Sperandeo 将道氏理论从理论层面转化为具操作性的实战工具：

- **主要趋势识别**：通过趋势线和道氏高低点判定
- **次级折返验证**：要求至少 1/3 至 2/3 回撤
- **成交量确认**：趋势方向应伴随成交量放大

### 第三层：入场/出场信号 — 两个核心模式

#### 2B 法则

Sperandeo 最具原创性的贡献。2B 法则描述一种**假突破反转**形态：

- **上升趋势中**：价格突破前高点后，立即（通常在 1-2 天内）跌回前高点之下 → 卖出信号
- **下降趋势中**：价格跌破前低点后，立即回升至前低点之上 → 买入信号

命名由来：趋势中的第二个高点/低点（B 点），其被突破本应确认趋势延续，但价格随即折返——即第二次突破尝试失败（2B = second B-point failure）。

```
上升趋势中的 2B（顶）：
     B
    / \          ← 假突破后反转
   /   \
  A     \
 /
/ → 跌破前低确认

下降趋势中的 2B（底）：
\
 \   A
  \ / \
   B   \       ← 假跌破后反转
        \
         \ → 升破前高确认
```

**2B 法则的操作规则**：
- 假突破后立即反向穿越前一极值点时入场
- 止损设在假突破的极端价格外侧
- 成功率高的 2B 信号通常伴随成交量异常（假突破方向缩量，反转方向放量）

#### 1-2-3 准则

用于系统化确认趋势反转的三步验证：

1. **趋势线突破（1）**：价格有效突破原有趋势线
2. **极点测试失败（2）**：价格回测前高（上升趋势中）或前低（下降趋势中），但无法创出新高/新低——这是趋势动能衰竭的关键证据
3. **中继点突破（3）**：价格进一步突破最近的回调低点（上升趋势中）或反弹高点（下降趋势中）——确认趋势已反转

```
上升趋势反转为下降：
     high
     /\
    /  \ 1 (趋势线突破)
   /    \
  /      \ 2 (无法创新高)
 /        \
/          3 (跌破前回调低点 → 确认)
           ↓
```

**1-2-3 准则的操作规则**：
- 标准入场在条件(3)满足后
- 激进交易者可在条件(2)满足后（前极点测试失败时）入场，此时风险回报比最优
- 保守交易者等三个条件全部确认后再入场

### 第四层：风险管理规则

Sperandeo 的风险管理是其体系区别于纯技术分析体系的关键：

1. **单笔最大风险**：任何单笔交易亏损不超过总资金的 1-2%
2. **相关性控制**：同时持仓品种的相关性必须纳入总风险计算
3. **金字塔加仓**：只在初始仓位盈利后再加仓，且每次加仓量递减
4. **止损纪律**：每笔交易入场前必须设好止损，止损只向有利方向移动
5. **风险回报比**：至少 1:3 的风险回报比才考虑入场

## 核心交易原则汇总

1. **保本第一** — 生存是交易的根本
2. **顺势而为** — 道氏理论确定的主要趋势方向是唯一应该交易的方向
3. **等待确认** — 不预测顶部/底部，用 1-2-3 准则等确认信号
4. **2B 法则抓反转** — 假突破往往是最佳的反转入场时机
5. **严格风控** — 1-2% 单笔风险上限，不可妥协
6. **心理稳定** — [[emotional-discipline]] 是执行系统的前提；恐惧和贪婪是最大的敌人
7. **持续学习** — 记录每笔交易、复盘、迭代改进
