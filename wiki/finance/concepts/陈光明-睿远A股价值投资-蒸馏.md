# 陈光明（睿远基金）— A股价值投资标杆

> **浓缩金句：** "价值投资不是买便宜的，是买好的。好的公司即使贵一点也会被成长消化。"

## 一、战绩概览

- 东方红资管时期：管的东方红4号年化约28%，从1000万做到超百亿
- 2018年创办睿远基金，首只公募一天募集700亿（配售比例7%）
- A股最受尊敬的价值投资者之一，风格极度稳定
- 低换手、长持有、深研究

## 二、核心理念：买好的，不是买便宜的

```
格雷厄姆式价值 → PE<10→买，PE>20→卖（基于价格）
陈光明式价值 → ROE>20+护城河→买，管它PE多少（基于质量）
```

**陈光明的三好标准：**

```
好行业 → 行业空间大、格局稳定、不会被颠覆
好公司 → ROE>20%、护城河清晰、管理层靠谱
好价格 → 不要求绝对便宜，但要求在合理区间
```

> "我不怕买贵一点，我怕买错。买贵了最多输时间，买错了永远回不来。"

## 三、可量化规则

### 行业筛选
- 行业空间：市场规模 > 1000亿（才有大公司生长的土壤）
- 行业增速：> GDP增速 × 1.5（行业在扩张而非萎缩）
- 竞争格局：CR3 > 40%（不是红海厮杀）

### 公司筛选
- ROE > 20% 且连续5年 > 15%
- 毛利率 > 30%（有定价权）
- 经营现金流/净利润 > 0.8（利润真）
- 管理层持股 > 3%（利益绑定）

### 估值容忍
- PE < 行业平均 × 1.2（略高于行业可以接受）
- PB < 5（A股）/ < 3（港股）
- PEG < 1.2（增速能覆盖估值）

## 四、与鳄鱼派融合

- 🟢 契合：长持有、不频繁交易、重仓集中
- 🟡 差异：陈光明对估值更宽容（鳄鱼派更注重便宜）
- 系统注入：作为 screener 的"品质把关层"——先过陈光明的品质测试，再过信号共振
