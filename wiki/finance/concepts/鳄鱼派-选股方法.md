# 鳄鱼派选股方法体系

## 板块赛马模型（头等马 vs 黑马）

**来源**: 文章#24 (2026.4.20), 文章#30 (2026.4.10), 文章#31 (2026.4.9)

通过日K线位置和OBV指标将板块分为"头等马"（强势）和"黑马"（潜在转强），是每日板块筛选的固定框架。

### 量化条件

| 类型 | 条件 | 后续演化 |
|------|------|---------|
| 头等马 | 日K站上60日均线 | 涨多歇一歇震荡 → 继续上（最优盘面） |
| 黑马 | 日K在60日线之下，但OBV上穿其均线 | 连续2日站上60日线 → 晋级头等马 |
| 杂毛 | 日K在60日线之下，OBV未上穿均线 | 不参与 |

### 伪代码

```python
def horse_rank(板块):
    if 板块.收盘价 > 板块.ma(60):
        return '头等马'
    elif 板块.收盘价 <= 板块.ma(60) and 板块.obv > 板块.obv_ma:
        return '黑马'
    else:
        return '杂毛'

def promote_check(板块, days=2):
    """黑马连续N日站上60日线则晋级头等马"""
    if 板块.收盘价 > 板块.ma(60) for consecutive days >= days:
        return '晋级头等马'
```

### 应用场景
- 每日板块筛选，确定交易方向
- 头等马队伍扩大速度加快 = 市场健康
- 前期的头等马涨多歇一歇震荡 → 后续继续上 = 最优盘面结构

## 个股三层筛选法

**来源**: 文章#31 (2026.4.9)

先选强势板块 → 再在强势板块内选强势个股。

### 量化条件

| 风偏等级 | 策略 | 操作 |
|---------|------|------|
| 风偏高（龙头选手） | 做强势板块里最强的个股（龙头） | 追涨/博傻，止损6%-8% |
| 风偏适中 | 做与板块指数同步或稍强的个股 | 板块ETF或中军票 |
| 风偏低（保守派） | 不做后排比板块弱的个股 | 前期和中期阶段不碰弱势股 |

### 伪代码

```python
def stock_filter(板块, 风偏等级):
    强势板块 = [b for b in all_sectors if b.close > b.ma(60)]
    if 风偏等级 == '高':
        return 最强_龙头(强势板块)   # 涨幅/成交额/涨停强度
    elif 风偏等级 == '中':
        return 板块内中等偏强(强势板块)  # 与板块指数同步
    elif 风偏等级 == '低':
        return None  # 或只做板块ETF，不做后排弱股
```

## 四类买点体系

**来源**: 文章#14 (2026.5.7), 文章#91 (2026.1.7)

四种标准化入场模式，是鳄鱼派核心方法论。

### 买点分类

| 编号 | 买点名称 | 入场条件 | 止损 | 止盈 | 适用场景 |
|------|---------|---------|------|------|---------|
| 1 | 博傻买点 | 放量加速追入 | 6%-8% | 15%-20% | 主升浪确认 |
| 2 | 分歧转一致买点 | 当日尾盘日K新高入场，或次日继续强势入场 | 6%-8% | 15%-20% | 板块分歧后重新走强 |
| 3 | 分歧买点 | 趋势板块/个股回调震荡，未继续新低时入场 | 5% | 6%-8% | 强势板块震荡期 |
| 4 | 初期赛马小趋势 | 止跌不久、形态开始走好，用均线/OBV筛选 | 视个股 | 视个股 | 市场刚止跌修复 |

### 市场阶段适配

```python
def choose_buy_type(市场阶段):
    if 市场阶段 == '刚止跌修复':
        return ['分歧转一致', '初期小趋势']
    elif 市场阶段 == '修复一段时间，强势板块震荡':
        return ['强势板块分歧买点', '新板块分歧转一致']
    elif 市场阶段 == '逼近前高未突破':
        return ['初期小趋势', '分歧转一致']
```

## 一/二/三类买点（个股技术形态）

**来源**: 文章#91 (2025.1.7), 文章#50 (2026.3.12)

板块逻辑够硬时，技术形态上的三类标准买点。

### 量化条件

| 买点类型 | 描述 | 仓位建议 | 注意事项 |
|---------|------|---------|---------|
| 一类买点（左侧底部） | 股价经历大幅下跌后初步止跌 | 仅可打底，不可重仓 | 左侧，需耐心 |
| 二类买点（回调二买） | 回调不破前低，形成W底或头肩底 | 最好把握的买点 | 需要有耐心等待 |
| 三类买点（右侧突破） | 突破前高或平台压力位确认 | 可加仓 | 需要突破确认 |

### 伪代码

```python
def buy_point_class(price_series):
    前低 = local_min(price_series, window=20)
    当前 = price_series[-1]
    if 当前 < 前低:  # 还在探底
        return '左侧观察'
    elif 当前 <= 前低 * 1.05:  # 接近前低不破
        return '二类买点区'
    elif 当前 > 前高(price_series, window=60):  # 创新高
        return '三类买点（突破确认）'
    else:
        return '一类买点区（左侧底部区域）'

# 错过三类买点后的应对
if 错过三类:
    耐心等新的二类或一类买点出现
```

## 突破强度分类

**来源**: 文章#24 (2026.4.20)

### 量化条件

| 类型 | 条件 | 信号强度 |
|------|------|---------|
| 强突破 | 涨停 或 涨幅 ≥ 5% | 强势买入信号 |
| 弱突破 | 小阳线新高 或 站稳均线 | 温和买入信号 |

```python
def break_strength(stock, date):
    change = (stock.close - stock.pre_close) / stock.pre_close
    if change >= 0.095:  # 涨停或接近涨停
        return '强突破(涨停)'
    elif change >= 0.05:
        return '强突破(涨幅≥5%)'
    elif stock.close > stock.ma(60) and change > 0:
        return '弱突破(站稳均线)'
    elif stock.close > stock.high_60d:
        return '弱突破(小阳线新高)'
    else:
        return '无效突破'
```

## 低风偏 vs 高风偏品种

**来源**: 文章#69 (2026.2.5)

按风险偏好划分品种，长线配置的基础框架。

### 品种分类

| 类型 | 特征 | 代表品种 |
|------|------|---------|
| **低风偏（低风险低弹性）** | 防御性、稳定分红、波动小 | 沪深300ETF, 中证500ETF, 红利ETF, 自由现金流ETF, 电力ETF, 消费ETF, 物流ETF, 养殖ETF, 保险行业 |
| **高风偏（高风险高弹性）** | 成长性、波动大、爆发力强 | 中证1000ETF, 创业板ETF, 芯片ETF, 科创50ETF, 恒生互联网ETF, 恒生科技ETF, 有色金属ETF, 化工ETF, 创新药ETF, 光伏ETF, 房地产ETF, 证券ETF |

### 应用场景
- 长线配置的基础框架
- 根据个人风险承受能力搭配组合比例

## 哑铃策略 — 盾牌+长矛

**来源**: 文章#59 (2026.2.27)

做行业配置时，拔估值传统行业为安全垫（盾），科技为弹性（矛），均配双管齐下。

### 经典配对

| 盾牌（安全垫） | 长矛（弹性） |
|--------------|------------|
| 金属化工 | 半导体 |
| 消费 | 软件 |
| 红利 | 科创 |

### 伪代码

```python
def dumbbell_allocation(总资金, 风险偏好):
    """哑铃配置：盾牌长矛各50%为基础，根据风险偏好微调"""
    盾牌比例 = 0.5
    长矛比例 = 0.5
    if 风险偏好 == '保守':
        盾牌比例, 长矛比例 = 0.7, 0.3
    elif 风险偏好 == '激进':
        盾牌比例, 长矛比例 = 0.3, 0.7
    return {
        '盾牌': [
            ('金属化工ETF', 总资金 * 盾牌比例 * 0.5),
            ('消费ETF', 总资金 * 盾牌比例 * 0.5),
        ],
        '长矛': [
            ('半导体ETF', 总资金 * 长矛比例 * 0.5),
            ('科创ETF', 总资金 * 长矛比例 * 0.5),
        ]
    }
```

## 主线判定标准

**来源**: 文章#50 (2026.3.12)

板块能否成为主线，需同时满足两个条件。

### 两大核心要素

| 要素 | 条件 | 量化指标 |
|------|------|---------|
| 资金认可 | 沪深300成分股 + 涨停个股中机构与游资共振 | 板块内涨停股数、龙虎榜机构席位 |
| 宏大叙事 | 未来可能还有资金持续买入的逻辑 | 政策面、技术面、市场的故事可讲性 |

### 伪代码

```python
def is_main_line(板块):
    资金认可 = False
    宏大叙事 = False
    
    # 条件1: 资金认可
    hs300_stocks = 板块.成分股 ∩ 沪深300
    涨停股 = [s for s in hs300_stocks if s.涨停]
    if len(涨停股) >= 3 and 机构游资共振(涨停股):
        资金认可 = True
    
    # 条件2: 宏大叙事
    if 板块.政策热度 > 阈值 and 板块.故事逻辑_可验证:
        宏大叙事 = True
    
    return 资金认可 and 宏大叙事
```

## 长线调仓三大原则

**来源**: 文章#58 (2026.3.2)

### 原则

1. **仓位上限原则**: 各板块仓位独立，规划20%上限不打穿
2. **止盈资金去向原则**: 止盈仓位只能投入原板块或新板块，不能加仓已打满的浮亏板块
3. **去弱vs加强原则**: 去弱加强适合短线投机，长线应坚持基本面（去强加弱/独立对待）

### 伪代码

```python
def rebalance_long(板块, 仓位信息):
    """长线调仓"""
    for 板块名, 信息 in 仓位信息.items():
        if 信息.仓位比例 >= 0.20:
            # 板块A仓位已达上限
            if 信息.浮盈 > 止盈目标:
                执行止盈(板块名, 止盈仓位)
                # 止盈资金只能投入原板块或新板块
                止盈资金 = 信息.止盈金额
            elif 信息.浮亏 > 止损目标:
                执行止损(板块名)
            # 不可用其他板块的止盈资金加仓A
        
        # 长线坚持基本面，不因短期强弱调仓
        if 信息.基本面未恶化:
            continue  # 持有
```
