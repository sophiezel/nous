# 彼得·林奇 — PEG+六类成长股

> **浓缩金句：** "寻找 PEG < 1 的成长股。任何普通人用生活常识都能选出好股票。"

## 一、补什么缺口

**补：中小成长股缺口。** 已有体系偏大盘蓝筹（邱国鹭龙头、蒋锦志PE<15大票、林园垄断消费），缺少中小市值成长股的挖掘框架。林奇管的麦哲伦基金高峰期持仓1400只股票，是成长股挖掘的极致大师。

## 二、核心理念：六类股票分类法

林奇把所有股票分成六类，每类操作方式完全不同：

| 类型 | 特征 | 预期收益 | 操作策略 | 典型 |
|------|------|---------|---------|------|
| **缓慢增长** | 增速<5%,高股息 | 股息+5% | 当债券持有 | 银行、电力 |
| **稳定增长** | 增速8-12% | 年化10-15% | 低买高卖做波段 | 茅台、伊利 |
| **快速增长** | 增速20%+ | 年化20-40% | 重仓持有不卖 | 拼多多、宁德 |
| **周期股** | 增速波动大 | 行业复苏时翻倍 | 行业底部买顶部卖 | 信义光能 |
| **困境反转** | 亏损或微利 | 反转成功翻3-10倍 | 等反转信号确认 | 美团? |
| **隐蔽资产** | 资产价值远超市值 | 价值重估翻倍 | 算清资产底价 | 破净央企 |

**关键洞察：不同类型的股票不能互相比较——周期股不能要求增速，快速增长不能要求高股息。**

## 三、PEG — 成长股估值核心

林奇最著名的贡献：

```
PEG = PE(TTM) / 盈利增速(%)

PEG < 0.5 → 极度低估 → 重仓
PEG < 1.0 → 合理偏低 → 买入
PEG = 1.0 → 合理     → 持有
PEG > 1.5 → 偏贵     → 减仓
PEG > 2.0 → 太贵     → 卖出
```

**盈利增速取：过去3年平均增速 × 0.7（保守打折）+ 未来2年一致预期 × 0.3**

## 四、可量化规则

### 股票类型自动分类
```python
def lynch_classify(symbol):
    g = earnings_growth_3y(symbol)
    p = dividend_yield(symbol)
    
    if is_cyclical(symbol):
        return "周期股"
    if eps(symbol) < 0:
        return "困境反转"
    if book_value(symbol) * 1.5 < market_cap(symbol):
        return "隐蔽资产"  # 市值<净资产1.5倍
    if g > 0.20:
        return "快速增长"
    if g > 0.08:
        return "稳定增长"
    if p > 0.03 and g < 0.05:
        return "缓慢增长"
    return "未分类"
```

### PEG筛选
```python
def lynch_peg_filter(symbol):
    pe = pe_ttm(symbol)
    g_past = earnings_growth_3y(symbol)
    g_future = consensus_growth_2y(symbol)
    g = g_past * 0.7 + g_future * 0.3
    if g <= 0: return None
    peg = pe / (g * 100)
    return {"peg": peg, "signal": "buy" if peg < 1.0 else "pass"}
```

## 五、系统注入

林奇作为**成长股专属通道**：

```
大盘蓝筹 → 蒋锦志+邱国鹭通道
成长股   → 林奇通道（PEG<1 + 六类分类）
周期股   → 邓晓峰通道（景气度判断）
消费垄断 → 林园通道
```

每条通道有自己的进入门槛和退出规则，互不串扰。**一个标的通过哪条通道，就按那条通道的规则执行。**
