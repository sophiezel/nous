## 一、克罗其人：利弗莫尔最忠实的执行者

斯坦利·克罗是杰西·利弗莫尔的**狂热追随者**，但他做了一件利弗莫尔没有做的事——**将利弗莫尔的天才直觉系统化为可执行的规则和策略**。

| 克罗本人 | 关键数据 |
|---|---|
| 1960年代入行（美林公司起步） | 营业员→分析师→清算公司总裁 |
| 1970年经典战绩 | 18,000美元本金三年滚到100万美元（自己+合伙人各一份） |
| 1975年"退休"（41岁） | 五年后83年重返市场 |
| 核心哲学 | **策略 > 系统 > 预测** |

克罗的自画像：
> "我不是在预测市场，而是在**追踪趋势**。一流的策略+平庸的系统 > 平庸的策略+一流的系统。"

## 二、长线持仓哲学（核心中的核心）

### 2.1 根本信念：趋势是你的朋友

克罗反复强调的六大战术（第一章）：

| # | 战术 | 精要 |
|---|---|---|
| 1 | **只在有趋势时进场** | 市场展现强烈趋势特性，或正在酝酿趋势，才放手进场 |
| 2 | **选对进场点** | 前一个趋势显著反转处；横向整理突破处；主趋势中的技术性回调 |
| 3 | **绝不轻易弃船** | "顺势而为"的仓位可能有巨大利润，千万不要轻易平掉 |
| 4 | **金字塔加码** | 趋势有利时，在技术性反转处加仓 |
| 5 | **趋势反转才离场** | 用客观分析确认趋势已反转，行动要快 |
| 6 | **做错要快跑** | 立刻认赔，不要"熬下去" |

### 2.2 持仓时间：不是天数，是趋势的长度

> **"只要市场对你有利，不管多久，仓位都要继续抱下去。"**

克罗的经典持仓案例：

- **黄豆放空17个月**：1984年6月11日放空 → 1985年12月6日回补，每口利润超10,000美元
- **糖多头持仓5年+**：1967年在2.00买入 → 经历短暂跌到1.33（浮亏1/3）→ 1969年多头启动 → 1974年涨到60.00
- **小麦多头**：从3.60做到4.90，期间三次加码，七位数字利润

### 2.3 "钱是坐着赚来的，不是靠操作赚来的"

这是克罗贴在电话上的利弗莫尔名言。他的意思是：

> **看对市场方向不算本领，能坐住不动才是真本事。**
>
> 大多数人在多头市场老早就做多，空头市场老早就放空，但他们没赚到钱——因为他们坐不住。

### 2.4 克罗的"坐功"训练法

- 电话上贴利弗莫尔名言："钱是坐着赚来的"
- 桌子上放一本航船杂志转移注意力
- 实在受不了就暂时离开办公室出去走走

## 三、金字塔加仓策略

### 3.1 核心原则

1. **只在赚钱的仓位上金字塔加码**
2. **加仓必须在技术性回调（顺势方向）时进行**
3. **加仓量递减**（正金字塔，不是倒金字塔）

### 3.2 经典正面案例：小麦多头（1974年）

| 步骤 | 价位 | 动作 |
|---|---|---|
| 初始建仓 | 3.60 | 买入 |
| 第一次加码 | 3.85附近 | 技术性回档处加码 |
| 第二次加码 | 4.40附近 | 反转后加码 |
| 平仓 | 4.90 | 反弹失败，全部出清 |

### 3.3 经典反面案例：可可豆多头

一群专业操作者在12.00买入可可豆，预测涨到20.00+。
- **错误操作**：价格从12.00涨到15.00途中，**不断加大加码金额**（形成倒金字塔）
- **结果**：第一次回档，帐户巨亏，恐慌清仓
- **然后在多头回调处放空**，彻底被轧
- 最终：**价格涨到22.00，但他们亏了约20万美元**

> **教训**：加码一定要是正金字塔，不能是倒金字塔！

### 3.4 加码策略总结

| ✅ 正确做法 | ❌ 错误做法 |
|---|---|
| 赚钱的仓位才加码 | 亏损的仓位摊平 |
| 回调/反弹时加码（顺势方向） | 突破追高加码 |
| 加码量递减 | 加码量递增（倒金字塔） |
| 配合止损保护 | 无止损加码 |

## 四、止损/止盈纪律

### 4.1 止损三大准则

**准则一：亏损必须设限，且客观设定**

克罗建议：**以交易所保证金的一定比率设定止损**（如50%-100%）。
- 这样做的好处：止损点会远离大多数投机客群集的位置，不容易被专业大户"猎杀"
- 避免主观判断："我觉得还能扛一扛"

**准则二：浮亏到影响睡眠，就是"太过分"了**

> 华特兹的名言被克罗引用："那你就卖掉你能够安睡为止。"

**准则三：第一笔损失是最便宜的损失**

### 4.2 止损与止盈的实战数据

克罗对数百位客户的调查显示（第18章）：

| 操作者类型 | 结果 | 平均每口亏损 | 平均每口盈利 |
|---|---|---|---|
| 金属制造商 | 原始资金105K → 亏损135K | $6,844 | $1,799 |
| 欧洲私人银行 | 100K → 剩54.5K | $4,156 | $255 |
| **成功的小额基金** | **18K → 130K（18个月）** | **$515** | **$1,020** |

关键差异：**成功者平均亏损仅为失败者的1/8~1/13！**

如果失败者将亏损限制在保证金的45%以内：
- 金属制造商：损失从$135,000降至$9,232
- 欧洲银行：损失从$45,000降至$6,719

### 4.3 止盈：移动止损法

克罗不使用"目标价"止盈，而是用**移动止损**：

> "不妨坐等市场自动把你带出场。设定'有效率'的停损点——随着市场对你有利，不断往前挪进停损点，直到最后碰到停损点出场为止。"

### 4.4 最重要的一条纪律：留强汰弱

> **"凡是有损失的，都要卖掉；有利润的，都要留着。"**

这条来自利弗莫尔，被克罗反复强调。但绝大多数人做反了：
- 赚了点小钱就急着平仓（怕利润回吐）
- 亏了死扛（希望反弹）
- 最终：**小赚大亏**

### 4.5 面对保证金催缴的正确做法

| ❌ 大多数人 | ✅ 正确做法 |
|---|---|
| 存入新资金"保卫"仓位 | 减仓，清掉亏损最大的仓位 |
| 平掉赚钱的仓位保留亏损的 | 保留赚钱的仓位，砍掉亏损的 |
| 希望能扛过去 | 客观面对：户头表现不好就别再投钱 |

## 五、真实交易案例深度解析

### 案例1：糖——耐心成就的超级大行情（第7章）

**时间**：1967-1974年  
**背景**：克罗刚过30岁，借了1万美元买交易所席位  
**操作**：
1. 1967年在**2.00**（每磅）建立大量糖多头仓位
2. 市场不涨反跌，一直跌到**1.33**——浮亏了1/3仓位
3. 克罗没有割肉，而是**继续持有**（但这是极特殊情况，因为他确信这是历史性低点）
4. 横盘整理了两年
5. 1969年多头市场启动
6. 1974年糖价涨到**60.00**——涨幅30倍

> **关键教训**：耐性+纪律+长远眼光。但注意：克罗敢于持有是因为他在历史性低点建仓（糖价低于麻袋成本+人工），且用了大量研究和分析支撑。

### 案例2：铜——技术面vs基本面的较量（第7章）

**时间**：1972年  
**操作**：
1. 克罗在48.00-50.00区间建立约350口铜多头仓位
2. 某银行家族后裔来访，拿出一份著名经济学家团队的报告：**供给过剩、需求疲软、至少再跌一年**
3. 克罗内心挣扎两天，最终决定**相信技术面**：市场走势告诉他价格正在稳住
4. 不久后，中国贸易团抵达伦敦，扫光了市场上的铜
5. 价格从50.00涨到100.00以上
6. **整个仓位赚了约130万美元**

> **关键教训**：当基本面和技术面分道扬镳时，**相信技术面**。价格创造消息，不是消息创造价格。

### 案例3：取暖油——利多消息不涨，就是多头信号（第6章）

**时间**：1985年7月  
**背景**：沙特石油部长雅曼尼宣布石油产量将加倍（重大利空）  
**操作**：
1. 所有人都在放空（"大户"、"业内人士"大规模做空）
2. 克罗的技术分析显示**应该做多**
3. 他无视所有利空消息和"内幕"，坚决做多
4. 市场确实先横盘几天，然后**强势突破上涨16美分**（每口6,700美元）
5. 空头被轧了一空

> **关键教训**：利空消息出来市场不跌反涨，说明空头陷阱，多头即将爆发。"要玩就要在真实的世界中玩。"

### 案例4：咖啡豆——等待突破的耐心（第3章）

**时间**：1985年7-10月  
**操作者**：克罗的朋友"乔"  
**操作**：
1. 咖啡豆在134.00-141.00区间横盘三个月
2. 乔下了双向委托单：突破141.60买入，跌破133.40卖出
3. 10月10日突破向上，141.60-141.80大量买入
4. 途中做了两次金字塔加码
5. 价格一路涨到**270.00**
6. 每口利润超14,000美元

> **关键教训**：横盘突破是最佳入场时机之一。简单（KISS）是最有效的。

### 案例5：黄豆——多次"逮到又错过"的惨痛教训（第10章）

**克罗的自嘲**：
1. 1972年，10.30买入黄豆油，11.30卖出——赚了一点，但价格后来涨到17.00
2. 3.19买入五月黄豆，3.22加码，3.24再加码，**3.36全部清掉**——就在黄豆创纪录多头启动之前！
3. 看着价格涨到8.59，"知道"要做头了，在8.58放空
4. 两周后被迫回补，**每口亏损15,930美元**
5. 市场最终在13.00做头——他早了两个月！

> **教训**：所有技术指标（除了一种）都显示超买可以做空，但那个被忽略的指标是——**"走势仍然向上！"**

## 六、与利弗莫尔思想的传承关系

克罗在第十六章专门写了一章"J.L.李佛摩这个人"。

### 6.1 克罗直接引用的利弗莫尔语录

| 利弗莫尔原话 | 克罗的应用 |
|---|---|
| "市场只有一个方向，不是多头或空头，而是**对的方向**。" | 全书的哲学基石，不要有执念 |
| "钱是**坐着赚来的**，不是靠操作赚来的。" | 贴在电话上，反复提醒自己 |
| "做棉花亏损了留在手里，小麦有利润却卖掉了……有损失还要摊平是最严重的错误。" | 留强汰弱的核心来源 |
| "看对市场正确的一边根本不算什么本领……能够做对事情又**能守住**的人不多见。" | 长线持仓的心理支柱 |
| "对我来说，赔钱是各种困难中最轻微的一个。**认赔亏损之后，赔钱再也不会困扰我。**" | 止损纪律的心理基础 |

### 6.2 克罗对利弗莫尔的超越

| 利弗莫尔（天才直觉型） | 克罗（系统执行型） |
|---|---|
| 靠天赋和直觉 | 靠系统和规则 |
| 没有留下可复制的系统 | 将哲学转化为可执行的策略 |
| 多次大起大落 | 强调风险管理为上 |
| 没有电脑 | 利用电脑趋势跟踪系统 |
| 交易是艺术 | 交易是**纪律+策略+系统** |

### 6.3 克罗的独特贡献

克罗在利弗莫尔思想基础上，增加了三个重要维度：

1. **策略优先于系统**："一流的策略+平庸的系统"优于"平庸的策略+一流的系统"
2. **客观化的趋势确认**：利用电脑系统、方向运动指数(DMI)、移动平均线等工具
3. **金字塔加码的具体规则**：量递减、只在回调加、顺势方向

## 七、克罗的完整交易系统框架

### 7.1 双重操作方法（第13章）

克罗独创的核心方法论——**顺势/逆势双重操作**：

**当市场处于横盘整理时**（占大部分时间）：
- 用**反趋势操作**：跌到区间下档买进，弹到上档卖出
- 用收盘停损点保护，设在区间外不远处

**当市场突破横盘区间时**：
- **清掉反势仓位，建立新的顺势仓位**
- 收盘价突破方向决定操作方向

适用条件：
- 先确定市场是横向整理（用方向运动指数DMI）
- 找出盘整区上档和下档
- 收盘价突破才确认，不理会盘中假突破

### 7.2 移动平均线系统的参数参考

霍克海马的研究（1970-1976年，13种商品）：

| 商品 | 最佳单均线天数 | 最佳双均线组合 |
|---|---|---|
| 白银 | 19天 | 13/26天 |
| 玉米 | 43天 | 12/48天 |
| 黄豆 | 55天 | 20/45天 |
| 铜 | 59天 | 17/32天 |
| 糖 | 60天 | 6/50天 |
| 可可豆 | 54天 | 14/47天 |

> 注意：胜率极低（20%-36%），但**盈亏比极高**——胜率低是趋势跟踪系统的正常特征。

### 7.3 仓位管理原则

- 每个期货仓位需有**2,000-4,000美元**作为后盾
- 操作频率要低，**比一般水准低**
- 顺势仓位不论多大都不嫌大；逆势仓位不论多小都嫌太多
- 一个投资组合中，当市场只有14%上涨、48%下跌时，做多仓位不应超过15%-25%

## 八、心理层面：赢家和输家的分野

### 8.1 投机客的悲叹

> "我看到市场按照我所分析的方向移动，而当我进场建立仓位之后，价格突然反转，往相反的方向走。"

这不是"他们"在针对你，而是**战术和进出时机不当**。

### 8.2 赢的渴望 vs 输的恐惧

克罗引述澳洲一位操作者的信：

> "纸面上的模拟操作中，只有赢的渴望；而实际的操作中，主要是输的恐惧。"

**输的恐惧导致**：
- 仓位过大
- 进出过于频繁
- 过早平掉赚钱仓位
- 死扛亏损仓位

### 8.3 希望与恐惧的错位

| 情绪 | 正确使用 | 错误使用 |
|---|---|---|
| **希望** | 希望赚钱的趋势继续 | 希望亏损的仓位反转 |
| **恐惧** | 恐惧亏损继续扩大（及时止损） | 恐惧利润回吐（过早止盈） |

### 8.4 赢家的正字标记

> "真正的专业操作者的正字标记，在于他们忍耐的力量——他们能够渡过不可避免的横逆，终而出人头地。"

> "重要的事情不是你怎么走红，而是你怎么复原。" —— Dennis Conner

## 九、对A股/港股波段操作的启示

### 9.1 可直接借鉴的核心原则

| 克罗原则 | A股/港股应用 |
|---|---|
| **趋势是你的朋友** | 只在大盘上升趋势中做多，下降趋势中空仓或做空（如有条件） |
| **长线持有，不轻易弃船** | 抓住主升浪，不要被日内波动洗出去 |
| **留强汰弱** | 加仓最强势的板块/个股；砍掉弱势股，不要补仓摊平 |
| **第一笔损失最便宜** | 破位就止损，不要等深套 |
| **不做预测，只做追踪** | 用均线系统（如20日/60日线）确认趋势，不是猜顶猜底 |

### 9.2 需调整的差异

| 差异点 | 期货（克罗的环境） | A股/港股 |
|---|---|---|
| 杠杆 | 6%保证金，极高杠杆 | 无杠杆（融资融券有但风险不同） |
| 双向交易 | 做多/做空同等便利 | 做空门槛高、标的有限 |
| 趋势持续性 | 商品趋势常持续数月到数年 | A股趋势周期更短，波动更大 |
| 仓位规模 | 可集中所有资金于一个市场 | 建议分散但不过度分散 |

### 9.3 具体策略建议

**长线趋势跟踪型（A股适用）**：
1. 用**周线图/月线图**确认大趋势方向
2. 只在均线多头排列时操作
3. 突破重要阻力位（如年线、前高）时建仓
4. 沿20日/60日均线做金字塔加码
5. 跌破关键均线即止损
6. **不要猜顶**，用移动止损保护利润

**波段操作型（A股/港股适用）**：
1. 识别明显的横盘整理区间
2. 区间下沿买入，上沿卖出（反趋势操作）
3. 突破区间则反向操作，顺势而为
4. 用收盘价确认突破，过滤日内假突破

### 9.4 克罗智慧在A股的心法总结

> 1. **不要因为专家看多就买，不要因为新闻利好就追**——价格已经消化了一切
> 2. **你最大的敌人不是市场，是你自己**——纪律>分析>预测
> 3. **赚钱的股票要抱紧，亏钱的要砍掉**——这和"价值投资补仓"完全不同
> 4. **牛市不言顶，熊市不言底**——顺势就好，不要猜
> 5. **"滑得比爬得快"** ——下跌比上涨快，做对方向的空头比多头赚得更快更稳

## 十、克罗的"金句"精选

1. **"市场只有一边，不是多头的一边，也不是空头的一边，而是对的一边。"**（利弗莫尔原话）
2. **"钱是坐着赚来的，不是靠操作赚来的。"**（贴在电话上的座右铭）
3. **"趋势是你的朋友。"**——但要真把趋势当朋友，不要只是嘴上说说
4. **"凡是有损失的，都要卖掉；有利润的，都要留着。"**
5. **"一流的策略和战术，加上平庸的操作系统，会比条件相反时操作得更好。"**
6. **"知者不言，言者不知。"**
7. **"带着一点小伤跑开的人，来日一定能活着赚大钱。"**
8. **"操作不当而跑得开的人，只要留一口气，改天还能再进场（并赚钱）。"**
9. **"价格创造消息，不是消息影响价格。"**
10. **"三个最重要的投机特质：纪律、纪律、纪律。"**
