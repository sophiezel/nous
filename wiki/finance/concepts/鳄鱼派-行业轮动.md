# 鳄鱼派行业轮动体系

## 春躁行情标准节奏模板

**来源**: 文章#59 (2026.2.27), 文章#93 (2025.1.5)

每年春躁行情的标准节奏框架。

### 时序三阶段

```
阶段1: 1-2个主线板块带头打高度（约2-4周）
       ↓
阶段2: 多数板块轮动上涨，赚钱效应扩散
       ↓
阶段3: 大金融 + 中字头 + 权重蓝筹补涨（尾声信号）
```

### 量化判断

```python
def spring_rally_stage(指数, 板块列表):
    """判断春躁行情所处阶段"""
    金融板块 = ['银行ETF', '证券ETF', '保险ETF', '中字头']
    主线板块 = get_top_sectors(板块列表, n=2)
    
    # 阶段3判断：大金融中字头补涨
    if all(均值涨幅(fin_sectors) > 均值涨幅(other_sectors)):
        return '阶段3-尾声信号'
    # 阶段2判断：多数板块轮动
    elif 板块上涨比例 > 0.6:
        return '阶段2-赚钱效应扩散'
    else:
        return '阶段1-主线打高度'
```

## 科技板块三梯队轮动模型

**来源**: 文章#19 (2026.4.27), 文章#14 (2026.5.7), 文章#2 (2026.5.25)

科技板块内部按梯队轮动，核心轮动框架。

### 梯队定义

| 梯队 | 对应板块 | 角色 | 特征 |
|------|---------|------|------|
| 第一梯队 | 通信、元件 | 火车头 | 持续新高 → 分歧走弱震荡 → 反弹 |
| 第二梯队 | 半导体、芯片 | 接力者 | 接住第一梯队流出资金，接力新高 |
| 第三梯队 | 软件、计算机、应用 | 补涨者 | 落后补涨 |

### 量化时序模型

```python
def tech_rotation(t1, t2, t3):
    """判断科技板块内部轮动状态"""
    t1_trend = trend(t1)  # '新高', '震荡', '回调'
    t2_trend = trend(t2)
    t3_trend = trend(t3)
    
    if t1_trend == '新高':
        return '第一梯队领涨阶段'
    elif t1_trend == '震荡' and t2_trend == '新高':
        return '资金切换至第二梯队接力'
    elif t3_trend == '补涨':
        return '第三梯队补涨-行情尾部'
```

### 两种演化路径

**延续方向（良性切换）**:
```
第一梯队分歧走弱 → 第二梯队接力新高 → 第二梯队反哺第一梯队
→ 第一梯队王者归来再新高 → 第三梯队加速补涨
```

**结束方向（不良切换）**:
```
第一梯队新高失败 → 第二梯队震荡 → 第三梯队补涨结束
→ 整体科技退潮
```

### 历史验证
- 过去一年A股从未成功实现一次良性的高低切无缝衔接
- 解铃还须系铃人：通信和元件不继续涨，短线情绪就不容易继续嗨
- 火车头板块调整2-3天后通常有反弹

## 增量行情电风扇轮动周期

**来源**: 文章#13 (2026.5.8), 文章#18 (2026.4.28)

增量行情进入疯狂轮动阶段后的规律。

### 量化条件

| 指标 | 描述 |
|------|------|
| 疯狂电风扇轮动 | 各板块轮流拉一遍 |
| 持续时间 | 约2周 → 市场选方向 |
| 演化路径1 | 轮动完直接结束 |
| 演化路径2 | 资金再推带头板块实现分歧转一致突破 |

```python
def fan_rotation_phase(days_since_start, 板块_轮动次数):
    """电风扇轮动判断"""
    if days_since_start >= 14 and 板块_轮动次数 > 8:
        # 2周各板块轮动一遍以上
        if 带头板块.趋势 == '新高':
            return '可能分歧转一致突破'
        else:
            return '可能结束，警惕回撤'
    elif 板块_轮动次数 >= 5:
        return '电风扇进行中'
    else:
        return '正常盘面'
```

## 大金融内部换帅规则

**来源**: 文章#14 (2026.5.7)

指数趋势行情中，大金融（证券）领涨品种的切换规则。

### 规则

| 阶段 | 允许换帅？ | 说明 |
|------|-----------|------|
| 初期（前2板） | ✅ 允许 | 不同证券领涨，赛马阶段 |
| 中后期 | ❌ 不允许 | 资金已大量介入无法轻易切换 |

```python
def financial_leader_switch(板数, 新龙头):
    if 板数 <= 2:
        return '允许换帅，赛马阶段'
    else:
        return '不能换帅，资金已深度介入'
```

### 应用场景
- 判断大金融行情持续性
- 中后期换帅 = 行情可能接近尾声

## 短线重仓条件

**来源**: 文章#33 (2026.4.7)

短线可以大干特干的必要条件。

### 两大条件（必须同时满足）

| 条件 | 量化指标 | 说明 |
|------|---------|------|
| 1. 大盘OBV右侧确认 | 大盘指数OBV上穿均线且不回落下穿 | 量价维度开启右侧 |
| 2. 大资金集中度 | 至少有一个日成交金额超千亿的板块/概念沿5日均线走趋势 | 大资金集中火力 |

### 伪代码

```python
def heavy_short_ready():
    condition1 = 大盘OBV > 大盘OBV_MA and not 大盘OBV_跌破均线
    condition2 = any(板块.日成交额 > 1000亿 and 板块.沿5日均线走趋势 for 板块 in all_sectors)
    
    if condition1 and condition2:
        return '可重仓短线'
    else:
        return '只能打游击，与量化斗智斗勇'
        # 一年中仅2-3个月适合重仓短线
```

## 资金切换困难规律

**来源**: 文章#20 (2026.4.24)

A股资金具有惯性，科技板块短期介入过深时，很难无缝切换到新板块当火车头。

### 规律

```
热门板块跌一跌 → 资金回流抢反弹（不是扎堆新板块）
```

### 新火车头孕育周期

| 阶段 | 参与资金 | 时间跨度 |
|------|---------|---------|
| 老火车头震荡稳住市场 | 市场整体 | 数天 |
| 机构抄底新板块打底 | 机构资金 | 数周 |
| 游资大户加入 | 游资+大户 | 数月 |

### 历史参考
- 2025年9-11月化工/金属在科技震荡中展露头角

## 板块赛马晋级加速信号（赚钱效应扩散）

**来源**: 文章#24 (2026.4.20), 文章#22 (2026.4.22)

### 量化条件

```python
def wealth_effect(头等马列表):
    """判断赚钱效应扩散程度"""
    新增头等马数 = count_new_promotions(头等马列表, window='1天')
    总头等马数 = len(头等马列表)
    
    if 新增头等马数 / 总头等马数 > 0.3:
        return '赚钱效应快速扩散，市场健康'
    elif 新增头等马数 > 0:
        return '赚钱效应缓慢扩散'
    else:
        return '赚钱效应停滞，需警惕'
```

### 最优盘面结构
- 前期的头等马涨多歇一歇震荡 → 后续继续上

## A股两大投资风格轮动

**来源**: 文章#79 (2026.1.22)

### 风格分类

| 风格 | 驱动力 | 典型板块 | 估值要求 |
|------|--------|---------|---------|
| 宏大叙事风格 | 政策驱动/故事舆论 | AI, 机器人, 航天 | 估值不重要 |
| 拔估值风格 | 经济情况/行业驱动 | 风光锂, 消费, 医药, 金属, 化工 | 估值很重要 |

### 历史周期
- 924以来本轮牛市: 宏大叙事为主
- 19-21年牛市: 拔估值风格为主
- 一个完整牛市周期中基本都会经历两种风格

```python
def current_style_judge(板块涨幅榜, 板块_pe):
    """判断当前市场主导风格"""
    宏大叙事板块 = ['AI', '机器人', '航天', '软件']
    拔估值板块 = ['消费', '医药', '金属', '化工', '风光锂']
    
    top_10 = get_top_sectors(涨幅榜, n=10)
    宏大计数 = sum(1 for b in top_10 if b.name in 宏大叙事板块)
    拔估值计数 = sum(1 for b in top_10 if b.name in 拔估值板块)
    
    if 宏大计数 > 拔估值计数:
        return '宏大叙事风格'
    else:
        return '拔估值风格'
```

## 指数三种演化路径（加速后）

**来源**: 文章#92 (2025.1.6), 文章#93 (2025.1.5)

指数放量大涨后的演化路径分析框架。

### 三种路径

| 路径 | 描述 | 发生频率 | 典型案例 |
|------|------|---------|---------|
| 1. 继续加速→过热 | 持续放量上攻至过热 | 少见 | 924行情 |
| 2. 加速后结束上涨 | 放量到~3.2万亿后结束 | **最常见** | — |
| 3. 加速后缩量震荡→再加速 | 缩量震荡/慢涨后再次放量加速 | 最理想 | 15年疯牛节奏 |

### 量化阈值

```python
def index_acceleration_path(成交量, 指数趋势):
    """判断指数加速后所处位置"""
    if 成交量 < 30000_0000_0000:  # < 3万亿
        return '还有溢价空间'
    elif 成交量 >= 30000_0000_0000:
        if 指数趋势 == '缩量震荡':
            return '路径3-可能再次加速（最理想）'
        elif 指数趋势 == '跌破趋势':
            return '路径2-可能结束上涨'
        else:
            return '到3万亿不一定结束，看具体信号'
```

## 主线判定2025年补充规则

### 主线缺失=电风扇轮动
**来源**: article_138 (2025.5.20), article_139 (2025.5.21)
- "没主线，没增量资金"→市场疯狂电风扇轮动
- 游资疯狂抱团→最后疯狂熄火→高标熄火→游资边打边退
- 散户一割就拉，一追就砸→场外观望资金不敢进来

### 双主线/一超多强
**来源**: article_167 (2025.9.24)
- 二波行情特点: 双主线、一超多强
- "科技吃独食"不会持续，需要切换

### 主线赛马押注
**来源**: article_144 (2025.7.10)
- "光伏和PCB，今天光伏胜出，PCB被PK了下去"
- 主线赛马: 押对了吃肉，压错了止损走人

### 高低切换信号
**来源**: article_153 (2025.10.30)
- 盘面资金开始持续切换的苗头→可以适当出手
- **暴力切换风险**: 大部分资金突然往低位切→引发被动砍仓和基金赎回→震荡幅度大
- **温柔切换**: 高位慢慢跌，低位慢慢涨→波动小

### 杠杆资金周期
**来源**: article_155 (2025.10.16)

625摔杯→杠杆资金大量涌入→大票领涨(权重牛)

→市场风格切换→小票/妖股

## 2026.5.27–7.15 轮动增量

### 老循环 vs 新循环
**来源**: article_542
- 老: 科技领涨缩量→跌后弱切换→科技反弹回流→其他跌
- 新(最佳): 科技弱/震荡→非科技轮动出火车头→放量普涨科技修复→新火车头+金融带指数新高

### 巨震 / 鲸落万物生
**来源**: article_550–552
- 巨震=科技资金大规模流向其他板块（内部重构），非单纯指数大跌
- 解铃还须系铃人：流动性/情绪/基本面杀跌分别用对应方式修复

### 见底路径与磨底形态
**来源**: article_545, 547
- 50见底→300/500→1000/2000→再回50；上证50过弱则循环不起
- **U优于V**：V易招飞行员；震荡走U更长久

### 全面切换确认
**来源**: article_557–567
- 切换初期不宜过早押新主线；科技未做头则新主线难出头
- 金币修复+炸弹去杠杆过半后再谈全面切换
