# 鳄鱼派跨市场传导体系

## A股与美股映射规律

**来源**: 文章#13 (2026.5.8)

A股大部分时候是美股的映射，但只学了一半——抱团学得登峰造极。

### 映射差异

| 市场 | AI应用企业 | 特征 |
|------|-----------|------|
| 美股 | 科技扩散到下游应用（软件补涨） | 完整的产业链映射 |
| A股 | 缺少AI应用企业（金山办公、科大讯飞、恒生电子除外） | 只有抱团学到位 |
| 港股 | 实打实的AI应用企业：腾讯、阿里、网易、商汤、金蝶 | 弥补A股缺口 |

### 量化判断

```python
def us_mapping_effect(a_sector, us_sector):
    """判断A股是否跟随美股映射"""
    if us_sector.trend == '上涨扩散到应用':
        if 'AI应用' in a_sector.related_concepts:
            return 'A股可能跟随，但仅限少数个股'
        return 'A股缺少映射标的，炒作时间较短'
    return '正常跟随'
```

## AI运用跨市场验证

**来源**: 文章#13 (2026.5.8)

AI运用炒作的持续性取决于港股和A股的配合。

### 组合条件

| 港股表现 | A股表现 | AI应用持续性 |
|---------|---------|------------|
| 港股炒权重 + A股炒题材 | 结构更长更持久 | ✅ 高持续性 |
| 仅A股炒题材 | 炒作时间较短暂 | ❌ 低持续性 |

### 伪代码

```python
def ai_app_persistence(港股_状态, A股_状态):
    if 港股_状态 == '权重上涨' and A股_状态 == '题材炒作':
        return '高持续性 — 港股权重+ A股题材'
    elif A股_状态 == '题材炒作' and 港股_状态 != '权重上涨':
        return '低持续性 — 仅A股单边炒作'
    else:
        return '中等持续性 — 需进一步观察'
```

## A股与国际市场（黄金/原油）4阶段联动规律

**来源**: 文章#48 (2026.3.16)

A股市场与国际市场（以黄金/原油为例）的联动规律，明确的4阶段模型。

### 四阶段模型

```
阶段1: 突发事件国际涨10% → A股先飙20-50%（超涨）
       ↓
阶段2: 国际涨势变缓 → A股先急跌杀多头，再急涨杀空头
       ↓
阶段3: 国际震荡 → A股疯狂扩散，杂毛补涨，前期大涨开始跌
       ↓
阶段4: 国际小幅下跌 → A股恐慌踩踏，集体大跌甚至跌停潮
```

### 量化模型

```python
def international_4stage(国际_日涨幅, 国际_趋势, A股_板块涨幅):
    """判断A股与国际联动所处的阶段"""
    黄金涨幅 = 国际_日涨幅.get('黄金', 0)
    A股_黄金板块 = A股_板块涨幅.get('黄金板块', 0)
    
    if 黄金涨幅 > 0.1 and A股_黄金板块 > 0.2:
        return '阶段1: A股超涨阶段'
    elif 黄金涨幅 > 0 and 黄金涨幅 < 0.05 and A股_黄金板块 > 0:
        if abs(A股_黄金板块 - 黄金涨幅) > 0.1:
            return '阶段2: 急跌急涨博弈阶段'
        else:
            return '阶段3: 扩散补涨阶段'
    elif 黄金涨幅 < 0 and A股_黄金板块 < -0.05:
        return '阶段4: 恐慌踩踏阶段'
    
    return '常规联动'
```

## 港股科技买点 — 腾讯沽空占比

**来源**: 文章#26 (2026.4.16)

通过腾讯沽空占比判断港股科技是否从反弹转为反转。

### 量化条件

| 指标 | 数值 | 含义 |
|------|------|------|
| 沽空均值 | ≈ 13%（近半年回测数据） | 基准参考线 |
| 数据来源 | 东财免费获取 | 免费可用 |
| 越反弹沽空占比越减少 | 出局空头越多 | 上涨越健康 |

### 伪代码

```python
def tencent_short_reversal():
    """通过腾讯沽空占比判断港股科技是否反转"""
    当前沽空占比 = get_short_ratio('0700.HK')  # 腾讯
    历史均值 = 0.13  # 近半年回测
    
    if 当前沽空占比 < 历史均值 and 当前沽空占比.趋势 == '下降':
        # 越反弹沽空占比越少 → 空头在出局
        return '反转确认 — 空头出局，上涨健康'
    elif 当前沽空占比 < 历史均值:
        return '反弹中 — 沽空低于均值，继续观察'
    elif 当前沽空占比 > 历史均值:
        return '空头拥挤 — 不宜重仓'
```

## 国内火播海外，海外火播国内

**来源**: 文章#87 (2026.1.13)

长线踩节奏的方式：A股火热时播种海外ETF，海外火热时播种A股。

### 逻辑

```
A股火热 → 人们忽略海外ETF → 溢价被压低 → 具有性价比 → 播种海外
海外火热 → 人们忽略A股 → A股被低估 → 具有性价比 → 播种A股
```

### 历史数据
- 前两年A股低迷时海外ETF溢价高达20-30%
- A股火热时海外ETF溢价被压低甚至折价

### 伪代码

```python
def cross_market_planting():
    """跨市场播种策略"""
    if A股_情绪 > 0.8:  # A股火热
        海外ETF_溢价 = get_premium('海外ETF')
        if 海外ETF_溢价 < 0.05:  # 溢价低甚至折价
            return '买入海外ETF — 性价比高'
    
    if 海外_情绪 > 0.8:  # 海外火热
        A股_估值 = get_valuation('沪深300')
        if A股_估值_PE_percentile < 0.3:  # A股低估
            return '播种A股 — 性价比高'
    
    return '等待机会'
```

## 日债/美债宏观预警

**来源**: 文章#3 (2026.5.22), 文章#2 (2026.5.25)

10年期日债利率和美债利率处于预警区间时会引发全球流动性担忧。

### 量化条件

| 指标 | 预警条件 | 影响 |
|------|---------|------|
| 10年期日债利率 | 处于"预警区间" | 影响全球金融市场流动性 |
| 基差飙升 | 与基差飙升并列出现在拥挤度确认信号中 | 系统性风险信号 |

### 应用场景
- 判断系统性风险
- 出现在交易拥挤度确认信号中（与基差飙升并列）

```python
def macro_risk_warning(日债利率, 美债利率, 基差):
    """宏观风险预警判断"""
    日债预警 = is_in_warning_zone(日债利率, market='japan_10y')
    美债预警 = is_in_warning_zone(美债利率, market='us_10y')
    
    if (日债预警 or 美债预警) and 基差 > 97:
        return '🔴 宏观预警 — 全球流动性风险'
    elif 日债预警 or 美债预警:
        return '🟡 关注 — 利率处于预警区间'
    else:
        return '🟢 正常'
```

## 港股/A股共性 — 杀恐慌买点

**来源**: 文章#69 (2026.2.5)

港股杀恐慌时，看资金流向判断谁在买谁在卖。

### 量化条件

| 指标 | 使用方法 |
|------|---------|
| ETF份额流向 | 恐慌时看份额是否增加 |
| 南向资金 | 恐慌时南向资金是否净买入 |
| 方法论 | 段永平：不知道大家在恐慌什么？又买了一点 |

### 伪代码

```python
def panic_buy_point(市场, 恐慌指标):
    """判断是否为杀恐慌买点"""
    if 市场 == '港股':
        ETF_份额变化 = get_etf_flow('港股科技ETF')
        南向资金 = get_southbound_flow()
        
        if ETF_份额变化 > 0 and 南向资金 > 0 and 恐慌指标 > 阈值:
            return '杀恐慌买点 — 聪明钱在买入'
    
    elif 市场 == 'A股':
        if 恐慌指标 > 阈值 and 成交量 > 均值 * 1.5:
            return '恐慌买点 — 逆向布局时机'
    
    return '常规波动，非恐慌买点'
```

## 独立王国 — A股不受外围干扰的两种场景

**来源**: 文章#80 (2026.1.21)

A股有时候会走出独立于外围的行情。

### 两种独立场景

| 场景 | 条件 | 背后逻辑 | 例子 |
|------|------|---------|------|
| 科技独立 | 科技逻辑硬 + 后台硬（大基金） | 国产替代/自主可控，不受外围影响 | 半导体独立行情 |
| 工具独立 | 工具板块（大金融） | 基本面/经济学原理失效，受龙哥调控 | 银行/证券护盘 |

### 判断逻辑

```python
def is_independent(板块, 外围利空):
    """判断A股是否不受外围影响"""
    if 板块 in ['半导体', '芯片', '信创', 'AI']:
        if 大基金_支持 and 国产替代逻辑():
            return True  # 科技独立
    elif 板块 in ['银行', '证券', '保险']:
        if 龙哥_调控信号():
            return True  # 工具独立
    return False  # 受外围影响
```

## 宏观数据指标解读（2026-05-27增量补充）

### M2增速=市场水位
**来源**: 多篇复盘(article_1, article_4, article_26, article_30, article_32等)
- M2增速上升 → 流动性宽松，利好股市
- M2增速下降 → 流动性收紧，股市承压
- M2增速与GDP增速差(超发货币) → 资产价格膨胀空间
- **鳄鱼派用法**: M2数据每月公布，作为中线仓位调整参考

### CPI/PPI组合判断
**来源**: article_11, article_14
- CPI上升+PPI上升 → 通胀上行，利好资源股
- CPI上升+PPI下降 → 消费端涨价，利好消费品
- CPI下降+PPI下降 → 通缩预期，利好债券/防守型

### 宏观数据日历
```
每月初: PMI(制造业采购经理指数) → 反映经济景气度
每月中: 社融/M2/新增信贷 → 反映流动性
每月中: CPI/PPI → 反映通胀
每季末: GDP → 反映经济总量
不定期: LPR(贷款市场报价利率) → 反映货币政策
```

### 融资余额=杠杆情绪
**来源**: article_34 (2026.2.5), article_51
- 融资余额连续增加 → 杠杆资金入场，看多
- 融资余额连续下降 → 杠杆资金撤退，看空
- **关键区分**: 主动降杠杆(节前效应/利息成本) vs 被动杀杠杆(强制平仓)
- "融资余额的连续下降，引发人们担忧，是否是杀杠杆？目前看并不是，此轮增加和下降都产生于局部板块"

### 假期效应
**来源**: article_34 (2026.4.3), article_44
- 假期前: 短线资金主动降杠杆(不愿付利息)
- 假期中: 外盘波动→情绪传导
- 假期后: 补涨/补跌→方向确认
- "今天A股，是包含了假期里冲突加剧的定价"
