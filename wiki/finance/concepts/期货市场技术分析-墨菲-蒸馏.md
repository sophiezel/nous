# 《期货市场技术分析》— 墨菲出场/止盈/止损体系蒸馏

> 约翰·墨菲（John J. Murphy）1986 年著作，技术分析圣经级教材  
> 聚焦第 10 章（摆动指数）、第 16 章（资金管理与交易策略），  
> 辅以第 4 章（趋势线/管道）、第 5-6 章（价格形态）中与出场相关的论述

---

## 一、墨菲体系的总纲：交易的三个要素

> 在任何成功的期货交易模式中，都必须考虑三个方面的要素：
> **价格预测、时机抉择和资金管理。**

墨菲体系中，"出场"（exit）横跨时机抉择和资金管理两大领域：
- **时机抉择**确定具体的入市和出市点（何时行动、如何行动）
- **资金管理**决定每笔交易投入多少资金、止损指令设在哪里

墨菲名言的完整版本：
> **"让利润充分增长，把亏损限于小额。"**

---

## 二、技术出场信号的完整分类体系

墨菲的出场信号可归纳为六大类别，按优先级排序：

### 1. 趋势线突破信号（优先级最高）
- 重要的上升/下降趋势线被决定性突破 → 平仓出市
- 第三条扇形趋势线被突破 → 趋势反转的有效信号
- 价格无力达到管道线的上/下边 → 趋势即将变化的警讯

### 2. 支撑/阻挡水平信号
- 支撑水平被跌破 → 多头平仓
- 阻挡水平被突破 → 空头平仓（或变为支撑后失守）
- 价格跳空的回补/突破 → 入市/出市依据

### 3. 价格形态完成信号
- 头肩形颈线被突破 → 趋势反转，平仓
- 双重顶/底颈线被突破
- 三角形/旗形等持续形态朝反方向突破

### 4. 移动平均线信号
- 价格跌破移动平均线 → 多头出场信号
- 短期平均线向下穿越长期平均线 → 趋势反转信号（死亡交叉）
- 移动平均线由支撑变为阻挡

### 5. 摆动指数信号（详见第四节）
- 进入超买/超卖区域 → 预警
- 相互背离（divergence） → 重要出场信号
- 穿越零线确认

### 6. 保护性止损指令（详见第五节）
- 技术止损（基于图表点位）
- 资金止损（基于风险限额）
- 跟踪止损（保护利润）

## 三、趋势线/通道/形态的出场规则

### 3.1 趋势线突破的出场规则

**上升趋势线被跌破 = 多头出场信号**
- 收市价穿越比日内穿越更有分量
- 价格过滤器（3%原则）：收市价超越趋势线至少 3% 才算有效突破（适用于长期图表）
- 时间过滤器（2天原则）：必须连续两天收市在趋势线另一侧
- 短线交易可采用更小的过滤器（如 1%）

**趋势线角色互换原理**（关键！）
> 上升趋势线（支撑线）一旦被向下突破，就演化为阻挡线；  
> 下降趋势线（阻挡线）一旦被向上突破，就演变为支撑线。
>
> → **这条规则可直接用于出场后的再入场判断**

**扇形原理（S扇形原则）**
- 三条依次变平缓的趋势线被连续突破 → 第三条被突破是趋势反转的最终信号
- 每次突破后，原支撑线变为阻挡线

### 3.2 管道线（通道）的出场规则

**管道线的出场意义：**
- 上升管道线的上边线 → 短线平仓获利的参考点
- 管道线被突破的意义与趋势线正好相反：
  - 上升管道线被突破 → 趋势加速（可增加多头头寸，而非出场）
  - 价格无力达到管道线 → **趋势减弱的警讯**，预示着管道另一边将被突破

**管道线的测算意义：**
- 价格管道的突破 → 价格通常顺突破方向运动，距离 ≈ 管道宽度

### 3.3 百分比回撤的出场参考

- 强势调整的最小回撤 ≈ 33%，最大回撤 ≈ 66%
- 50% 回撤是最常见的倾向
- 在调整阶段中，回撤到 40%-60% 区域是重新入场（而非出场）的机会

### 3.4 价格形态的出场规则

**头肩形顶部 → 颈线跌破处是最佳卖出/出场点**
- 测算目标：从头部到颈线的垂直距离，从颈线突破点向下投影

**双重顶/底 → 颈线突破出场**
- 测算目标 ≈ 形态高度

**三角形整理 → 朝反方向突破则出场**
- 价格在三角形内摆动幅度缩小，交易量萎缩
- 突破伴随交易量放大才可信

## 四、摆动指数的超买/超卖出场信号

### 4.1 基本原则

> 摆动指数是第二位的指标，必须附属于基本的趋势分析。  
> **不可仅凭摆动指数进入超买/超卖区域就平仓！**

摆动指数最有效的三种情况：
1. **达到极限值**（超买/超卖）→ 警讯
2. **处于极限区域的相互背离** → 重要预警
3. **顺着趋势方向穿越零线** → 确认信号

### 4.2 RSI（相对力度指数）

- 刻度 0-100，70 以上超买，30 以下超卖
- 9天RSI灵敏度更高，80/20 替代 70/30
- **牛市中超买水平上移（80），熊市中超卖水平下移（20）**

**RSI出场信号要点：**
1. RSI 首次进入超买/超卖 → 只是警告信号，不是出场理由
2. **RSI 第二次进入危险区，且未验证价格新高/新低 → 真正的出场信号**
3. 顶部衰竭动作（top failure swing）：
   - RSI > 70
   - 新峰值无力超过前一个峰值
   - 向下跌破前一个谷值
   - → **多头出场信号**
4. 当 RSI 从 70 线下方向下穿越回来 → 卖出信号
5. RSI 图线上也可以加趋势线分析，趋势线被突破同样有效

**墨菲的忠告：**
> "在强烈的上升趋势中，超买状态常常能持续一段时间。  
> 仅仅根据摆动指数进入上边界，不足以构成平仓理由。  
> 应当耐心等待第二次进入危险区，方可采取预防措施——  
> 部分平仓获利，或设置紧凑的保护性止损指令。"

### 4.3 随机指数（%K/%D）

- %D 线更重要（较慢），70 以上超买，30 以下超卖
- **最佳卖出信号：%D 值在 85-90 时**
- 看跌背离：%D > 70，形成两个依次下降的峰，而价格继续上涨
- 真正的卖出信号：%D 已转头向下后，%K 向下穿越 %D（右侧相交）
- 墨菲强调：周线图上的随机指数信号更强，可用于确认主要趋势

### 4.4 威廉斯指数（%R）

- 刻度与随机指数顺序相反：0-20 超买，80-100 超卖
- 同样依赖于超买/超卖区的相互背离

### 4.5 动力指数（Momentum）

- 零线穿越：向上穿越零线 = 买入，向下穿越零线 = 卖出
- **必须顺着主要趋势方向使用**：趋势向上时才采用买入信号，趋势向下时才采用卖出信号
- 动力指数领先于价格变化 → 可作为提前出场信号
- 常用参数：10 天（最常用），5 天（更灵敏），20 天（更平滑）

### 4.6 相互背离（Divergence）— 最重要的摆动指数信号

**看跌背离（负向背离）**：
- 价格创出新高，摆动指数却无力创出新高
- 发生在摆动指数处于超买区域时 → 意义重大
- 预示新一轮上涨可能失败

**看涨背离（正向背离）**：
- 价格创出新低，摆动指数却未创新低
- 发生在摆动指数处于超卖区域时

**墨菲的背离出场规则：**
1. 背离 + 极限区域 → 预警
2. 背离 + 摆动指数突破自身前一峰/谷 → 确认
3. **仍须价格趋势本身显示反转迹象，才最终出场**
4. 在等待确认期间：使用紧凑的保护性止损指令

## 五、止损设置的多种方法

### 5.1 资金止损（固定百分比止损）

墨菲给出的具体量化规则：

| 规则 | 内容 |
|------|------|
| 总资本限制 | 在任何时候，投入市场的资金 ≤ 总资本的 **50%** |
| 单一市场限制 | 任何单个市场投入的资金 ≤ 总资本的 **10%-15%** |
| 单笔风险限额 | 单笔交易最大可亏损额 ≤ 总资本的 **5%** |
| 同一群类限制 | 同类市场（如贵金属）总投入 ≤ 总资本的 **20%-25%** |

**操作方法：**
- 总资本 × 5% = 单笔最大亏损额
- 用这个限额 ÷ 每张合约的止损点数 = 可持有的合约数
- 例：100,000 美元账户 × 5% = 5,000 美元风险限额
  - 止损设 12 美元/合约 → 可做 4 张（4 × $1,200 ≤ $5,000）
  - 止损设 15 美元/合约 → 只可做 3 张

### 5.2 技术止损（基于图表点位）

**支撑/阻挡止损：**
- 多头止损 → 设置在有效支撑点位的下侧
- 空头止损 → 设置在有效阻挡点位的上侧
- 支撑/阻挡的判断依据：前期低点/高点、趋势线、移动平均线、价格跳空

**趋势线止损：**
- 多头头寸的止损设在主要上升趋势线下方若干距离
- 趋势线越重要（被试探次数越多、持续时间越长），止损位越有意义

**百分比回撤止损：**
- 利用 33%/50%/66% 回撤位置来设定止损
- 在较强趋势中可选 66% 回撤下方作为止损

**移动平均线止损：**
- 在上升趋势中，将止损设在关键移动平均线（如 40 天均线）下方

### 5.3 波动率止损

墨菲明确指出：
> "交易者应当考虑市场的波动性。市场的波动性越大，止损指令就应当比较远。"

- **高波动市场 → 止损设远一些**，以避免被噪音触发
- **低波动市场 → 止损可设近一些**
- 止损过近 → 容易被短期摇摆（"噪音"）触发，过早出局
- 止损过远 → 虽然能避开噪音，但最终损失较大
- **关键是要走中庸之道**

### 5.4 保护性止损指令的具体类型

墨菲详细讨论了各类止损指令的优缺点：

| 指令类型 | 说明 | 适用场景 |
|---------|------|---------|
| **止损指令（Stop）** | 触及即转为市价指令 | 最常用，保护多头/空头头寸 |
| **跟踪止损** | 随价格上涨而上移 | 保护已获利的头寸 |
| **止损限价指令** | 同时设止损价和限价 | 既要止损又控制成交价格 |
| **触市指令（M.I.T.）** | 触及即转为市价 | 突破入市或出场 |

### 5.5 止损设置的综合决策流程

墨菲明确给出了"资金管理 + 图表分析"相结合的止损设定方法：

1. 确定买入点（假设 301 美元）
2. 从图表找出最近的可靠支撑水平（如 290 美元）
3. 将止损设在支撑下方（如 289 美元）
4. 计算每张合约风险（$12 × 100 美元 = $1,200）
5. 计算总风险上限（$5,000）
6. 确定可持合约数（4 张）
7. **如果支撑太远 → 要么减少合约数，要么寻找更接近的支撑**

> **核心原则："
> 止损指令必须放在有效的图表点位上，
> 同时满足资金管理的限额要求。"

### 5.6 复合头寸的止损策略（★★★★ 关键策略）

这是墨菲体系中极具实用价值的出场策略：

**复合头寸（Multiple-unit Position）**：
将交易头寸分为两部分：
1. **跟势头寸（Trend Position）** — 设较远的止损指令，为市场巩固/调整留余地，图谋长期利润
2. **交易头寸（Trading Position）** — 设较近的止损指令，频繁短线交易，锁定利润

**操作方法：**
- 当市场达到第一个目标，接近阻挡区，同时摆动指数显示超买
  - 对交易头寸：平仓获利，或设紧凑止损
  - 对跟势头寸：继续持有，止损设较远
- 如果趋势恢复 → 把已平仓的交易头寸补回来
- 如果趋势反转 → 跟势头寸用远端止损保护

> 这个策略与利弗莫尔的"试探性建仓+加仓"思路相通，  
> 但与利弗莫尔不同的是：墨菲强调同时持有不同止损距离的多单位头寸，  
> 而非仅逐步累加仓位。

## 六、墨菲的"何时该卖"系统性论述

### 6.1 出场的系统化清单

墨菲在全书结尾给出的出场相关问题清单（必须在入市前回答）：

> 1. 在今后一到三个月内，当前市场趋势会怎样演变？
> 2. 我决定在本市场买入还是卖出？
> 3. 交易合约的数量是多少？
> 4. **在判断错误的情况下，我打算承受多大的风险？**
> 5. **我的利润目标在何处？**
> 6. **在什么点位入市？什么点位出市？**
> 7. 采用何种指令类型？
> 8. **我应当把保护性止损指令设置于何处？**

### 6.2 入市时就要想好出场

墨菲强调交易计划的重要性：
> "先制订好计划，然后贯彻到底。"

每个交易计划必须包含：
- **利润目标**（技术目标位）
- **止损位置**（最大可接受亏损）
- **报偿-风险比**（profit-to-risk ratio）

### 6.3 3:1 报偿-风险比准则

> "报偿-风险比至少达到 3:1，方可动作。"

**计算公式：**
- 预期利润（报偿） ÷ 预期亏损（风险） ≥ 3
- 例：黄金交易，预测风险 10 美元，则利润潜力至少需达到 30 美元

**进阶用法**：加入"可能性因子"
- 潜在利润 × 利润发生概率 + 潜在亏损 × 亏损发生概率
- 墨菲承认这"从统计学角度看颇有道理"，但问题在于交易者很难事前量化概率

### 6.4 分批出场的策略体系

墨菲的分批出场（复合头寸法）与克罗的"金字塔出场"不同：

| 特征 | 墨菲复合头寸法 | 克罗金字塔法 |
|------|--------------|-------------|
| 核心思路 | 同时持有跟势头寸 + 交易头寸 | 逐步减仓，大头寸先出 |
| 止损设置 | 跟势头寸远端，交易头寸近端 | 统一在关键位 |
| 获利处理 | 交易头寸频繁锁利 | 部分减仓，剩余持有 |
| 加仓规则 | 盈利头寸上加码 | 在盈利头寸上加码 |
| 亏损处理 | 绝不在亏损头寸上加码 | 绝不在亏损头寸上加码 |

### 6.5 保守 vs 大胆的交易风格

墨菲明确推崇**保守风格**：
> "从长期来看，保守的交易风格最可取。"

引述《商品期货游戏》：
> "甲交易者成功的把握较大，但交易作风较为大胆；  
> 乙交易者成功的把握较小，但能奉行保守的交易原则。  
> 从长远看，乙取胜的机会可能比甲更大。"

**成功/失败后的处置原则：**
- 连续亏损后 → 不要冒进试图扳回，但也**不要过于保守**（否则更难回本）
- 连续盈利后 → **不要在刚刚获利后就马上扩大投入**（等于是超买时买入）
- 更明智的做法：**在资本金有亏损时开始增加投入**（低买高卖的原理同样适用于资金管理）

### 6.6 "平仓盈利头寸前，优先平仓亏损头寸"

这是墨菲的重要规则，与许多交易者的直觉相反：
> "大多数人潜意识里想'先拿回一些利润'，但正确的做法是  
> **先处理亏损的头寸**——它们才是威胁本金安全的毒瘤。"

## 七、与已有止盈框架的互补与差异

### 7.1 与利弗莫尔体系的比较

| 维度 | 利弗莫尔 | 墨菲 |
|------|---------|------|
| 止损哲学 | 找到关键点，一旦失误立即出场 | 结合资金管理 + 图表技术，系统化止损 |
| 加仓方式 | 金字塔加仓，越加越少 | 金字塔加仓 + 复合头寸管理 |
| 出场依据 | 趋势转向迹象出现 | 多维度信号综合判断（趋势线+摆动指数+支撑/阻挡+移动平均线） |
| 利润保护 | 盈亏平衡止损 | 跟踪止损 + 分批出场 |
| 风险控制 | 凭经验判断"错误" | **量化风险限额（5%原则）** |

**墨菲的独特贡献**：将利弗莫尔直觉式的"关键点止损"升级为可量化、可系统化的止损体系，同时保留了技术分析的艺术性。

### 7.2 与克罗体系的比较

| 维度 | 克罗 | 墨菲 |
|------|-----|------|
| 趋势定位 | 只做主要趋势，忽略中小波动 | 三种趋势（主要/中等/短暂）并存分析 |
| 出场时机 | 趋势改变信号出现 | 综合多种信号，分批出场 |
| 止损设置 | 宽止损，给趋势足够空间 | 也是宽止损，但结合资金限额调整头寸规模 |
| 止盈方式 | 让利润奔跑，不轻易出场 | **复合头寸法**：部分锁利，部分奔跑 |
| 加仓 | 只在盈利头寸上加仓 | 同左，且强调只能在盈利头寸上加码 |

**核心差异**：
- 克罗更极端地强调让利润奔跑，出场信号较少
- 墨菲更务实，承认"大多数交易以亏损告终"（最成功的交易商也只能在 40% 的交易中获利），因此设计了分批锁利的机制

### 7.3 与趋势交易法的比较

**趋势交易法的出场逻辑**（基于海龟交易法则/唐奇安通道）：
- 出场信号来源于入场规则的反向突破
- 例如：10日/20日突破入场，则 10日/20日反向突破出场

**墨菲体系的补充**：
- 出场信号来源远多于趋势交易法：摆动指数、相互背离、趋势线突破、支撑/阻挡、价格形态
- 强调信号之间的**相互验证**（越多信号指向同一方向，结论越可靠）
- 提供了**摆动指数在趋势市中"超买不等于卖出"**的重要辨别准则
- 复合头寸法解决了趋势交易法"长期持有 vs 短期波动"的核心矛盾

### 7.4 墨菲的独特贡献总结

1. **资金管理是出场体系的基础层**：5% 风险限额 → 决定了可持有头寸 → 影响止损位置选择
2. **多信号综合而非单一信号出场**：21 项技术分析清单，任何单一工具都不足以决定出场
3. **"让利润充分增长"的具体执行方案**：复合头寸法 + 跟踪止损
4. **摆动指数的正确用法**：不可孤立使用，必须服从主要趋势，第二次信号才是真正的出场点
5. **止损设置的量化+图表双维度结合**

## 九、墨菲出场决策流程总图

```
入市前
├─ 1. 确定趋势方向（长期→短期）
├─ 2. 设定利润目标（技术测算）
├─ 3. 设定止损位（支撑/阻挡下方）
├─ 4. 计算报偿-风险比（≥3:1）
├─ 5. 计算头寸规模（5% × 总资本 ÷ 每合约风险）
└─ 6. 选择指令类型

持仓中
├─ 每日检查技术信号变化
│   ├─ 趋势线是否被突破？
│   ├─ 摆动指数是否超买/超卖？
│   ├─ 有无相互背离？
│   ├─ 支撑/阻挡是否被穿越？
│   └─ 移动平均线关系如何？
├─ 调整止损
│   ├─ 跟踪止损（价格上涨后上移）
│   └─ 盈亏平衡止损（利润足以覆盖风险后）
└─ 分批出场决策
    ├─ 交易头寸：接近阻挡/超买 → 部分平仓
    └─ 跟势头寸：趋势未变 → 继续持有

出场触发条件（任一满足即可）
├─ 保护性止损被触及
├─ 重要趋势线被突破
├─ 关键支撑/阻挡被穿越
├─ 摆动指数+背离确认
├─ 价格形态朝反方向突破
├─ 移动平均线趋势反转
└─ 达到预设利润目标（分批出场可能在此）
```
