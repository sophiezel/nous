# 全球宏观对冲框架 — 实操蒸馏

> 核心不是预测，而是情景假设 + 赔率计算。在不确定的世界里构建确定性的资产配置。

---

## 一、核心理念

### 1.1 什么是全球宏观对冲

全球宏观策略（Global Macro Strategy）是一种对冲基金策略，基于对各国宏观经济及政治环境的分析，通过在全球股票、债券、外汇及大宗商品市场建立多空头寸获取收益。\"宏观\"一词来源于利用宏观经济原理识别金融资产价格的失衡错配；\"全球\"则指在全世界的范围内寻找这种错配。

**两类交易模式**（全球宏观策略-百度百科）：
- **定向型交易**：押注单一资产的价格波动，如做多美元指数或做空日本债券
- **相对价值型交易**：同时持有一对同类资产的多头和空头，利用相对价格错位盈利，如做多新兴市场股票+做空美股

**两种操作模式**：
- **积极型**：高杠杆、高频率，代表：索罗斯量子基金
- **保守型**：低杠杆甚至零杠杆，代表：保险基金、主权基金

### 1.2 核心思维：不是预测，是情景假设+赔率

- \"我不会以一套特定的规则来玩游戏，我会努力去寻找游戏中规则的变化。\"——索罗斯
- 全球宏观策略的交易者寻找的是那些\"远离均衡\"状态的价格波动（超出均值一个标准差以上）
- 时机选择意味着一切——因为杠杆放大了收益和损失

### 1.3 Dalio的全天候策略框架

桥水基金的Ray Dalio将经济环境划分为**四种\"气候\"**，按增长和通胀两个维度的超预期/低于预期组合：

| 经济增速 vs 预期 | 通胀 vs 预期 | 表现出色的资产 | 配置比例 |
|-----------------|-------------|---------------|---------|
| 高于预期 | 高于预期 | 大宗商品、黄金、通胀挂钩债券 | 25% |
| 高于预期 | 低于预期 | 股票、公司债 | 25% |
| 低于预期 | 高于预期 | 通胀挂钩债券、黄金 | 25% |
| 低于预期 | 低于预期 | 国债、长期国债 | 25% |

**核心创新：风险平价（Risk Parity）**
- 传统资产配置按资本（金额）平衡 → 90%股票+10%国债，但90%的风险来自股票
- 桥水按波动性（风险）平衡 → 让各类资产对组合的风险贡献相等
- 例：如果股票波动率是国债的10倍，国债的配置金额应该是股票的10倍

## 二、中国宏观对冲实践者

### 2.1 凯丰投资：吴星的\"商品+宏观\"体系

凯丰投资是中国领先的宏观对冲基金管理公司，管理规模约百亿（凯丰官网）：

- **投资理念**：\"细节暗藏产业密码，研究发现价值内核\"
- **核心特征**：覆盖全球大宗商品、债券、权益类资产及其衍生品
- **策略定位**：以商品为起点，向宏观对冲延伸——\"从商品基本面的细节中发现宏观的线索，再通过大类资产配置来兑现\"
- **研究方法**：深度产业研究，团队覆盖10+产业链

凯丰的宏观策略体系可以概括为\"三层次\"：
1. **顶层**：全球宏观经济周期判断（增长、通胀、流动性）
2. **中层**：大类资产配置（股/债/商/汇的权重和方向）
3. **底层**：具体品种/个股的基本面研究（产业细节）

### 2.2 混沌投资：葛卫东的全球化之路

葛卫东从国内期货起步，逐步拓展为真正的全球宏观投资者（闽发论坛、雪球报道）：

- **交易范围**：不再局限于国内三家期交所，伦敦、纽约、东京等市场都在做
- **品种覆盖**：大宗农产品、外汇、金融衍生品
- **核心方法**：\"期货主要是基于对经济形势和趋势的判断，挣的是波段的钱\"
- **风险控制**：杠杆控制在3倍以下，从分析索罗斯狙击英镑的杠杆比例推算得出

**葛卫东的全球化框架**：
- 美元强弱→全球商品定价→国内通胀预期→央行货币政策→资产配置
- 从\"主动寻找机会\"到\"静等机会出现\"——\"重大机会到来的时候自己会感悟到\"

### 2.3 敦和资产：叶庆均的宏观对冲

叶庆均（叶大户）领导的敦和资产管理规模超千亿，是中国最大的宏观对冲基金之一，投资范围涵盖商品期货、股票、债券、外汇等全资产类别。

## 三、关键宏观指标三层分类

全球宏观对冲的核心能力：区分领先、同步、滞后指标，构建预测能力。

### 3.1 领先指标（预测未来3-12个月）

| 指标 | 含义 | 对资产的影响 |
|------|------|------------|
| 制造业PMI新订单 | 经济动能的最前沿 | 连续3个月>50→偏多权益/商品 |
| 中美10年期利差 | 跨境资本流向的先行指标 | 利差收窄→北向资金减少→A股承压 |
| 美元指数 | 全球流动性阀门 | 美元走强→新兴市场承压；美元走弱→利好新兴市场 |
| 铜金比 | 经济景气度代理变量 | 比值上升→风险偏好上升→利好周期股 |
| 信用利差（投资级-国债） | 金融压力指标 | 利差扩大→流动性收紧→减仓所有风险资产 |
| 央行资产负债表规模 | 全球流动性总量 | 扩表→资产价格上升；缩表→资产价格承压 |

### 3.2 同步指标（验证当前状态）

| 指标 | 含义 |
|------|------|
| GDP增速（季度） | 经济整体运行状况 |
| 社会消费品零售总额 | 内需强度 |
| 工业增加值 | 生产端活跃度 |
| 失业率 | 劳动力市场状况 |
| CPI/PCE | 通胀压力 |
| 企业盈利增速 | 微观盈利状况 |

### 3.3 滞后指标（确认趋势已形成）

| 指标 | 含义 | 投资启示 |
|------|------|---------|
| 资本开支增速 | 企业信心恢复的最后一环 | 资本开支上升→周期/商品行情已近尾声 |
| 库存周期（被动去库→主动补库） | 确认经济阶段 | 主动补库存→商品行情正在兑现 |
| 工资增速 | 劳动力市场的滞后确认 | 工资大涨→通胀顽固→央行鹰派 |
| 央行利率决策 | 确认经济周期位置 | 开始加息→经济已过热；开始降息→经济已衰退 |

## 四、美元周期与跨境资本流动框架

### 4.1 美元周期的\"三碗面\"框架

中金公司研究部缪延亮提出的美元周期分析框架（2025年6月）：

**基本面**：美国经济的相对表现
- 当美国经济增长好于其他主要经济体→美元走强
- 美国经济\"一枝独秀\"vs欧洲疲弱→美元受益

**政策面**：美联储货币政策
- 加息周期→美元走强；降息周期→美元走弱
- 美联储滞后市场的\"纠错机制\"是关键

**资金面**：跨境资本流动
- 美元升值→全球资金流入美国→进一步推高美元（正反馈）
- 金融账户资金流动对汇率的边际影响＞经常账户

**美元周期的两个正反馈机制**（索罗斯\"反身性\"）：
1. **实体正反馈**：美元升值→他国美元债务负担加重→经济恶化→资金继续流向美国
2. **金融正反馈**：美元升值→吸引更多资金流入美国→美资产价格上涨→进一步吸引资金

### 4.2 美元周期对资产的影响路线图

```
美元走弱阶段：
  美元↓ → 新兴市场资本流入↑ → MSCI新兴市场指数↑
         → 人民币升值 → A股受益（北上资金流入→核心资产上涨）
         → 大宗商品以美元计价上涨 → 商品股/资源国货币走强
         → 港股受益（港币挂钩美元，资金流向亚太）

美元走强阶段：
  美元↑ → 新兴市场资本流出↑ → 新兴市场股债双杀
         → 人民币贬值 → A股承压（北上资金流出）
         → 商品承压（除黄金等避险品种）
         → 港股承压（流动性收紧）
```

### 4.3 中美利差与北向资金的关系

**核心传导链**（国联期货研究报告、国信证券研究）：
```
中美10年期利差变化 → 跨境套利资本流动 → 人民币汇率预期
  → 陆股通(北向)资金流向 → A股核心资产定价
```

**量化规律**（基于历史数据）：
- 中美利差每扩大10bp，北向资金流入速度约提升15%
- 人民币升值1%，对应北向资金流入提速约23%
- 当\"出口强势 + 中美利差正向走扩 + 汇率升值\"三个条件同时出现时，沪深300月均收益率达3.85%（2017-2024年数据，11个月中有10个月正收益）

**重要修正**：北向资金的\"聪明\"更多是对行情变动的灵敏嗅觉，而非对汇率的直接反应。\"将单月的股市上涨解释为人民币升值所带动的北向资金流入可能并不完善，真正吸引外资的是资产本身的价值。\"（国信证券）

## 五、跨市场经济周期联动

### 5.1 美国→中国→新兴市场传导链

```
美国经济周期
  ├→ 美债收益率变化 → 全球无风险利率基准 → 新兴市场估值锚
  ├→ 美元强弱 → 全球资本流动方向 → 新兴市场资金进出
  ├→ 中国出口需求 → 中国经济动能 → 大宗商品需求
  └→ 风险偏好(VIX) → 全球资金配置（risk-on/off）
        ↓
  中国经济周期
  ├→ 大宗商品进口需求 → 南美/中东/非洲出口国
  ├→ 人民币汇率 → 亚洲货币联动
  └→ A股/港股 → 亚太资本市场风向标
        ↓
  新兴市场整体
  ├→ 资本流动方向（与美元周期负相关）
  ├→ 大宗商品出口国 vs 进口国分化
  └→ 全球制造业PMI联动
```

### 5.2 全球宏观的\"核心-外围\"框架

| 层次 | 经济体 | 核心观察指标 | 投资含义 |
|------|-------|------------|---------|
| **核心1: 美国** | 全球流动性发动机 | 美联储利率、非农、CPI、10Y利率 | 决定全球无风险利率和风险偏好 |
| **核心2: 中国** | 全球最大的商品需求国 | 社融、PMI、房地产销售、基建投资 | 决定商品方向，影响新兴市场出口 |
| **外围: 欧洲** | 深受美国影响 | 欧央行利率、德国IFO | 欧元强弱影响美元指数构成 |
| **外围: 日本** | 套利交易源头 | 日央行利率、日元汇率 | 日元套利交易影响全球风险资产 |
| **前沿: 新兴市场** | 顺周期敏感 | 经常账户、外债占比、外汇储备 | 美元走弱时弹性最大 |

## 六、与鳄鱼派的契合点

### 6.1 宏观判断→仓位决策

鳄鱼派的\"潜伏-高胜率-重仓\"路径，在全球宏观框架中的升级版本：

| 鳄鱼派要素 | 全球宏观版本 | 实操方法 |
|-----------|------------|---------|
| **潜伏** | 等待宏观信号的\"极端值\" | 等待美元周期拐点、中美利差极端值、PMI连续超预期/低于预期 |
| **高胜率** | 多维度宏观信号共振 | 基本面+政策面+资金面\"三碗面\"同时指向同一方向 |
| **重仓** | 保守型宏观对冲中的战术调整 | 在\"经济超预期+通胀低于预期\"时重仓权益，其他时间轻仓 |

### 6.2 全球宏观给鳄鱼派的升级

1. **从单一品种到多资产**：鳄鱼派传统上聚焦股票或单一期货品种，全球宏观框架让鳄鱼可以跨资产配置——股市不好时做债券、汇率不好时做商品
2. **从方向判断到情景分析**：不预测方向，而是预设多个情景并做好应对预案（索罗斯式思维）
3. **从\"等机会\"到\"主动构建组合\"**：鳄鱼派被动等待，全球宏观主动配置——在任何环境下都有可做的事
4. **风险平价思维**：用波动率来平衡各头寸的风险，比鳄鱼派的\"重仓单一机会\"更安全

### 6.3 鳄鱼派实战中的宏观应用

**当宏观信号与个股信号冲突时**：
- 宏观优先（\"不要跟美联储对着干\"——葛卫东）
- 在紧缩周期中，个股的基本面再好也难以独善其身
- 在宽松周期中，差的个股也可能被水抬升

**\"宏观底\"的鳄鱼式抄底**：
- 等待三个宏观信号的共振：美元走弱 + 中美利差收窄 + 中国经济数据企稳
- 三个信号出现2个时可以轻仓布局
- 三个信号全部出现时重仓入场
- 止损信号：任何一个信号重新恶化

## 七、可量化规则

```python
def global_macro_signals():
    \"\"\"全球宏观对冲信号体系\"\"""
    signals = {}
    
    # 1. 美元周期判断
    dxy = usd_index()
    dxy_5y_pct = percentile_5y(dxy, inverse=True)  # 美元强势=低百分位
    
    usd_weak = dxy < dxy_ma_200  # 美元指数低于200日均线
    usd_strong = dxy > dxy_ma_200
    
    if usd_weak and dxy_5y_pct > 0.70:
        signals['usd_cycle'] = ('美元弱势周期', '利好新兴市场/A股/商品')
    
    # 2. 中美利差方向
    cn_10y = china_10y_yield()
    us_10y = us_10y_yield()
    spread = cn_10y - us_10y
    spread_ma_3m = sma(spread, 63)  # 3个月均线
    
    if spread > spread_ma_3m and spread > 0:
        signals['cn_us_spread'] = ('利差走扩', '利好北向资金流入')
    elif spread < spread_ma_3m and spread < 0:
        signals['cn_us_spread'] = ('利差收窄', '北向资金承压')
    
    # 3. 四象限情景分析（Dalio全天候框架）
    growth_vs_exp = gdp_nowcast() - gdp_consensus()      # 增长vs预期
    cpi_vs_exp = cpi_nowcast() - cpi_consensus()          # 通胀vs预期
    
    if growth_vs_exp > 0 and cpi_vs_exp > 0:
        signals['quadrant'] = ('过热', '超配商品/通胀挂钩债')
    elif growth_vs_exp > 0 and cpi_vs_exp < 0:
        signals['quadrant'] = ('金发女孩', '超配股票/信用债')
    elif growth_vs_exp < 0 and cpi_vs_exp > 0:
        signals['quadrant'] = ('滞胀', '超配现金/短久期债券')
    else:
        signals['quadrant'] = ('衰退', '超配国债/长久期债券')
    
    # 4. 仓位建议
    if signals.get('quadrant') in ['金发女孩'] and signals.get('usd_cycle') == ('美元弱势周期', ...):
        max_equity_position = 0.85  # 最有利于权益
    elif signals.get('quadrant') in ['滞胀']:
        max_equity_position = 0.20  # 最不利于权益
    else:
        max_equity_position = 0.50  # 中性
    
    signals['position_suggestion'] = max_equity_position
    
    return signals
```
