# 裘国根（重阳投资）— 绝对收益+宏观价值

> **浓缩金句：** "投资的第一要务是不亏钱。宁可少赚，不能大亏。"

## 一、战绩概览

- 中国首批阳光私募，2001年创立重阳投资
- 20年年化约15%，最大回撤控制极好（2008年仅-13% vs 大盘-65%）
- 风格：绝对收益导向——熊市少亏比牛市多赚更重要
- 代表作：招商银行、中国平安、上海家化

## 二、核心理念

裘国根跟其他价值派最大的区别：他是**宏观驱动**的。

```
其他人：自下而上选股 → 不管大盘
裘国根：宏观定仓位 → 行业选方向 → 个股选龙头
```

**三层决策框架：**

| 层级 | 判断 | 频率 | 仓位影响 |
|------|------|------|---------|
| L1 宏观 | 经济周期位置 | 季度 | 决定整体仓位50-90% |
| L2 行业 | 政策+景气度 | 月度 | 决定行业配置 |
| L3 个股 | 估值+品质 | 持续 | 行业内选龙头 |

## 三、可量化规则

### 宏观仓位调节
```python
def qiugen_macro_position():
    pe_shanghai = get_market_pe("sh000001")
    
    if pe_shanghai < 12: return 0.90  # 满仓
    elif pe_shanghai < 16: return 0.70
    elif pe_shanghai < 20: return 0.50
    elif pe_shanghai < 25: return 0.30
    else: return 0.10  # 几乎空仓
```

### 选股偏好
- 大盘蓝筹为主（市值 > 500亿）
- PE < 15 或 PB < 1.5
- 股息率 > 3%
- 金融+消费+公用事业为主

- 🟢 高度契合：宏观择时、等好时机
