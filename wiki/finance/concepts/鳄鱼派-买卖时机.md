# 鳄鱼派买卖时机

## 入场时机

### 三条件共振（缺一不可）

1. **价格低位** — 价值规律，跌出安全边际
2. **信号确认** — 技术面+基本面+资金面共振
3. **情绪配合** — 多数人绝望/恐慌

### 右侧交易五步流程
**来源**: 文章#32

右侧行情完整演变流程：
1. **放量普涨** → 广撒网开超市，不适合追高
2. **缩量分化** → 赛马PK，观察谁持续
3. **分化出主线** → 确定龙头板块
4. **主线吸引增量资金** → 增量入场
5. **再次放量普涨** → 高潮阶段，准备止盈

**买点位置**：在分化分歧阶段（第2步）和分歧转一致阶段（第3→4步）买入
> 赛马PK原则：最终只有少数板块能持续走流畅的单边趋势

### 分批建仓与微笑曲线
**来源**: 文章#60

- **左侧选手**是主动买套，按间隔分批逢低买进
- **微笑曲线出现概率**：宽基指数 > 行业指数 > 个股
- 个股左侧前提：公司有绝对优势和实力，不被同行卷死
- 微笑曲线几乎百分百出现于宽基指数（只要市场不倒闭）
- 定投核心：间隔分批，做低成本

### 三类买点体系（左侧/右侧全体系）
**来源**: 文章#42, 文章#52, 文章#91

| 类型 | 位置 | 仓位 | 说明 |
|------|------|------|------|
| 一类买点（左侧底部） | 止跌筑底阶段 | 仅可打底，不可重仓 | 市场缩量+信号1/2/5满足 |
| 二类买点（回调二买） | 回调不破前低 | 最好把握，需要耐心 | 等待回调确认 |
| 三类买点（右侧突破） | 突破确认 | 需要突破确认后才可加仓 | 信号1(放量)+2(火车头)+5(基差正常)=博弈止跌 |

> 三种买点都错过了就耐心等新的二买出现
> **"大胆假设，小心求证"**：尾盘用真金白银抢先手

### 具体买点

| 场景 | 信号 | 操作 |
|------|------|------|
| 恐慌杀跌后 | 缩量止跌+大资金进场 | 试探性建仓 20% |
| 两只脚共振 | 科技+金融同时上涨 | 加仓至 50% |
| IF基差转正 | 飞行员撤退 | 加仓至 80% |
| 全面共振 | 四条件全满足 | 满仓 |

### 不买的场景

- 缩量反弹（下跌放量→反弹缩量）
- 声东击西（金融拉科技跌）
- 两只脚一只跌
- IF基差 > 50（飞行员看空）
- 仅便宜但无其他信号
- **过早高低切**（2026.5.25新增）：科技退潮后不要指望市场无缝衔接，其他板块也难持续大涨成新主线

### 高低切正确时机（2026.5.25新增）
**来源**: 文章 (2026.05.25)

```
正确流程：
1. 科技退潮确认（情绪连续两天下降 + 融资余额连续减少）
2. 观察资金去向（机构先去哪些板块打底）
3. 等底部买扎实（机构持仓增加 + 成交量温和放大）
4. 短线大资金点火（出现新火车头）
5. 确认新主线形成 → 再跟

错误流程：
1. 科技刚开始走弱 → 立即切低位板块 ❌
2. 低位板块涨一天 → 追进去 ❌
3. 结果：低位板块又跌，科技反弹，两头挨打
```

> **历史规律**：过去一年A股从未成功实现一次良性的高低切无缝衔接。

## 离场时机

### 强制离场（趋势破必须走）

| 信号 | 动作 |
|------|------|
| 火车头低开 > 2% | 立即减仓 50% |
| IF基差 > 80 | 立即减仓至 30% |
| 热门股双顶 | 清仓 |
| 两只脚共振下跌 | 清仓 |
| 科技前排做头 | 减仓至 20% |

### 退潮三阶段卖出

```
阶段1 初见下跌 → 减仓至 50%
阶段2 缩量反弹 → 不追，维持 50%
阶段3 双顶确立 → 清仓
```

### 止盈策略

| 类型 | 止盈线 | 说明 |
|------|--------|------|
| 短线 | +8% | 快速获利了结 |
| 中线波段 | +15% | 趋势跟随 |
| 长线价值 | +30% | 基本面驱动 |

### 5日均线趋势持仓法
**来源**: 文章#88

趋势行情"逐渐成熟阶段"：股价沿5日均线运行，不必急于止盈。
- 几乎不看分时图，每天收盘看日K即可
- 只要日K保持在5日均线附近运行，不必着急
- **趋势终结信号**：跌破5日均线且连续两日无法收回
- "熟透阶段"精准止盈很难，不如在趋势破位时统一离场

### 滚动持仓与底仓纪律
**来源**: 文章#36

- 鱼头反复震荡时，很多人忍不住做T → 养成滚动持仓习惯
- **核心纪律**：留足底仓，别T着T着底仓没了
- 大仓位在前10%涨幅里卖掉只轻仓吃后面20-30% = 失去长线意义
- 滚动持仓不是单纯区间震荡高抛低吸，要判断是"鱼头震荡"还是"鱼身结束"

### "卖一半，包治百病"
**来源**: 文章#89, 文章#91

- 行情火热时部分止盈，不代表不看好后市
- **"卖一半，包治百病"** — 实在怕回落就止盈一半
- 疯牛故事参考：2015年50万变2亿但没止盈，最终归零
- 做好动态持仓：成熟的庄稼要收获，没成熟的别乱动
- 趋势行情里不用抢也不用急

### 移动止盈

从最高点回撤 5% → 卖出。防止赚了钱不能全身而退。

## 鳄鱼派最难的哲学

> 不是赚钱，而是赚了钱，全身而退。

老股民能识破"声东击西"，先出来观望。新股民看到大金融大涨就加仓冲进去——然后被套。

核心：**赚了就跑比抄底更难**。

**来源**: article_533

**来源**: article_558, 564

### 港股右侧加仓
**来源**: article_562
- 正反馈：南下→涨→空头平仓→A股科技释放→再南下；沽空仍高则不急

### 三剑客加仓节奏
**来源**: article_555–560
- 三年规划不可一周配完；便宜捡一点，没便宜拿好；忌追涨恐慌
