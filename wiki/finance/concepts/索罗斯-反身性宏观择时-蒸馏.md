# 索罗斯（量子基金）— 反身性+宏观择时

> **浓缩金句：** "市场总是错的。当趋势自我强化到不可持续时，就是出手的时候。"

## 一、补什么缺口

**补：宏观择时缺口。** 已有13人中裘国根做宏观仓位调节（PE分位数法），但缺少索罗斯式的"趋势转折点判断"——识别泡沫何时破裂、恐慌何时见底。

## 二、核心理念：反身性

```
传统金融学 → 价格反映基本面 → 市场是有效的
索罗斯理论 → 价格影响基本面 → 市场永远是错的

反身性链条：
  价格上涨 → 更多人买入 → 基本面改善（信贷扩张/乐观预期）
  → 价格继续涨 → 更多人买入 → 基本面过度膨胀
  → 某一点 → 逆转 → 价格下跌 → 恐慌卖出 → 基本面恶化
```

**索罗斯不是赌方向，是赌"趋势的不可持续性"——当反身性循环走到极致，必然逆转。**

## 三、可量化规则

### 反身性检测指标
```python
def soros_reflexivity_signal(market):
    """检测市场是否处于反身性极端"""
    pe = market_pe(market)        # 市场PE
    pe_5y_pct = pe_percentile_5y(market)
    margin = margin_balance(market)  # 融资余额
    margin_1y = margin_growth_1y(market)
    new_accounts = new_investor_accounts(market)
    
    # 反身性上行极端（泡沫）
    if pe_5y_pct > 0.90 and margin_1y > 0.50:
        return ("泡沫期", "趋势不可持续，准备做空/减仓")
    
    # 反身性下行极端（恐慌）
    if pe_5y_pct < 0.10 and margin_1y < -0.30 and new_accounts < two_year_low * 0.3:
        return ("恐慌底", "恐慌不可持续，准备抄底")
    
    return ("正常", "")
```

    """确认反身性循环的转折点"""
    # 必须满足三个条件

## 四、系统注入

索罗斯不作为日常信号，作为**危机模式触发器**：

```
正常模式 → 鳄鱼派信号主导
索罗斯触发泡沫警报 → 强制仓位上限降至50%
索罗斯触发恐慌底警报 → 允许仓位上限提至90%
索罗斯确认趋势转折 → 强制全员重新评估持仓
```
