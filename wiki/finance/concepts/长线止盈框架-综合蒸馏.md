# 长线止盈框架 — 七位大师卖出哲学综合蒸馏

> **核心洞察：** 七位大师的买入方法千差万别，但卖出哲学惊人地一致——
> 卖出不是因为"跌了"，而是因为"当初买入的理由不存在了"。

---

## 一、本杰明·格雷厄姆 — 内在价值回归卖出

### 核心原则

**"市场先生为你服务，而非指导你。"** 卖出决策基于内在价值与市场价格的偏离度，而非情绪或预测。当市场先生给出高得离谱的报价时，你就应该卖给他。

### 卖出触发条件（清单式）

| # | 触发条件 | 量化标准 | 操作 |
|---|---------|---------|------|
| 1 | 股价远超内在价值 | 股价 ≥ 评估价值的 1.5倍（进取型）或 PE > 20（防御型） | 分批卖出 |
| 2 | 市场极度狂热 | 市场先生报价"高得离谱"时 | 全部或大部卖出 |
| 3 | 股债比例失衡 | 股票仓位 > 75%（再平衡上限） | 减至50%基准 |
| 4 | 股息记录中断 | 连续派息中断（防御型投资者的卖出信号） | 卖出 |
| 5 | 基本面恶化 | 连续2年利润下降、流动比 < 1.5 | 卖出 |

### 典型案例

- **GEICO案例（后记）：** 格雷厄姆买入GEICO后，股价从2美元涨到30美元，他卖出大部分——不是因为不看好，而是因为价格已远超内在价值。结果GEICO后来涨了200倍。格雷厄姆的反思："一次幸运的机会，可能超过一辈子的努力。"
- **股债再平衡：** 1972年市场高位时，格雷厄姆建议将股票仓位降至最低；1974年市场崩盘后，建议将股票仓位提至最高。这不是择时，是"价格越低，安全边际越大"的机械化操作。

### 关键语录

> "不要在股价出现大幅上涨后立即购买股票，也不要在股价出现大幅下跌后立即出售股票。"（第8章）
> "证券并没有所谓的好坏之分，只有便宜和昂贵之分。"（第20章）

## 二、沃伦·巴菲特 — 护城河侵蚀/管理层变坏时卖出

### 核心原则

**"以合理的价格买入伟大的公司，然后什么都不做。"** 巴菲特本质上没有"止盈"概念——他不因为股价涨了而卖出。他只在一个时候卖出：**当初买入的长期逻辑被破坏**。

### 卖出触发条件（清单式）

| # | 触发条件 | 判断标准 | 操作 |
|---|---------|---------|------|
| 1 | 护城河被永久性侵蚀 | 品牌弱化、技术被颠覆、客户流失、定价权丧失 | 清仓 |
| 2 | 管理层变坏 | 资本配置变差、股东利益被损害、薪酬不合理、关联交易 | 清仓 |
| 3 | 护城河评分降级 | 护城河评分从 >70（宽）降到 <40（无） | 卖出 |
| 4 | 极端估值泡沫 | 自由现金流收益率 < 无风险利率（FCF/市值 < 国债利率） | 减仓 |
| 5 | 发现更好的机会 | 有护城河更宽、价格更合理的替代标的 | 换仓 |
| 6 | 行业结构永久性改变 | 技术颠覆、监管颠覆、消费习惯根本性改变 | 卖出 |

### 典型案例

- **可口可乐（1998年后未卖）：** 1998年可口可乐PE高达50倍，巴菲特没有卖出——因为护城河还在、管理层还在。这是"不卖哲学"的体现。
- **华盛顿邮报（2014年卖出）：** 巴菲特卖出不是因为股价涨了，而是因为报纸行业被互联网颠覆，护城河消失了。
- **IBM（2017年清仓）：** 买入IBM时认为它的客户转换成本极高，后来发现IBM在云计算时代不再不可或缺，护城河变窄——清仓。
- **航空股（2020年清仓）：** COVID-19改变航空业结构，护城河被永久侵蚀——清仓。注意：这不是因为跌了（他抄底了达美航空），而是因为**竞争结构变了**（政府援助让所有航空公司都活下来了，供给没有出清）。

### 关键区别

> 巴菲特的卖出是**质变触发**（护城河/管理层/行业结构），而非**量变触发**（股价涨了多少、PE到了多少）。
> 这与格雷厄姆的"估值回归卖出"形成对照——巴菲特更看重企业的长期竞争力，格雷厄姆更看重价格与价值的差价。

## 三、彼得·林奇 — 六类股的各自卖出信号

### 核心原则

**"不同类型的股票不能互相比较——卖出信号取决于股票类型。"** 林奇把股票分成六类，每类的持有和卖出规则完全不同。关键是：同一只股票的卖出信号可能在买入时就已确定。

### 卖出触发条件（清单式）

#### 1. 缓慢增长型（增速<5%，高股息）
| # | 触发条件 | 操作 |
|---|---------|------|
| 1 | 股价涨30-50%后（典型涨幅空间到了） | 卖出 |
| 2 | 股息率降到历史低点 | 卖出 |
| 3 | 公司失去提价能力或市场份额 | 卖出 |

#### 2. 稳定增长型（增速8-12%）
| # | 触发条件 | 操作 |
|---|---------|------|
| 1 | PEG > 1.5（偏贵） | 减仓 |
| 2 | PEG > 2.0（太贵） | 卖出 |
| 3 | 连续2个季度增速低于预期 | 减仓观察 |
| 4 | PE超过行业均值50%以上 | 卖出 |

#### 3. 快速增长型（增速20%+）— 林奇最擅长
| # | 触发条件 | 操作 |
|---|---------|------|
| 1 | 增速放缓到25%以下（关键拐点） | 减半仓 |
| 2 | 新业务/新产品故事无法兑现 | 卖出 |
| 3 | 公司在多个领域盲目扩张 | 卖出 |
| 4 | 管理层开始卖出股票 | 警惕/减仓 |
| 5 | PEG > 2.0 | 卖出 |
| 6 | 机构持股比例过高（所有人都知道了） | 减仓 |

#### 4. 周期型
| # | 触发条件 | 操作 |
|---|---------|------|
| 1 | 库存积压、产能过剩信号出现 | 卖出 |
| 2 | PE最低时（盈利顶峰）→ 卖出 | 反向操作 |
| 3 | 竞争者大量涌入 | 卖出 |
| 4 | 行业景气度见顶指标（如汽车销量/房价见顶） | 清仓 |

> **林奇名言：** "周期股的投资秘诀是在行业最糟糕的时候买入，在行业最好的时候卖出。当所有人都说周期结束了——那就是卖出的时候。"

#### 5. 困境反转型
| # | 触发条件 | 操作 |
|---|---------|------|
| 1 | 反转成功后股价翻了3-10倍 | 卖出大部分 |
| 2 | 反转逻辑兑现，公司恢复常态 | 重新归类后按新类型管理 |
| 3 | 反转失败（债务问题恶化/重组失败） | 立即止损 |

#### 6. 隐蔽资产型
| # | 触发条件 | 操作 |
|---|---------|------|
| 1 | 资产价值被市场重估，股价接近内在资产价值 | 卖出 |
| 2 | 被收购/私有化完成 | 卖出 |
| 3 | 核心资产被出售后 | 卖出 |
| 4 | 管理层开始浪费资产价值 | 卖出 |

### 典型案例

- **克莱斯勒（周期股）：** 林奇在汽车行业最糟糕时买入克莱斯勒，在行业复苏、PE被压缩到极低时卖出。不是因为PE低所以便宜（周期股PE最低时反而是顶部），而是因为"每个人都在称赞周期的结束"。
- **Dunkin' Donuts（快速增长型）：** 林奇持有到增速放缓才卖，期间股价涨了10倍。他不是在高PE时卖，而是在增速拐点出现时卖。
- **PEG统一框架：** PEG < 0.5重仓、0.5-1.0持有、1.0-1.5减仓、> 2.0卖出——这是林奇跨类型的统一估值标尺。

## 四、张磊（高瓴资本）— 长期结构性变化逆转退出

### 核心原则

**"找到最好的公司，做时间的朋友。很多人问我什么时候卖，我的答案是不卖。"** 张磊的"不卖"是建立在结构性变化趋势之上的——只要结构性趋势还在，就不卖。卖出只有一个理由：**当初投资的结构性逻辑被颠覆了**。

### 卖出触发条件（清单式）

| # | 触发条件 | 判断标准 | 操作 |
|---|---------|---------|------|
| 1 | 商业模式被颠覆 | 新技术/新模式完全替代旧模式（如功能机→智能机） | 清仓 |
| 2 | 管理层变质 | 创始人心态变化、不再有格局、执行力下降、学习能力消失 | 清仓 |
| 3 | 结构性的行业变化转向相反方向 | 政策颠覆（如教培双减）、技术路线终结、消费习惯根本逆转 | 清仓 |
| 4 | 极端估值泡沫 | 估值到达不可持续的程度（张磊本人可能不减仓，但散户必须减） | 减仓 |
| 5 | 哑铃两端失衡 | 传统端或成长端比例严重偏离目标（40%/60%） | 再平衡 |

### 不卖的情况

```
下列情况在张磊框架中不构成卖出理由：
✗ 股价下跌50%        → 反而加仓
✗ 短期业绩不及预期    → 持有观察
✗ 宏观经济波动        → 忽略
✗ 市场情绪悲观        → 不关注
✗ 估值偏高（PE 40-80）→ 如果增速匹配，可以接受
```

### 典型案例

- **腾讯（2005年→至今）：** 张磊2005年重仓腾讯，经历了2008年金融危机、2011年PC→移动转型、2018年游戏版号停发——所有这都不是卖出理由，因为"中国互联网结构性增长"这个大的逻辑没有变。
- **百丽国际（私有化）：** 2017年张磊以531亿港元私有化百丽（当时市场认为鞋业已死）。他的判断是：百丽的渠道价值+供应链能力可以被数字化改造，结构性的价值没有被市场理解。这不是卖出，而是"买入更多并参与改造"。
- **京东（2010年）：** 张磊给京东3亿美元时，刘强东想要7500万美元。张磊说："要么拿3亿，要么一分不给。"因为他看到的是"重资产自建物流"这个结构性机会，不是短期盈利。
- **教培行业（2021年清仓）：** 当"双减"政策出台，行业结构性逻辑被彻底颠覆（这不是周期性波动），高瓴清仓——这是"结构性的变化逆转"的典型案例。

### ⚠️ 风险提示

> 张磊可以承受50%回撤不动，因为他管的是10年期的钱。散户没有这个条件。鳄鱼派的止盈止损纪律必须优先于张磊的"不卖"哲学。

## 五、冯柳（高毅资产）— 赔率不再有利时退出

### 核心原则

**"承认自己是弱者，不与市场争对错，只做大概率和高赔率的决策。"** 冯柳的卖出不是"估值高了"或"涨了多少"，而是**赔率结构变了**——上涨空间与下跌空间的比不再有利。

### 卖出触发条件（清单式）

| # | 触发条件 | 量化标准 | 操作 |
|---|---------|---------|------|
| 1 | 赔率降到2:1以下 | (目标价-现价)/(现价-硬底价) < 2.0 | 寻找轮动标的 |
| 2 | 找到赔率4:1以上的更好的标的 | 候选标的赔率 > 4.0 | 从低赔率轮动到高赔率 |
| 3 | 趋势类机会——趋势破坏 | MA20跌破MA60 或 月线MACD死叉 | 退出 |
| 4 | 价值类机会——估值已达到合理 | PB回到1倍以上 或 PE回到历史中位数 | 退出或减仓 |
| 5 | 博弈类机会——共识已反转 | RSI从<25回到50以上+成交量放大 | 退出 |
| 6 | 可认知层级降级 | 从"可想象/可展望"降级到仅"可理解" | 减仓 |
| 7 | 选股逻辑被证伪 | 买入时的核心假设被市场否定 | 立即退出 |

### 冯柳的特殊性：永远满仓轮动

> **冯柳本质上不"卖出"，只"换仓"。** 他永远满仓，靠轮动来控制风险——从低赔率标的换到高赔率标的。这与鳄鱼派的"减仓/空仓等待"有根本区别。

```
冯柳的轮动逻辑：
  持仓A（赔率 1.8:1）→ 赔率偏低
  ↓
  发现候选B（赔率 4.5:1）→ 赔率极佳
  ↓
  从A切换到B（不是卖出，是换仓）
```

### 典型案例

- **茅台（2013-2015年）：** 冯柳在茅台遭遇"八项规定"利空时买入（博弈类机会），持有到市场共识恢复。当茅台的估值回升到合理水平、赔率不再突出时，他逐步换到其他标的。不是不看好茅台，而是赔率不再是最优。
- **海康威视（2018年）：** 在中美贸易摩擦导致海康估值被杀到历史低点时买入（价值类机会），当贸易摩擦缓和、估值回归后退出。
- **轮动的哲学：** "选股票就像选美——不选自己觉得最美的，选裁判（市场）最终会认为最美的。一旦裁判的打分已经反映在价格里，就该换下一个。"

### 量化赔率公式

```
赔率 = (目标价 × 0.7 - 当前价) / (当前价 - 硬底价)

硬底价 = max(净清算价值, 股息支撑价, 前低支撑位)
目标价 = 分析师一致预期（打折处理）

冯柳门槛：赔率 ≥ 3:1 才买入
                   ≥ 2:1 继续持有
                   < 2:1 考虑轮出
```

## 六、邱国鹭（高毅资产）— 品质/估值/机会三角卖出

### 核心原则

**"数月亮不数星星——选已经赢了的公司，等它过贵了或变坏了再卖。"** 邱国鹭的卖出框架最为简洁，只有三条理由——买错了、变贵了、有更好的。这三个理由对应品质、估值、机会三个维度。

### 卖出触发条件（清单式）

| # | 触发条件 | 判断标准 | 操作 |
|---|---------|---------|------|
| 1 | **买错了** — 买入逻辑被证伪 | 基本面恶化、行业格局改变、管理层变坏 | 立即卖出，不等待 |
| 2 | **变贵了** — PE超过历史90%分位 | PE > 历史5年90%分位 或 大盘PE > 25 | 逐步减仓至50%以下 |
| 3 | **有更好的** — 发现赔率更好的标的 | 新标的质量相当但估值低30%+ | 换仓 |
| 4 | 品质降级（新增触发） | ROE连续2年<15%、毛利率持续下滑、护城河变窄 | 卖出 |
| 5 | 大盘系统性高估 | 大盘PE > 25时整体仓位降至50%以下 | 系统性减仓 |

### 与冯柳的关键区别

```
冯柳卖出 = 赔率驱动（数学计算）
邱国鹭卖出 = 逻辑驱动（品质/估值判断）

冯柳：赔率<2:1 → 轮出（不论公司好坏）
邱国鹭：品质不变 → 可以不卖（即使赔率降低了）
       品质变坏 → 必须卖（不论赔率好坏）
```

### 典型案例

- **金融股（2015年牛市末期）：** 邱国鹭在2015年股灾前大幅减仓银行股，不是因为不看好银行，而是因为"银行股从PE 5倍涨到PE 10倍——虽然仍然便宜，但已经不便宜了"（PE从历史10%分位涨到70%分位）。这是"变贵了"触发。
- **某白酒股（塑化剂事件后）：** 买入逻辑是"品牌壁垒+行业格局确立"，后来品质没问题，估值回归后卖出——不是不看好，而是"找到了更好的"（更便宜的地产龙头）。
- **"跌了不加仓"：** 邱国鹭有一条重要纪律——因为跌了而卖不在框架里。跌了只会让他想加仓，但加仓的前提是"买入逻辑没变"。如果跌了是因为逻辑变了——那叫"买错了"，必须卖。

## 七、李录（喜马拉雅资本）— 文明级别的不卖哲学

### 核心原则

**"做多中国不是赌政策，是赌14亿人追求更好生活的动力不会消失。"** 李录的卖出哲学本质上就是——不卖。他的投资框架建立在文明演进（3.0文明转型）的级别上，是七位大师中卖出条件最少的。

### 卖出触发条件（清单式）

| # | 触发条件 | 判断标准 | 操作 |
|---|---------|---------|------|
| 1 | **李录三问出现任何一个"不确定"** | 20年后公司还存在吗？还是行业领导者吗？管理层值得托付20年吗？ | 不买或卖出 |
| 2 | 文明级趋势逆转 | 中国现代化进程出现根本性逆转（李录认为概率极低） | 清仓 |
| 3 | 估值疯狂 | PE超过10年中位数的1.2倍以上 | 减仓（但李录本人做得很少） |
| 4 | 管理层不再值得托付 | 管理层持股大幅下降、资本配置能力下降 | 卖出 |

### 李录 vs 张磊：两种"不卖"

```
张磊的"不卖" = 结构性趋势不变 → 不卖（5-10年视野）
李录的"不卖" = 文明级趋势不变 → 不卖（10-30年视野）

张磊卖出的阈值：商业模式被颠覆、管理层变质、极端估值泡沫
李录卖出的阈值：文明级趋势逆转、三问出现不确定

李录的卖出条件比张磊更少——因为他的投资视野更长。
```

### 典型案例

- **比亚迪（2002年→至今）：** 李录2002年买入比亚迪，持有至今超过20年，经历了汽车行业的多轮周期、电动车技术路线之争、股价巨大波动。他为什么不卖？因为"中国从2.0文明向3.0文明转型"这个大的逻辑框架里，电动车是不可或缺的一环，而比亚迪是这一环中管理最优秀的公司。
- **"不卖"的真正含义：** 李录不是死扛，而是他的投资周期（10-30年）天然跨越了市场波动。在这个时间尺度上，择时（卖出的时机选择）带来的边际收益远小于选错公司的风险。

## 九、统一卖出决策树

将所有卖出触发条件整合为一个可执行的决策树：

```
Q1：买入逻辑还在吗？
├── 否 → 立即卖出（格雷厄姆/邱国鹭/冯柳原则）
│   ├── 基本面恶化？→ 卖
│   ├── 行业被颠覆？→ 卖
│   ├── 管理层变坏？→ 卖
│   └── 上涨逻辑被证伪？→ 卖
│
└── 是 → 进入 Q2

Q2：价格合理吗？
├── 极度高估（PE > 历史90%分位 或 PEG > 2.0）
│   ├── 长期资本（张磊/李录风格）→ 不减仓
│   ├── 价值回归派（格雷厄姆/邱国鹭）→ 逐步减仓
│   └── 轮动派（冯柳）→ 继续持有但寻找更好的
│
├── 偏高（PEG 1.5-2.0 或 PE > 历史70%分位）
│   ├── 稳定成长股（林奇）→ 减仓
│   ├── 快速增长股（林奇）→ 持有观察
│   └── 周期股（林奇）→ 准备顶部卖出
│
└── 合理或低估 → 进入 Q3

Q3：有更好的机会吗？
├── 是（赔率差距 > 2:1）→ 轮换（冯柳/邱国鹭原则）
└── 否 → 继续持有（不卖）
```

## 十、与鳄鱼派「潜伏后重仓」的衔接

### 核心观念：等待

鳄鱼派的精髓是"潜伏后重仓"，即三个关键词：

1. **潜伏** = 等待买点（信号共振才入场）
2. **卖出** = 等待卖点（信号解除就出场）
3. **核心都是"等待"** — 不预测，只响应

### 七位大师卖出哲学与"等待"的映射

| 鳄鱼派阶段 | 对应卖出哲学 | "等待"什么 |
|-----------|------------|-----------|
| 潜伏（空仓等待） | 格雷厄姆：等待安全边际出现 | 等待价格跌到内在价值以下 |
| 潜伏（空仓等待） | 邱国鹭：等待利空出尽 | 等待"跌不动了"的信号 |
| 建仓（轻仓试探） | 冯柳：等待赔率合适 | 等待赔率 ≥ 3:1 |
| 重仓（信号共振） | 林奇：等待增长兑现 | 等待公司按预想路径成长 |
| 持有（不卖） | 张磊/李录：等待时间验证 | 等待结构性趋势兑现 |
| 卖出（等待卖点） | 格雷厄姆：等待价格回归内在价值 | 等待市场先生的疯狂报价 |
| 卖出（等待卖点） | 巴菲特：等待护城河被侵蚀的信号 | 等待管理层的行动/行业的改变 |
| 卖出（等待卖点） | 林奇：等待六类股各自卖出信号 | 等待增速放缓/PEG变贵/周期见顶 |
| 卖出（等待卖点） | 冯柳：等待赔率变得不利 | 等待上涨空间缩小/下跌空间扩大 |
| 卖出（等待卖点） | 邱国鹭：等待三个理由之一出现 | 等待买错/变贵/有更好的 |

### "等待"的统一框架

```
完整的投资周期 = 两次"等待"：

第一次等待：从空仓到买入（潜伏）
  等待什么？→ 安全边际出现（格雷厄姆）
            信号共振（鳄鱼派）
            赔率合适（冯柳）
            利空出尽（邱国鹭）

中间阶段：持有（等待价值兑现）
  等待什么？→ 护城河持续（巴菲特）
            结构性趋势兑现（张磊/李录）
            成长按预期（林奇）

第二次等待：从持有到卖出（等待卖点）
  等待什么？→ 价格回归内在价值（格雷厄姆）
            护城河变窄（巴菲特）
            类型信号触发（林奇）
            赔率不利（冯柳）
            品质/估值/机会三角失衡（邱国鹭）
            三问不确定（李录）

关键认知：买点和卖点都是等出来的，不是算出来的。
```

### 鳄鱼派与七位大师的融合指南

```
买入端（潜伏+重仓）：
  1. 邱国鹭四不碰 → 品质过滤（先筛掉垃圾）
  2. 冯柳赔率检查 → 赔率 ≥ 3:1（再筛赔率）
  3. 格雷厄姆安全边际 → 价格 < 内在价值（三筛价格）
  4. 鳄鱼派信号共振 → 买入（终筛时机）
  → 重仓

持有端（等待）：
  1. 李录三问 → 确认是否值得长期持有（确定持有风格）
  2. 张磊/林奇分类 → 确定退出规则（分类管理）
  3. 不因波动而卖（七位大师共识）
  → 持有

卖出端（等待卖点）：
  1. 首选检查：买入逻辑还在吗？
     → 不在 → 立即卖（七位大师统一）
  2. 次选检查：赔率是否不利？
     → 不利 → 准备轮出（冯柳/邱国鹭）
  3. 三选检查：估值是否极致？
     → 极致 → 分批卖出（格雷厄姆/林奇）
  → 卖出后回到"潜伏"状态
```

def should_sell(symbol, portfolio_context):
    """
    七位大师卖出信号的统一量化检查
    返回卖出理由列表，空列表=不卖
    """
    reasons = []
    
    # 1. 买入逻辑检查（所有大师统一优先级最高）
    if buy_thesis_broken(symbol):
        reasons.append("买入逻辑被证伪 — 立即卖出")
    
    # 2. 护城河检查（巴菲特）
    if buffett_moat_score(symbol) < 40:  # 宽>70, 窄40-70, 无<40
        reasons.append(f"护城河降级至{get_moat_level(symbol)}")
    
    # 3. 赔率检查（冯柳）
    odds = compute_fengliu_odds(symbol)
    if odds < 2.0:
        # 检查是否有更好的候选
        best_candidate = find_best_rotation_target(symbol)
        if best_candidate and compute_fengliu_odds(best_candidate) > 4.0:
            reasons.append(f"赔率{odds:.1f}:1 < 2:1，发现更好标的")
    
    # 4. 估值检查（格雷厄姆+邱国鹭+林奇）
    pe_pct = pe_percentile_5y(symbol)
    peg = compute_peg(symbol)
    if pe_pct > 0.90:
        reasons.append(f"PE处于历史{pe_pct*100:.0f}%分位 — 极度高估")
    elif peg and peg > 2.0:
        reasons.append(f"PEG={peg:.1f} > 2.0 — 太贵")
    
    # 5. 类型特定检查（林奇）
    stock_type = lynch_classify(symbol)
    type_signal = lynch_type_sell_signal(symbol, stock_type)
    if type_signal:
        reasons.append(type_signal)
    
    # 6. 结构性检查（张磊+李录）
    if structural_trend_reversed(symbol):
        reasons.append("结构性趋势逆转 — 清仓")
    if not lilu_three_questions(symbol):
        reasons.append("李录三问之一不通过 — 不适合长期持有")
    
    # 7. 品质降级检查（邱国鹭）
    if quality_score(symbol) < 5:  # 品质评分<5
        reasons.append(f"品质评分下降至{quality_score(symbol)}")
    
    return reasons

## 总结

七位大师的卖出哲学可以浓缩为 **"一个前提 + 三个检查"**：

**一个前提：** 不因为"跌了"而卖出（七位大师无一例外）。

**三个检查（按优先级）：**
1. **逻辑检查：** 当初买入的理由还在吗？不在 → 必须卖。
2. **赔率检查：** 上涨空间/下跌空间还划算吗？不划算 → 考虑轮出。
3. **估值检查：** 价格极端了吗？极致了 → 分批卖出。

**最终：** 卖出不是交易的终点，而是下一次"潜伏等待"的起点。
