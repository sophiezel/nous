# 资金管理系统 — 深蒸馏笔记

> 原著：《一个交易者的资金管理系统》| 作者：班尼特·A·麦克道尔 (Bennett A. McDowell)
> 核心主题：仓位管理与风险控制的实战手册
> 蒸馏目标：提取可执行的数学原理、仓位计算、风险应对与组合管理

## 一、核心哲学：资金管理的心理基础

### 1.1 为何资金管理比交易系统更重要

- 交易者常沉迷于"找圣杯"（完美的进场策略），但**仅靠系统无法致富**
- 资金管理是**保险**——不是"不够性感"的琐事，而是确保你**不下牌桌**的根本
- 亏损是交易的一部分——最优秀的交易者亏损笔数常大于赢利笔数，但他们通过止损和仓位控制实现了整体盈利

### 1.2 需要管理的六种交易风险

| 风险类型 | 定义 |
|---------|------|
| 交易风险 | 单笔交易可计算的风险，**唯一可控制的风险** |
| 市场风险 | 市场固有的、无法控制的风险（崩盘、黑天鹅） |
| 保证金风险 | 使用杠杆后可能倒欠经纪公司的钱 |
| 流动性风险 | 想卖没人买，或无法在合理价位成交 |
| 隔夜风险 | 收盘后发生意外，开盘跳空导致巨大亏损 |
| 波动性风险 | 市场剧烈振荡导致频繁止损 |

**首要原则**：永远不要用超过资产净值10%的资金做交易。

### 1.3 交易者的思维（15个特征摘要）

- 不关心单笔盈亏，接受风险，接受亏损为交易的一部分
- 享受过程，不被市场欺负，不愤怒
- 只用**一个系统**，不受外界影响
- 不试图征服市场，顺势而为
- 对自己所有交易结果负责

## 二、数学原理：破产风险、凯利公式与最优f

### 2.1 破产风险（Risk of Ruin, ROR）

破产风险的三个输入变量：
1. **胜率（Win Rate）** — 赢利笔数 ÷ 总笔数
2. **回报率（Reward Ratio）** — 平均每笔赢利 ÷ 平均每笔亏损
3. **风险百分比（Risk %）** — 每笔交易承受的资金百分比风险

**核心关系**：
- 胜率 ↑ → 破产风险 ↓
- 回报率 ↑ → 破产风险 ↓
- 单笔风险 % ↑ → 破产风险 ↑

### 2.2 凯利公式（最优 f 公式）

**原始凯利公式（Kelly Formula）**：

```
f = [(A + 1) × P - 1] / A
```

其中：
- `f` = 每笔交易最优的百分比风险
- `A` = 平均回报率（1美元亏损对应几美元赢利）
- `P` = 平均胜率（成功概率）

**示例计算**：
- 胜率 35%，回报率 2:1
  `f = [(2 + 1) × 0.35 - 1] / 2 = [1.05 - 1] / 2 = 0.025 = 2.5%`
- 胜率 40%，回报率 2:1
  `f = [(2 + 1) × 0.40 - 1] / 2 = [1.20 - 1] / 2 = 0.10 = 10%`

**凯利 vs 破产风险表**：凯利公式比破产风险表更激进，不会给出 0% 破产风险的结果。保守交易者应优先参考破产风险表而非凯利。

### 2.3 破产风险表使用示例（来自瑙泽·鲍尔绍拉的《期货交易者资金管理策略》）

**10% 资金风险下的破产概率矩阵（节选）**：

| 胜率 | 2:1回报率 | 3:1回报率 | 4:1回报率 |
|------|-----------|-----------|-----------|
| 25%  | 100.0%    | 99.0%     | —         |
| 30%  | 100.0%    | 27.7%     | —         |
| 35%  | 60.8%     | 8.2%      | —         |
| 40%  | 14.3%     | 2.5%      | —         |
| 45%  | 3.3%      | 0.8%      | —         |
| 50%  | 0.8%      | 0.2%      | 0.0%      |

**四个实战案例**：
1. 胜率 60%，回报率 1，风险 2% → 破产率 100% → **必须降低风险或提高回报率**
2. 胜率 55%，回报率 2，风险 2% → 破产率 16% → 风险降至 1% 后破产率降至 0.1%
3. 胜率 25%，回报率 3，风险 2% → 破产率 99.7% → **首要目标是提高胜率**
4. 胜率 50%，回报率 3，风险 2% → 破产率 0% → 高级交易者可尝试 10% 风险

### 2.4 关键统计数据的三个公式

```
胜率 = 赢利笔数 ÷ 总笔数 × 100%
回报率 = 平均每笔赢利 ÷ 平均每笔亏损
佣金率 = 总佣金 ÷ 毛利润 × 100%
```

## 三、仓位计算的具体方法

### 3.1 2% 风险公式（核心法则）

```
账户总资金 × 2% = 单笔最大风险金额
```

**示例**：$25,000 × 2% = $500（含佣金和滑点）

> **高级交易者提示**：若系统胜率与回报率数据充分，可突破 2% 限制，参考凯利公式或破产风险表确定最优风险百分比。

### 3.2 交易量公式（Position Sizing）

```
(风险金额 - 佣金) ÷ (进场价 - 止损价) = 交易量（股数/合约数）
```

**无杠杆示例**：
- 账户：$25,000
- 单笔风险：$500（2%）
- 股票 MSFT 进场价：$60.00
- 初始止损价：$58.50
- 价差：$1.50
- 佣金：$80（来回）
- 交易量：($500 - $80) ÷ $1.50 = **280 股**

**使用杠杆示例**：
- 账户：$50,000
- 杠杆：150%（总购买力 $75,000）
- 风险按 $50,000 的 2% 计算：$1,000
- IBM 进场价：$91.49，止损价：$90.20
- 价差：$1.29，佣金：$51.20
- 交易量：($1,000 - $51.20) ÷ $1.29 = **753 股**

### 3.3 仓位计算的三要素

正确的仓位计算依赖三个变量的协同控制：
1. **进场点** — 系统决定，基于市场动力
2. **出场点（止损）** — **必须在进场前确定**，基于市场动力（关键支撑/阻力位）
3. **交易量** — 通过公式反推，确保风险可控

## 四、止损出场原则

### 4.1 七种基本止损点

1. **初始止损**：进场前确定的止损位置，用于计算仓位大小
2. **跟踪止损**：随着利润累积逐步移动止损点
3. **阻力止损**：在阻力位设置的跟踪止损
4. **3条竹线跟踪止损**：趋势可能衰竭时使用
5. **1条竹线跟踪止损**：快速锁定利润
6. **趋势线止损**：在趋势线外侧设置
7. **回归通道止损**：利用回归通道外侧

### 4.2 止损核心原则

- **必须根据市场动力设置止损**，不能随意设定等额止损（如"亏200美元就平"）
- 止损点应放在关键支撑/阻力位之外，给予市场充分的"呼吸空间"
- 初始止损点**一旦设定，不能因情绪而移动**
- 加仓后必须调整整体仓位的止损点

### 4.3 隔夜持仓五原则（日内交易者）

1. 该交易当前**必须是赚钱的**
2. 短周期图（如15分钟图）必须显示明确趋势
3. 必须根据**日线图**设置止损点
4. 按日线止损点重新计算交易量，控制风险在 2% 以内
5. 第二天开盘务必紧盯开盘价

## 五、连续亏损的应对策略

### 5.1 交易记录中必须追踪的关键指标

| 指标 | 用途 |
|------|------|
| 最多连续亏损笔数 | 预估正常回撤深度 |
| 平均连续亏损笔数 | 心理学参考 |
| 资金曲线最大下跌 % | 压力测试底线 |
| 资金曲线平均下跌 % | 正常波动范围 |

### 5.2 具体应对规则

**当资金曲线下跌时：**
- 下跌 10% 时：**减少交易量**（参考破产风险表或凯利公式）
- 连续止损 7 次时：**减少交易量**
- 下跌 15% 时：**停止实战交易**，切换至模拟交易直到盈利
- 连续 25 笔交易整体亏损：**停止实战**，开始模拟寻找问题

**分析资金曲线下跌时需自问的问题：**
- 是正常的系统概率导致的下跌，还是人为错误？
- 是否遵守了所有交易系统原则？
- 进场前是否设置了止损点？
- 是否及时止损了？

### 5.3 假期规则（何时停止交易）

| 时间维度 | 触发条件 |
|---------|----------|
| 一天内 | 连续亏2~3笔，或亏损$500~$1000 |
| 一周内 | 连续亏2~3笔，或亏损$1000~$2000 |
| 一个月内 | 账户亏损10%，或交易25笔后仍亏损 |

## 六、多品种/多策略组合管理

### 6.1 整体账户风险控制

- **单笔风险上限**：每笔交易 ≤ 2%
- **整体账户风险上限**：建议 ≤ 6%~10%
  - 6% 方案：同时交易 3 笔，每笔 2%
  - 10% 方案：同时交易 5 笔，每笔 2%
- **板块分散**：每个板块风险不超过 2%
  - 例如：科技板块 2% + 能源板块 2% + 外汇板块 2% = 整体 6%

### 6.2 净值风险管理

- 活跃交易账户风险 ≤ 个人净值的 **10%**
- 随着净值增长，定期重新评估风险金额

### 6.3 逐级加仓（Scaling In）原则

- **只在盈利时加仓**，绝不在亏损时向下摊平成本
- 加仓前确保跟踪止损点已在成本价之上
- 加仓后按新的总仓位和止损点重新计算整体风险
- 向下摊平成本 = 输家的做法（无视初始仓位风险，无脑增加风险暴露）

### 6.4 逐级平仓（Scaling Out）原则

- 初始仓位必须足够大（至少3份合约/股）才能逐级平仓
- 典型模式：平仓 1/3 → 平仓 1/3 → 最后 1/3 用止损出场
- 目的：锁定利润 + 减少焦虑，让剩余仓位能长期持有
- 示例（$25,000 账户，做空电子迷你盘）：
  - 风险 $500（2%），买入6份合约
  - 第一信号平掉30% → 第二信号再平30% → 剩余40% 用止损锁定

## 七、与鳄鱼派「重仓」原则的风险对冲

### 7.1 直接对冲思路

麦克道尔的资金管理系统与鳄鱼派"重仓"原则在根本上对立：

| 维度 | 本书原则 | 鳄鱼派重仓 |
|------|---------|-----------|
| 单笔风险 | ≤2% | 可达10%~25% |
| 杠杆使用 | 谨慎，风险基于本金计算 | 积极使用杠杆放大 |
| 止损方式 | 基于市场动力的宽止损 | 基于净值的紧止损或不止损 |
| 破产概率 | 趋向0% | 较高 |
| 核心目标 | 不下牌桌，稳定复利 | 高赔率下的暴利 |

### 7.2 可借鉴的折中方案

1. **用凯利公式而非固定 2%**：如果你的系统胜率 40%、回报率 3:1，凯利建议 6.67% 风险——这比 2% 激进，但比"重仓"的 10~25% 温和
2. **破产风险表校验**：即使想冒更高风险，也要先查破产风险表，确认破产率在可接受范围内
3. **动态调整仓位**：账户增长后逐步提升仓位，而非一开始就重仓
4. **分散对冲**：重仓单一品种时，用其他低相关品种分散 6%~10% 的整体风险

### 7.3 风险管理是最好的"重仓保险"

鳄鱼派如果能接受以下约束，则重仓方案的风险大幅降低：
- 单笔重仓 + 严格止损（跳空风险仍需注意）
- 整体账户暴露不超过净值的 10%
- 连续亏损 3 笔后自动降仓
- 每月/每季做一次破产风险复盘

## 八、自我诊断工具

### 8.1 风险概况评分表

| 问题 | 低风险(5分) | 中风险(10分) | 高风险(15分) |
|------|-------------|--------------|-------------|
| 当前交易的市场 | 债券/无杠杆 | 股票 | 期货/杠杆 |
| 过去1年收益率 | ≥50% | 10%~50% | <10%或亏损 |
| 平均胜率 | 50%~100% | 35%~50% | 0%~35% |
| 风险忍受度 | 喜欢低风险 | 接受中等风险 | 享受高风险 |
| 交易水平 | 持续盈利 | 盈亏平衡 | 亏损/无经验 |
| 平均回报率 | ≥3 | 2~3 | <2 |

**评分结论**：
- 30~50分：可尝试更高风险（2%→3%），但下跌时立刻降回
- 50~70分：风险适中，继续保持
- 70~90分：应降低风险（2%→1.5%），减少过度交易

### 8.2 纪律性评分表

**30~50分**：高度自律，可轻松执行系统
**50~70分**：全脑思考者，状态良好
**70~90分**：需花额外精力做交易记录和分析

## 九、设计自己的资金管理系统（五步法）

### 步骤1：确定每笔交易亏损百分比

- 新手：固定 2%
- 进阶：根据月度胜率与回报率计算凯利公式
- 高级：结合破产风险表选择最优风险百分比
- 资金曲线下跌后：风险减少 25%（如 2% → 1.5%）

### 步骤2：确定交易量计算方法

- 使用交易量计算器或手动公式
- 用第10章的公式：`(风险 - 佣金) ÷ (进场 - 止损) = 交易量`

### 步骤3：确定整体账户风险上限

- 6%（3笔各2%）或 10%（5笔各2%）
- 每个板块不超过 2%

### 步骤4：确定净值风险上限

- 活跃交易账户 ≤ 净值的 10%

### 步骤5：确定出场和交易记录原则

- 进场前确定止损点
- 用跟踪止损锁定利润
- 每日/每周/每月/每年做交易记录
- 持续跟踪胜率、回报率、佣金率、最大回撤等核心指标

## 十、模拟交易验证流程

### 从模拟到实战的 10 步计划

1. 书面化交易原则和资金管理原则
2. 开始模拟交易（与实战相同的时间框架）
3. 用交易者助理系统记录和评估业绩
4. 将 **25 笔交易视为一大手**
5. 持续练习直到盈利
6. 实现**连续 3 大手盈利**后转入实战
7. 实战中继续按 25 笔一大手分析业绩
8. 实战 25 笔后仍未盈利 → 回到模拟交易
9. 连续 6 笔亏损或回撤 15% → 检讨市场周期/时间框架变化
10. 资金曲线严重下跌时：停止实战 → 模拟交易验证 → 25 笔连续盈利后恢复实战
