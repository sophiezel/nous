## 一、N字形态的定义与识别规则

### 1.1 理论基础

N 字理论由台湾数学教授李进财创立，是用严格定义的 N 字形态量测出向上或向下攻击的 K 线力道，由 K 线力道研判盘态与后市走势，最终找出趋势方向与下单依据。

**核心特点**：每个定义清晰明确，无模棱两可；可用计算机程序实现智能识别。

### 1.2 基本形态

| 形态 | 构成 | 含义 |
|------|------|------|
| **正N字** | 两低夹一高，突破前高形成 | 多头攻击形态（最小攻击形态） |
| **倒N字** | 两高夹一低，跌破前低形成 | 空头攻击形态 |

**识别口诀**：
- 两高一低，跌破低点形成 **倒N字**
- 两低一高，突破高点形成 **正N字**

### 1.3 从 V 字理解 N 字

- **V字** = 两高一低（单一转折，无趋势力道发动）
- **倒V字** = 两低一高（单一转折）
- V字的两个高点中间夹一个低点 → 跌破该低点 → **倒N字**
- 倒V字的两个低点中间夹一个高点 → 突破该高点 → **正N字**

### 1.4 关键点位定义

| 术语 | 定义 | 作用 |
|------|------|------|
| **轧空K线** | 形成正N字的K线 | 多头攻击起点 |
| **杀多K线** | 形成倒N字的K线 | 空头攻击起点 |
| **轧空低点** | 轧空K线的最低点 | 正N字止损位 |
| **杀多高点** | 杀多K线的最高点 | 倒N字止损位 |
| **末升低点** | 上升趋势中最后一个回调低点 | 趋势止盈/止损跟随点 |
| **末跌高点** | 下降趋势中最后一个反弹高点 | 趋势反转参考点 |

### 1.5 一饱二吐（目标位量测）

N 字形成后，用量测目标预估涨幅/跌幅：

- **一饱（第一目标位）**：N 字形态高度的 1 倍
- **二吐（第二目标位）**：N 字形态高度的 2 倍（力道强劲时可达）

计算方法：以 N 字（或倒 N 字）的起点到转折点的垂直距离，加上突破点/跌破点的价位。

> 注："一饱"即吃饱，"二吐"即吃到吐——形容力道发挥的程度。

## 二、入场信号

### 2.1 核心原则：先止跌，再找攻击

**N 字理论抄底铁律**：
1. 先找 **止跌信号**（刹车）
2. 止跌信号出现后，找 **攻击买点**（再次启动）
3. 没有止跌信号 → 没有买入理由（避免接下坠的刀子）

同理，顶部操作：先找止涨信号，再找卖出点。

### 2.2 顺势买入（突破买入）

| 战法 | 说明 |
|------|------|
| **N字突破追买** | N 字形态形成、突破前高时买入，止损位设在轧空低点 |
| **过前高轧空波段追买** | 价格突破前高后，确认轧空力道延续时追入 |
| **补缺不回追买** | 跳空缺口被回补后不破低点，再次上攻时买入 |

### 2.3 逆势买入（回调买入）

| 战法 | 说明 |
|------|------|
| **一止跌、二突破、拉回找买点** | 止跌信号出现→突破关键位→回测不破时买入 |
| **多头抵抗找买点** | 下跌过程中，空头力道衰竭、多头开始抵抗时买入 |
| **月线负背离找买点** | 大周期（月线）出现底背离时，找小周期买点介入 |

### 2.4 N 字交易系统的买点特征

- 包含 **18 种以上高胜率买点**
- 每个买点同时标示 **止损位** 和 **目标位**
- 每个买点配有 **资金使用比例** 建议

## 三、出场/止盈规则

### 3.1 目标位止盈（一饱二吐）

- N 字形成后，系统绘制虚线作为利润目标价位
- 股价到达 **一饱目标位** → 可考虑卖出部分或全部
- 股价到达 **二吐目标位** → 大概率涨势衰竭，应考虑全出
- 同时也需参考近期压力 K 线和远期压力 K 线位置

### 3.2 趋势止盈法（末升低点跟随）

- 上升趋势中，**末升低点** 随走势不断抬高
- 只要价格不跌破末升低点，一路持有
- 跌破末升低点 → 卖出全部筹码
- 这是一种"赚就赚一波段"的操作方法

### 3.3 止损止盈线（台阶式）

- N 字交易系统的台阶式趋势线，智能跟随趋势
- 既不会因小幅震荡被洗出，也不会设得太远损失过大
- 止损止盈线基于 N 字理论的关键支撑位

### 3.4 高抛低吸策略

- 在上涨趋势中，当总资金使用比例降低到一定程度（往往是某涨升波段的高点）
- 可适当降低仓位，取回部分获利
- 等价位回到止损止盈线附近时，再找买点介入

## 四、止损设置

### 4.1 止损位的确定

| 形态 | 止损位 |
|------|--------|
| 正N字买入 | **轧空低点**（形成 N 字那根 K 线的最低点） |
| 倒N字做空 | **杀多高点**（形成倒 N 字那根 K 线的最高点） |
| 回调买入 | 止跌信号前的最低点 |
| 突破买入 | 突破 K 线的低点 |

### 4.2 实破与虚破

- **虚破**（盘中跌破）：盘中短暂跌破止损位
- **实破**（收盘跌破）：收盘价低于止损位 → **执行出场**

N 字交易系统以 **收盘价跌破** 为出场依据。
- 上班族：可在尾盘预知无法站上止损位时卖出
- 无法盯盘者：可于第二日开盘价卖出

### 4.3 资金管理中的止损

- 每笔交易风险控制在 **总资金的 2%~3%**
- 止损位与建仓价位的距离 × 持仓比例 = 单笔最大亏损
- 通过资金控制比例联动，确保每次止损不超过总资金的 2%~3%

## 五、N字形态在不同时间框架的应用

### 5.1 三重滤网法

| 层级 | 周期 | 作用 |
|------|------|------|
| **第一层** | 月线 | 判断大趋势方向（打底/轧空/追杀） |
| **第二层** | 周线 | 中期趋势确认 |
| **第三层** | 日线/分时 | 精准买卖点 |

**原则**：大周期定方向，小周期找点位。大周期与小周期相互制约、相互协同。

### 5.2 长线保护短线

- 长线趋势看好（不跌破止损止盈线）→ 短线出现高点时可高抛
- 短线高抛的勇气来自长线框架的保护
- 跌破长线关键位时，无论短线如何都应出场

### 5.3 适应各种盘态

N 字理论将盘态分为 **六大盘态**（每种又分六种，共 36 种走法）：

| 盘态 | 操作策略 |
|------|----------|
| 轧空盘（单边上涨） | 波段持有，趋势止盈 |
| 追杀盘（单边下跌） | 空仓或做空 |
| 盘坚盘 | 可参与，注意节奏 |
| 盘跌盘 | 观望或轻仓 |
| 盘整盘 | 高抛低吸，快进快出 |
| 多空交替 | 根据 N 字形态判断转向 |

## 六、与趋势交易法的互补关系

### 6.1 N 字理论 vs 传统趋势交易

| 对比维度 | 传统趋势交易 | N 字理论 |
|----------|-------------|----------|
| 趋势判断 | 均线系统（MA/MACD） | N 字形态 + 关键点位 |
| 入场点 | 均线金叉/突破 | N 字突破/回调确认 |
| 止损位 | 均线下方 | 轧空低点（精确价位） |
| 目标位 | 无明确量测 | 一饱二吐（精确量测） |
| 盘态适应 | 单边市场有效，盘整失效 | 六大盘态全覆盖 |

### 6.2 N 字理论的补充优势

1. **最小攻击形态** — 比波浪理论更细致，从最小攻击起点开始观察
2. **力道量化** — 一饱二吐将趋势力道数字化
3. **贯穿所有理论** — N 字理论如同串起珍珠的项链，能解释所有 K 线理论和指标
4. **提前预判盘态** — 比传统形态学更早发现盘整/突破/反转

### 6.3 结合使用方法

```
趋势交易法（大周期定方向）
        ↓
N 字理论（中周期确认盘态）
        ↓
N 字形态（小周期找买卖点）
        ↓
一饱二吐（量测目标位）
        ↓
轧空低点/末升低点（设止损止盈）
```

- **趋势交易法** 提供大周期的方向判断
- **N 字操盘法** 提供精确的进出场点和目标测算
- 两者结合 = 完整的趋势跟随交易系统

### 6.4 关于追涨杀跌

N 字理论认为，**追涨杀跌才是真正的顺势而为**：
- 追涨在起涨处（不是追高在顶部）
- 杀跌在起跌处（不是杀低在底部）
- 看似追涨，实际是在抄底——因为追的是盘态转强后的起涨点

## 七、N字理论的核心哲学

1. **风险利润比优先** — 每次出手前先计算最大亏损（止损位）和预期利润（目标位）
2. **大赚小赔** — 赚就赚一波段，赔只赔一小段（总资金的 2%~3%）
3. **以不变应万变** — 不变的 N 字理论应万变的市场盘态
4. **综合研判** — 不能只用一招一式硬套，要结合多周期、多因素分析
5. **应变重于预测** — 重点不是预测准不准，而是出现各种情况时如何应对

## 八、关键交易规则速查

| 场景 | 规则 |
|------|------|
| 正N字出现 | 突破前高买入，止损设在轧空低点，目标看一饱二吐 |
| 倒N字出现 | 跌破前低卖出/做空，止损设在杀多高点 |
| 上升趋势中 | 末升低点不断抬高，不破不出 |
| 下跌趋势中 | 先找止跌信号，再找攻击买点 |
| 盘整盘中 | 等待突破方向，突破高点追涨，跌破低点杀跌 |
| 止损执行 | 收盘价跌破止损位即出场 |
| 资金管理 | 单笔最大亏损 ≤ 总资金的 2%~3% |
| 多周期分析 | 月线→周线→日线，大周期定方向，小周期找点位 |
