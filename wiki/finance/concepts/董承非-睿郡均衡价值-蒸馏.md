# 董承非（睿郡资产）— 均衡价值生存之道

> **浓缩金句：** "在A股这个大波动的市场里，活下去比赚得多更重要。"

## 一、战绩概览

- 前兴全基金副总经理，管兴全趋势15年年化约17%
- A股极少数经历过2008、2015、2018三次大熊市且全部存活下来的基金经理
- 2022年转战私募睿郡资产
- 风格：极度均衡、永不极端、活下来第一

## 二、核心理念：均衡是最大的风控

董承非和前面所有人的最大区别——他不追求极致，他追求**不犯大错**。

```
其他人 → 找到最好的 → 重仓 → 暴赚或暴亏
董承非 → 找到最稳的 → 分散 → 稳赚少亏
```

### 均衡的三层含义：

**行业均衡：**
- 单行业上限 20%（比邱国鹭的30%更保守）
- 至少覆盖 5 个以上行业
- 周期+成长+消费+金融+公用事业 缺一不可

**风格均衡：**
- 价值股 40%（高股息+低PE）+ 成长股 40%（高ROE+高增速）+ 现金 20%
- 不因为看好成长就全仓成长

**时间均衡：**
- 分批建仓，每批间隔至少1个月
- 不一次性打满仓位

## 三、可量化规则

```python
def dongchengfei_balance_check(portfolio):
    """检查组合是否均衡"""
    warnings = []
    
    # 行业集中度
    max_sector_weight = max_sector_concentration(portfolio)
    if max_sector_weight > 0.20:
        warnings.append(f"单行业{max_sector_weight:.0%}>20%")
    
    # 行业数量
    sectors = unique_sectors(portfolio)
    if len(sectors) < 5:
        warnings.append(f"仅覆盖{len(sectors)}个行业，需≥5")
    
    # 现金比例
    cash_pct = get_cash_ratio(portfolio)
    if cash_pct < 0.10:
        warnings.append(f"现金{cash_pct:.0%}<10%")
    
    # 个股集中度
    for pos in portfolio:
        if pos["weight"] > 0.08:
            warnings.append(f"{pos['name']}单票{pos['weight']:.0%}>8%")
    
    return warnings
```
