# 查理·芒格 — 多元思维+误判心理学

> **浓缩金句：** "反过来想，总是反过来想。如果我知道我会死在哪里，我就永远不去那里。"

## 一、补什么缺口

**补：元原则层——所有操盘手之上的"操作系统"。** 已有20人的具体方法论，但缺一个"思维检查层"——在做任何决策之前，先问：我会不会在犯芒格说的那种错？

## 二、核心理念

芒格不教你怎么选股，他教你怎么不犯蠢。

### 误判心理学清单（25种倾向中的5个最致命的投资错误）

```
1. 确认偏误 → 只看支持自己持仓的信息，忽略反面
   自检：我是不是在找理由不卖？是不是在选择性阅读？

2. 损失厌恶 → 亏损时死扛，盈利时急着卖
   自检：如果我现在空仓，我会买这只票吗？不会→该卖

3. 过度自信 → 以为自己能预测市场
   自检：我对这个判断的确信度有数据支持吗？还是感觉？

4. 从众心理 → 别人都在买/卖所以我也买/卖
   自检：我在独立判断还是在跟风？

5. 锚定效应 → 被买入价锚定，不肯认错
   自检：我的判断基于"买入价"还是"当前价值"？
```

## 三、可量化规则

### 芒格式决策自检表
```python
def munger_decision_check(decision):
    """任何重大交易前必须通过的五问"""
    checks = []
    
    # 1. 逆向思考
    checks.append(("如果这个决定是错的，最可能的死法是什么？", 
                   identify_failure_mode(decision)))
    
    # 2. 确认偏误
    checks.append(("我找了多久的反面证据？", 
                   "pass" if searched_counter_evidence else "fail"))
    
    # 3. 能力圈
    checks.append(("这在我的能力圈内吗？", 
                   "pass" if inside_circle_of_competence(decision) else "fail"))
    
    # 4. 激励
    checks.append(("谁在靠这个决定赚钱？", 
                   check_incentives(decision)))
    
    # 5. 延迟判断
    checks.append(("能不能等24小时再决定？", 
                   "如果可以等=信号不够强"))
    
    fails = [c for c in checks if c[1] == "fail"]
    return ("通过" if len(fails) == 0 else f"未通过: {[c[0] for c in fails]}")
```

## 四、系统注入

芒格作为**所有决策的最后一道闸门**——不做量化评分，做"芒格自检"。

```
任何买入/卖出/重仓决策 → 鳄鱼派+各通道审批 → 芒格自检表 → 
  → 5问全过 → 执行
  → 有fail → 延迟24小时再判断
```

> "如果你不能通过芒格的自检表，你大概率在犯蠢。"
