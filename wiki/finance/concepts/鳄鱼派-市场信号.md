# 鳄鱼派市场信号体系

## 两只脚理论

> 指数不论是上涨还是下跌，看两只脚。科技和金融，有一个在涨，指数就跌不深；有一个在跌，就涨不高。两个一起涨是最好的盘面；两个一起跌，指数就拉稀。

### 大小儿子隐喻（2026.5.25补充）

> 小儿子（科技）是继续集万千宠爱于一身，越涨越出利好。大儿子（金融等弱势板块）是继续夹缝中生存，越弱越不受资金待见。大儿子不单指金融，也包括其他类似走势的板块。

**深化规则**（来源: 文章#2, 2026.05.25）:
- 小儿子（科技）：集万千宠爱于一身，越涨越出利好
- 大儿子（弱势板块）：不单指金融，也包括其他类似走势的板块（如地产、消费等低位板块）
- 大儿子继续夹缝中生存，越弱越不受资金待见
- 仅极少数长线资金在逢低打底大儿子

### 量化映射 — 科技+大金融排列组合

#### 五种场景（来源: 文章#12）
替代原有4场景模型，更精确刻画科技与金融互动：

| # | 科技状态 | 大金融状态 | 指数方向 | 操作 |
|---|---------|-----------|---------|------|
| 1 | ✅ 良性轮动+火车头新高 | 有板块走趋势 | 指数新高概率大，普涨行情 | 可重仓 |
| 2 | ✅ 良性轮动+火车头新高 | 无板块走趋势 | 指数震荡，科技吸血其他板块 | 持仓科技 |
| 3 | ❌ 轮动不良性+仅抱团火车头 | 无趋势 | 指数震荡回调概率大 | 减仓 |
| 4 | ❌ 科技熄火 | 有板块走趋势 | 指数宽幅震荡，换主线概率大 | 观望换仓 |
| 5 | ❌ 科技熄火 | 无趋势 | 指数拉稀概率大 | 空仓 |

```python
def two_feet_signal(tech_change, fin_change) -> str:
    if tech_change > 0 and fin_change > 0: return '共振上涨'
    elif tech_change > 0 or fin_change > 0: return '跷跷板'
    else: return '共振下跌'
```

## 交易拥挤度（新增 2026.5.25）

> 成交额百亿以上的个股29只，科技占27只。市场放量三千亿，却依然是普跌。不论是增量还是存量短线资金，都在做一件事：卖其他，买科技。

### 拥挤度演化路径
**来源**: 文章#1 (2026.05.26), 文章#2 (2026.05.25)

拥挤度演化：**资金集中度（初期/中期，正面）→ 交易拥挤度（后期，负面）**

- **资金集中度** = 正面，代表市场资金不杂乱、合力打造赚钱效应
- **交易拥挤度** = 负面，资金过度集中于单一板块，形成踩踏风险
- 如同"屠龙少年→恶龙"的异化过程（详见 [[鳄鱼派-核心体系#屠龙到化龙]]）

### 拥挤度量化分界

| 指标 | 正常（资金集中度） | 预警区 | 危险（交易拥挤度） |
|------|------|------|------|
| 百亿成交个股中科技占比 | <60% | 60-85% | >85% |
| 放量但普跌 | 否 | 偶尔 | 持续 |
| 增量资金方向 | 分散 | 集中 | 单押 |

当前(2026.5.25): 科技占百亿成交93%(27/29) → 🔴 极度拥挤

**历史出现拥挤度极值记录**: 去年2次、今年2月1次、本次（2026.5.26）为第4次

### 拥挤度下跌三大征兆
1. 百亿科技占比 > 85%
2. 放量但普跌（卖其他买科技）
3. 增量资金单押科技

**操作**: 拥挤≠立即熄火。但只做强的，弱了就走，边打边撤。

## 市场情绪评级 — 晴雨表体系
**来源**: 文章#21, 文章#17

### 情绪五级系统

| 等级 | 状态 | 操作 |
|------|------|------|
| ☀️ 阳光明媚 | 放心干，短线可重仓 | 积极做多 |
| ⛅ 晴转多云 | 适当减仓止盈，短线注意 | 谨慎乐观 |
| 🌧️ 小雨 | 暂停板块赛马，短线最难做的两周结束 | 观望防守 |
| 🌧️🌧️ 中雨 | 降低仓位，等待恢复信号 | 减仓 |
| 🌧️🌧️🌧️ 大雨 | 空仓或轻仓，等待明确转暖 | 空仓 |

### 恢复信号（小雨→多云）
- 强反弹到飞行员不敢起飞
- 火车头强（可换梯队不换板块）
- 继续放量

### 关键规律
- 市场情绪演化很少直线推进，类似天气：多云转小雨后可能再次多云
- **"秋老虎"效应**：高温不会一场大雨就浇灭 — 强势行情不会一次调整就结束

## 科技分段操作

> 科技有前排、后排、扩散、补涨，每只股票所处的阶段都有差异。有的遇到双顶回落，有的还在反弹做双顶，有的继续走趋势新高。核心就一点：只做强的，弱了就走，边打边撤。

### 四阶段

```
前排（龙头）: 趋势新高，最强  → 可持有
后排（跟涨）: 反弹做双顶      → 边涨边减
扩散（补涨）: 刚启动         → 观察
弱股        : 双顶回落        → 立即清仓
```

**铁律**: 边打边撤——不恋战，不假设科技一直强。

### 火车头轮动规律 — 良性高低切换条件
**来源**: 文章#20, 文章#12, 文章#19, 文章#18

#### 三梯队模型

| 梯队 | 板块 | 角色 |
|------|------|------|
| 第一梯队（火车头） | 光通信/元件 | 持续新高→分歧走弱震荡→反弹 |
| 第二梯队 | 半导体/芯片 | 接住第一梯队资金接力新高 |
| 第三梯队 | 软件/计算机/应用 | 补涨 |

#### 良性切换 vs 不良切换

| 类型 | 方向 | 结果 |
|------|------|------|
| ✅ 良性切换 | 第二梯队反哺第一梯队→第一梯队王者归来→第三梯队加速补涨 | 行情延续 |
| ❌ 不良切换 | 第一梯队新高失败→第二梯队震荡→第三梯队补涨结束 | 行情见顶 |

#### 良性切换条件
1. 资金回流通信和元件（老火车头修复）
2. 出现新火车头接力

> **历史记录**: 过去一年A股从未成功实现一次良性的高低切无缝衔接。
> **解铃还须系铃人**：通信和元件不继续涨，短线情绪就不容易继续嗨。

#### 火车头调整规律
- 火车头板块调整2-3天后通常有反弹

## 飞行员信号（IF基差）

> 尾盘飞行员起飞迹象明显，IF基差扩大到了97。飞行员无退场迹象，尾盘再度增仓打压，基差飙升创近期新高。

### 量化规则

| IF基差 | 信号 | 仓位 |
|--------|------|------|
| > 80 | 大规模起飞+增仓 | ≤30% |
| 30-80 | 轻度起飞 | ≤50% |
| -20~30 | 中性 | 正常 |
| < -20 | 反向 | 可加仓 |

**数据源**: IF主力合约基差 = IF连续 - 沪深300现货

## 退潮节奏

> 下跌→反弹→再下跌。热门股双顶→飞行员大规模起飞。

### 三阶段

| 阶段 | 特征 | 操作 |
|------|------|------|
| 1 初次下跌 | 科技前排做头 | 减至50% |
| 2 反弹诱多 | 缩量反弹+金融掩护 | 不追 |
| 3 再次下跌 | 双顶确立+基差扩大 | 清仓 |

### 板块轮动退潮（新形态）
**来源**: 文章#81

退潮新特征：航天等热门板块退潮 → 带跌半导体和AI → 龙哥出手护盘

| 退潮特征 | 说明 |
|---------|------|
| "永动机资金"打游击 | 退潮后资金流向物流、地产、消费、建筑材料等低位冷门板块 |
| 资金回流规律 | 退潮后资金会回流逻辑硬的板块（半导体/AI/金属/化工），反复做 |
| 轮动行情追涨 | 胜率极低，宜低吸不宜追高 |
| 市场双驱动 | 龙哥（从降温→护盘）+ 市场先生（热点退潮→资金四散） |

## 宏观变量

> 10年期日债利率，依然处于预警区间。日债和美债可能影响全球金融市场流动性。

### 滞涨假设（2026.5.25新增）
**来源**: 文章 (2026.05.25)

鳄鱼派提出"滞涨或者发生不太好的事情"的宏观新假设。即使指数上涨（创业板涨超2%），假设依然成立，因为：
1. 交易拥挤度进一步提升（百亿成交29只中科技占27只）
2. 飞行员无退场迹象，尾盘再度增仓打压，基差飙升创近期新高
3. 10年期日债利率依然处于预警区间

> 核心判断：指数上涨≠假设被证伪。需同时观察拥挤度、基差、日债三个维度。

### 新增监控

| 指标 | 预警阈值 | 说明 |
|------|---------|------|
| 10年日债利率 | >1.5% | 影响全球carry trade |
| 10年美债利率 | >4.5% | 压制风险资产估值 |

## 高低切风险与资金路径（2026.5.25新增）
**来源**: 文章 (2026.05.25)

### 资金从科技出来的路径
```
科技退潮
  → 机构先去其他板块打底（逢低买入）
  → 底部买扎实
  → 短线大资金才会去点火，打造火车头
  → 新主线形成
```

> **不要指望市场无缝衔接**。科技退潮后，其他板块也难持续大涨成新主线。短线过早高低切，反而容易挨打，不如先观望。

### 高低切失败的历史规律
- 过去一年A股从未成功实现一次良性的高低切无缝衔接
- 解铃还须系铃人：通信和元件不继续涨，短线情绪就不容易继续嗨
- 正确做法：等资金从科技出来→观察机构打底方向→确认新火车头→再跟

### 情绪判断的融资余额法（2026.5.25新增）
**来源**: 文章 (2026.05.25)

判断科技情绪是否下降，不能只看股价走势，要结合融资余额：
- **情绪下降确认条件**：杠杆哥们持续减仓 + 融资余额连续两天减少
- 单日减少不够，必须连续两天才能下结论

```python
def sentiment_declining(margin_balance_changes: list[int]) -> bool:
    """融资余额连续两天减少 = 情绪下降"""
    return (len(margin_balance_changes) >= 2 
            and margin_balance_changes[-1] < 0 
            and margin_balance_changes[-2] < 0)
```

### 情绪温度计（短线客分层）
| 类型 | 行为 | 对应温度 |
|------|------|---------|
| 激进型 | 继续做，直到情绪到100°往下降再休息 | 90-100° |
| 稳健型 | 边打边撤，降低仓位，留底仓 | 90°附近 |
| 保守型 | 激流勇退，底仓不留，刀枪入库 | <90° |

## 声东击西

> 金融拉升时科技低走，新股民看到大金融大涨加仓冲进去。老股民识破，先出来观望。

### 识别

1. 金融突然拉升 + 科技低开
2. 火车头（光通信/元件）走弱
3. 上午冲高 → 下午科技带金融一起跌

**操作**: 火车头低开 → 立即减仓，不犹豫。

## 股指期货基差矩阵（2026-05-27增量补充）

### 四大基差分化判断
**来源**: article_10, article_14, article_40, article_50
- IC(中证500)/IM(中证1000)与IF(沪深300)的基差分化反映市场风格
- IC/IM贴水大于IF → 小票被做空，资金偏好大盘蓝筹
- IC/IM贴水缩小快于IF → 小票活跃，题材股行情
- 四大基差同步收敛 → 全面做多信号

### 股期联动验证
**来源**: article_2 (2026.5.25), article_23 (2026.1.23)
- 商品期货涨 + 对应A股板块涨 → 联动确认，趋势可信
- 商品期货涨 + A股板块不涨 → 背离，警惕假突破
- "看看商品期货就明白了，本周是一波标准的股期联动行情"

### 交割周效应
**来源**: article_34 (2026.4.3)
- 交割前2天: 波动加大，基差剧烈收敛/扩大
- 交割日当天: 盘中异动频繁，不宜开新仓
- 交割后首日: 基差重新定价，趋势确认
