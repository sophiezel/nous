# 邓晓峰（高毅资产）— 行业景气度轮动

> **浓缩金句：** "在鱼多的地方钓鱼。先找到景气度向上的行业，再从里面挑最好的公司。"

## 一、战绩概览

- 前博时基金基金经理，管理的博时主题行业基金7年年化约25%
- 2007年上证6000点时发行，到2014年离任时净值翻倍（同期上证腰斩）
- 现高毅资产首席投资官，管理规模数百亿
- A股最擅长"行业轮动+重仓持有"的公募转私募代表

## 二、核心理念：在鱼多的地方钓鱼

邓晓峰的框架是倒过来的——大多数人先选股再看行业，邓晓峰先选行业再选股：

```
Step 1: 行业景气度判断 → 哪些行业未来1-3年向上？
Step 2: 行业内选股      → 这个行业里谁最受益？
Step 3: 重仓持有        → 景气度拐点出现前不动
Step 4: 拐点退出        → 行业景气度见顶信号→清仓换下一个行业
```

> "我从来不研究5000只股票，我只研究50个行业，每个行业只看前3名。这样就只有150只股票。"

## 三、行业景气度五维判断

### 3.1 需求端（最重要）

```
✓ 下游需求增速 > 10%（量）
✓ 渗透率 < 50%（还有空间）
✓ 政策明确支持（新能源、半导体、军工...）
✓ 终端产品提价（价）
→ 四项满足至少两项
```

### 3.2 供给端

```
✓ 行业CR3 > 40%（格局好）
✓ 新增产能 < 需求增速（不会供过于求）
✓ 产能利用率 > 80%（满产）
→ 供给受限意味着利润弹性大
```

### 3.3 库存周期

```
被动去库存（库存低位+需求上升）→ 最佳入场时点 🟢
主动补库存（库存上升+需求上升）→ 持有等顶 🟡
被动补库存（库存高位+需求下降）→ 准备退出 🟠
主动去库存（库存下降+需求下降）→ 坚决回避 🔴
```

### 3.4 盈利趋势

```
ROE 趋势向上 → 景气度确认
毛利率 环比连续2个季度上升 → 定价权增强
经营现金流/净利润 > 1 → 利润质量高
```

### 3.5 估值位置

```
行业PE分位数 < 50% → 安全
行业PE分位数 > 80% → 警惕（可能已经price in）
但：高景气行业可以接受高PE——关键是景气度是否持续
```

## 四、行业内选股：找"最受益"的

景气行业找到后，邓晓峰在行业内选股的标准是"谁弹性最大"：

### 选股优先级：

```
1. 成本最低的（毛利率最高）         → 利润弹性最大
2. 份额最大的（营收最大或增长最快）   → 确定性最高
3. 产能最充足的（产能利用率最高）     → 能承接需求爆发
4. 技术最好的（研发投入最多或专利最多）→ 壁垒最深
```

**可量化：**
- 毛利率 > 行业平均 +5%（成本优势）
- 营收增速 > 行业平均（份额在扩大）
- 产能利用率 > 85%（产能充足）
- 研发费率 > 5%（技术壁垒）

### 不选的特征：
- 概念纯正但没业绩
- 行业老二老三（除非差异化极强）
- 重资产但产能利用率低
- 管理层在行业景气时热衷跨界

## 五、仓位与持有

### 5.1 集中持有

- 常态持仓 8-12 只
- 单票上限 15%，极度确信可到 20%
- 单行业上限 40%（邓晓峰比其他高毅基金经理更集中）
- 核心逻辑：景气行业+龙头公司→重仓拿住，不被波动洗出去

### 5.2 持有的纪律

```
持有期间不看日线，只看月线
只要行业景气度没拐头、公司基本面没恶化，就不卖
-20%的回撤在邓晓峰体系里不是卖出的理由，而是加仓的理由
```

> 这一点和鳄鱼派高度一致——逻辑不破就不动。

### 5.3 卖出的唯一理由：景气度拐点

```
退出信号（满足任意一条即减仓）：
1. 行业ROE连续2个季度下行
2. 库存周期进入"被动补库存"
3. 下游需求增速降至 < 5%
4. 政策转向（如补贴退坡、监管收紧）
5. 替代技术出现（如光伏被钙钛矿颠覆）
```

## 六、邓晓峰的行业轮动时钟

他有一个简化的时钟模型：

```
阶段1: 行业出清期 → 小厂倒闭、龙头份额提升 → 关注但不买
阶段2: 需求启动期 → 下游出现新需求 → 开始建仓（30%仓位）
阶段3: 供需共振期 → 需求爆发+供给跟不上 → 重仓（60-80%仓位）
阶段4: 景气高位期 → 业绩兑现、估值扩张 → 持有不加仓
阶段5: 拐点出现期 → 库存积压、需求放缓 → 逐步清仓
```

**当前A股/H股哪些行业在哪个阶段？**
这是系统可以自动判断的——用 akshare 行业数据 + 库存周期模型。

## 七、与鳄鱼派的契合/冲突点

| 维度 | 邓晓峰 | 鳄鱼派 | 契合/冲突 |
|------|--------|--------|----------|
| 选股框架 | 行业→龙头 | 信号→共振 | 🟡 邓更偏自上而下 |
| 仓位管理 | 重仓集中 | 重仓集中 | 🟢 高度契合 |
| 持有逻辑 | 景气度不倒不卖 | 趋势不破不卖 | 🟢 高度契合 |
| 行业分散 | 3-5个行业 | 不限 | 🟡 邓更集中 |
| 退出条件 | 景气度拐点 | 止损/止盈线 | 🟡 不同触发条件 |

**融合方案：** 在鳄鱼派的信号共振之外，加一层邓晓峰的"行业景气度"前置判断。信号共振的票如果所在行业处于景气下行期，降半仓。反之，景气上行期的信号共振，加倍信心。

## 八、可落地为系统规则的特征

### 规则1：行业景气度评分（0-100）
```python
def industry_prosperity_score(industry):
    score = 0
    # 需求端(40分)
    if demand_growth(industry) > 0.10: score += 20
    if penetration_rate(industry) < 0.50: score += 10
    if policy_support(industry): score += 10
    # 供给端(30分)
    if industry_cr3(industry) > 0.40: score += 15
    if capacity_utilization(industry) > 0.80: score += 15
    # 库存周期(20分)
    if inventory_cycle(industry) == "被动去库存": score += 20
    elif inventory_cycle(industry) == "主动补库存": score += 10
    # 盈利(10分)
    if roe_industry_trend(industry) == "up": score += 10
    return score
```

### 规则2：景气周期阶段判定
```python
def cycle_stage(industry):
    """返回 1-5，对应邓晓峰时钟的五个阶段"""
    # 基于库存+ROE+需求增速综合判断
    roe_trend = roe_qoq(industry)  # ROE环比
    demand = demand_growth(industry)
    inventory = inventory_level(industry)
    
    if roe_trend < 0 and demand < 0: return 1  # 出清期
    elif roe_trend > 0 and demand > 0.05 and inventory == "low": return 2  # 启动期
    elif roe_trend > 0 and demand > 0.10 and inventory == "rising": return 3  # 共振期
    elif roe_trend >= 0 and demand > 0.05 and inventory == "high": return 4  # 高位期
    else: return 5  # 拐点期
```

### 规则3：弹性选股（行业内的优选）
```python
def elasticity_rank(industry_symbols):
    """在景气行业内按弹性排序"""
    scored = []
    for s in industry_symbols:
        score = 0
        if gross_margin(s) > industry_avg_margin + 5: score += 3
        if revenue_growth(s) > industry_avg_growth: score += 3
        if capacity_utilization(s) > 0.85: score += 2
        if rd_ratio(s) > 0.05: score += 2
        scored.append((s, score))
    return sorted(scored, key=lambda x: -x[1])
```

## 九、不适合的场景

- 行业轮动失效期（所有行业一起跌的系统性熊市）
- 新兴行业没有历史数据（无法判断景气周期）
- 纯主题驱动（如AI概念——需求数据不可得，邓晓峰框架用不上）
- 短线交易（他的持仓周期是年）
