# 徐翔（前泽熙投资）— 涨停板战法

> **浓缩金句：** "量在价先，题材是魂。涨停板是市场情绪最极端的表达。"

> ⚠️ 徐翔因操纵证券市场罪被判刑。此处仅蒸馏其公开可查的交易方法论（量价关系、题材轮动），不涉及任何违法操作。

## 一、战绩概览

- 1993年3万元入市，到2015年据称个人资产超200亿
- 泽熙投资存续期间（2009-2015），5年平均年化远超100%
- A股短线交易史上最高收益率记录
- 2015年被捕，2017年判刑5年6个月

## 二、核心理念：量价+题材+速度

徐翔体系三个关键词：

### 2.1 量在价先

```
放量上涨 → 真金白银进场 → 可信 → 跟随
缩量上涨 → 没人跟风 → 可疑 → 不碰
放量滞涨 → 出货 → 危险 → 远离
```

**可量化规则：**
```python
def xuxiang_volume_signal(symbol):
    vol_today = volume(symbol)
    vol_avg_5 = avg_volume_5d(symbol)
    price_change = change_pct(symbol)
    
    # 放量上涨（最可靠的买入信号）
    if vol_today > vol_avg_5 * 2 and price_change > 0.05:
        return ("🟢 strong_buy", "放量突破")
    # 放量滞涨（出货信号）
    if vol_today > vol_avg_5 * 1.5 and -0.02 < price_change < 0.02:
        return ("🔴 distribution", "放量滞涨→出货")
    return ("neutral",)
```

### 2.2 题材是魂

徐翔最核心的洞察：A股短线不是炒业绩，是炒题材。

```
题材强度判断（徐翔体系）：
  国家级政策（国常会/发改委）→ 强题材 → 重仓参与
  部委级政策            → 中等题材 → 中等仓位
  地方/行业级           → 弱题材 → 轻仓或不碰
  纯概念/传闻            → 不碰
```

### 2.3 速度即风控

徐翔的止损极度严格：
```
买入后次日不涨停 → 减仓50%
买入后次日跌3%   → 全清
持仓不超过3天    → 到期无论盈亏都走
```

## 三、可量化规则

### 涨停板强度分类
```python
def limit_up_strength(symbol):
    """分析涨停板质量"""
    open_pct = (open_price - prev_close) / prev_close
    vol_first_hour = volume_first_hour(symbol)
    times_touched_board = count_board_touch(symbol)  # 开板次数
    
    if open_pct > 0.09 and times_touched_board == 0:
        return "一字板（最强，买不到）"
    elif times_touched_board == 0:
        return "封死涨停（强）"
    elif times_touched_board == 1 and vol_first_hour < avg_volume * 2:
        return "开板回封（中等）"
    else:
        return "烂板（弱，次日大概率低开）"
```

### 题材共振判断
```python
def theme_resonance(sector):
    """判断题材是否有持续性"""
    # 板块内涨停家数
    limit_up_count = count_limit_up_in_sector(sector)
    # 龙头封单量
    leader_seal_amount = get_leader_seal(sector)
    
    if limit_up_count >= 5 and leader_seal_amount > 10e8:
        return ("强题材", "可参与")
    elif limit_up_count >= 3:
        return ("中等题材", "轻仓试探")
    else:
        return ("弱题材", "不参与")
```

## 四、与鳄鱼派融合

| 维度 | 徐翔 | 鳄鱼派 |
|------|------|--------|
| 持仓期 | 1-3天 | 数月-数年 |
| 选股 | 题材+量价 | 信号共振 |
| 止损 | 次日跌3%全清 | ATR自适应 |
| 核心矛盾 | 超短线 vs 中长线 |

- 🔴 徐翔的超短线和鳄鱼派的中长线是根本上不同的时间维度
- 🟢 但量价关系+题材共振判断可以作为鳄鱼派"信号共振"的补充维度
- 系统注入：仅作为"量价异常检测"模块——当徐翔式量价信号触发时，标记为"短线资金关注"，但不直接触发交易。鳄鱼派的持仓周期决定了不能跟超短线信号。
