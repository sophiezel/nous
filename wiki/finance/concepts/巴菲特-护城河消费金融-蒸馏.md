# 巴菲特（伯克希尔）— 护城河+消费金融

> **浓缩金句：** "以合理的价格买入伟大的公司，比以便宜的价格买入平庸的公司要好得多。"

## 一、补什么缺口

**补：全球消费+金融龙头视角。** 已有林园（A股嘴巴股）+ 蒋锦志（全球估值），但缺少巴菲特式的"护城河深度评估"——不是看PE够不够低，而是看护城河够不够宽。

## 二、核心理念：护城河四问

巴菲特买任何公司之前先问四个问题：

```
1. 这家公司10年后还会存在吗？
   → 可口可乐、铁路、银行 → 会
   → AI概念股、元宇宙 → 不确定

2. 竞争对手能不能抢走它的客户？
   → 有转换成本（银行/软件）、品牌忠诚（茅台/苹果）→ 不能
   → 同质化产品（大宗商品/制造）→ 能

3. 它能不能提价而不丢客户？
   → 茅台提价、苹果提价 → 能（有定价权）
   → 航空公司提价 → 不能（客户立刻比价）

4. 管理层是把股东当合伙人还是当提款机？
   → 看薪酬、看资本配置、看分红
```

## 三、可量化规则

### 护城河评分
```python
def buffett_moat_score(symbol):
    score = 0
    # 品牌护城河(25分)
    if brand_strength(symbol) == "top": score += 25
    # 转换成本(25分)
    if switching_cost(symbol) == "high": score += 25
    # 网络效应(25分)
    if has_network_effect(symbol): score += 25
    # 成本优势(25分)
    if cost_advantage(symbol) == "structural": score += 25
    return score  # >70=宽护城河, 40-70=窄护城河, <40=无护城河
```

### 巴菲特式估值
```python
def buffett_value_check(symbol):
    """合理价格=未来10年自由现金流折现"""
    fcf = free_cashflow(symbol)
    fcf_growth = min(growth_rate_5y(symbol), 0.10)  # 保守，上限10%
    discount = 0.08  # 折现率8%
    
    # 简化：自由现金流收益率 > 无风险利率×2
    fcf_yield = fcf / market_cap(symbol)
    risk_free = get_risk_free_rate()  # 10年国债
    
    if fcf_yield > risk_free * 2:
        return ("undervalued", "值得买入")
    elif fcf_yield > risk_free:
        return ("fair", "合理")
    return ("overvalued", "等待回调")
```

## 四、系统注入

巴菲特作为**终极品质审查**——其他通道选出的票，必须过巴菲特护城河评分>40分，否则降半仓。

```
选股通道（林奇/邓晓峰/蒋锦志...）→ 巴菲特护城河审查 → 鳄鱼派信号共振 → 执行
                                   ↓ 不通过
                              降半仓或放弃
```
