# 趋势交易法 — 系统化趋势跟踪方法论（蒸馏版）

> 《趋势交易法》是鹿希武基于20年实战交易创立的系统化趋势跟踪方法，建立在数理统计和概率论基础之上。核心思想：**亏小赚大，追随趋势，用概率取胜。**

---

## 一、交易哲学基石

### 1. 交易观与方法论

- **交易观决定方法论**：有什么样的交易观，就会有什么样的交易策略。正确的交易观是走向成功的前提。（第一章）
- **交易的本质**：交易是由"盈利交易"和"亏损交易"共同组成的不可分割整体，不存在100%正确的交易。（第一章）
- **概率思维**：金融市场的方向判断属于随机性现象，上升和下降的概率各趋近50%。盈利的关键不在于提高准确率，而在于**提高盈亏比**（2:1）——让亏损的交易小，让盈利的交易奔跑。（第九章）
- **破除我执法执**：不自大、不自满，按规则出牌，前后一致。（第一章）
- **先有分析，后有方向**：分析前大脑必须处于空白状态，不能预先有方向性暗示，否则分析只是走过场。（第一章）

### 2. 盈亏平衡基础

- 理论上：盈亏比2:1时，只需**34%准确率**即可盈亏平衡。
- 实战中：实际只需约**35%准确率**即可盈亏平衡（表9-1、9-2）。
- 盈利交易中：仅20%达到盈亏比>2:1，50%为1:1，30%为1:4。（第九章）

## 二、趋势的定义、识别与确认体系

### 1. 趋势分类

趋势分为三种：（第二章第一节）

| 类型 | 结构 | 特征 |
|------|------|------|
| 上升趋势 | 主升浪（奇数）+ 调整浪（偶数） | 一浪高一浪 |
| 下降趋势 | 主跌浪（奇数）+ 调整浪（偶数） | 一浪低一浪 |
| 横向整理 | 无趋势 | 无明显方向，需与调整浪区分 |

### 2. "势"的含义

"势"指价格运行的节奏：
- 上升趋势：快升慢调 或 慢升快调
- 下降趋势：快跌慢调 或 慢跌快调
- 横向整理：窄幅震荡 或 宽幅震荡（第一章）

### 3. 趋势识别五大工具

#### (1) 波浪理论（第二章）
- **数浪方式**：同级别数浪（前后区间跨度一致）和不同级别数浪（所有满足参数的区间均计数）
- **主浪特性**：
  - 前后主浪周期比率：1:1、1:1.618、1:2
  - 前后主浪高度比率：1:1~1.236、1:1.618~2
  - 浪1高度与整个趋势高度比率：3.236倍或4.236倍
  - 浪5后反转概率：**85%**；浪3后反转概率：34%
- **调整浪类型**：简单调整浪、ABC调整浪（最常见）、三角形调整浪（含扩涨三角形）、12345调整浪（鹿希武独创，外汇市场占比23%）
- **调整浪特性**：前后调整浪周期1:1，高度1:1或1:0.828，角度相似

#### (2) 趋势线（第三章）
- **上升趋势线**：连接最低点（或相对低点）与最高点之前的某一调整浪低点，中间不穿越任何价位。
- **下降趋势线**：连接最高点（或相对高点）与最低点之前的某一调整浪高点，中间不穿越任何价位。
- **绘制原则**：
  1. 不能连接最高点之后的低点
  2. 绘制的趋势线不能穿越任何价位
  3. 需满足设定的交易区间跨度参数
  4. 有转向用趋势线和判断调整浪趋势线之分
- **准确率**：>70%

#### (3) 拐点线（第四章）
- **定义**：来自通道理论，是外延线的平行线，价格将与拐点线相交的位置称为拐点。
- **绘制原则**："要找下，先画上；要找上，先画下"
- **使用时机**：通常**5浪时启动拐点线转向操作**，3浪时重心在守住阻力/支撑
- **拐点线类型**：转向拐点线、主浪结束位置、调整浪结束位置、横向整理、扩涨趋势、追加头寸出场点
- **注意事项**：浪2调整幅度>浪1的78.6%时，绘制的拐点线不能连接浪1和浪3的低点

#### (4) 分界点A（第五章）
- **定义**：设定交易区间的最低点或最高点
- **特点**：转向准确率>80%，但转向较晚、盈利空间小
- **使用原则**：
  - 行情中期→选大的分界点A
  - 行情结束期→选小的分界点A
- **综合运用**：突破拐点线时距分界点A较近（如<20点），推迟转向以分界点A为准

#### (5) K线反转形态（第六章）
- **准确率排序**：
  - 启明星/黄昏星：**80%**（最重要、最可靠）
  - 阴抱阳/阳抱阴：53%
  - 十字星：35%
  - 锤子线：48%
  - 乌云/刺透：36%
- **应用原则**：先用趋势线/拐点线/分界点A确定买卖区域，再在区域内观察K线反转形态

### 4. 趋势确认流程

价格突破下降趋势线/拐点线/分界点A → 未来上升概率>70% → 假定为"100%"事件处理（用止损处理剩余概率）（第九章）

## 三、入场与出场规则

### 1. 入场规则

| 场景 | 入场信号 | 止损位 |
|------|----------|--------|
| 上升趋势确认 | 回调至拐点线/分界点A+启明星 | 启明星低点下方 |
| 下降趋势确认 | 反弹至拐点线/分界点A+黄昏星 | 黄昏星高点上方 |
| 突破入场 | 突破拐点线+K线转向确认 | 近期高低点外 |
| 调整浪结束 | 拐点区域形成启明星 | 调整浪低点下方 |

### 2. 出场规则

- **趋势反转出场**：价格突破趋势线/拐点线/分界点A
- **加仓部分出场**：出现3根连续阴线 或 突破5根临时拐点线
- **5浪后启动转向**（反转概率85%）
- **小趋势是交易方向，大趋势是未来方向**

### 3. 核心信号总结

> **买入三要素**：①上升趋势确认 ②价格回调至拐点区域 ③出现启明星
> **卖出三要素**：①下降趋势确认 ②价格反弹至拐点区域 ③出现黄昏星

## 四、加仓与减仓逻辑

### 1. 加仓原则（第八章）

- **金字塔加码**：每次加码的数量**比上次少**（如3手→2手→1手）
- **禁止倒金字塔加码**：禁止越加越大
- **加码时机**：
  - 趋势明确（ROC变化率确认趋势概率>盘整概率）
  - 趋势初期和中期，**不在末期加仓**
  - 调整浪结束位置出现启明星时
- **激进加码策略**：连续阳线收市在之前阳线最高点之上时，每根K线加码

### 2. 减仓/退出规则

- **加仓部分退出条件**：
  - 出现3根连续阴线
  - 价格突破绘制的小临时拐点线（5根拐点线）
- **初始头寸持有至趋势真正反转**
- **防御型退出**：先行退出，待价格回升（如启明星出现）再补回

### 3. 进攻型vs防守型

| 策略 | 适用场景 | 操作 |
|------|----------|------|
| 守株待兔 | 趋势不明显 | 保持头寸不变，等待信号 |
| 边攻边守 | 中等确定性 | 时而减仓，时而加仓 |
| 激进进攻 | 强趋势确认 | 不断增加头寸 |

## 五、假突破过滤机制

### 1. 拐点线与分界点A联合过滤

突破拐点线时分界点A距离较近（如<20点）→ 推迟转向，等突破分界点A后再转向。（第五章）

### 2. K线形态确认

不单独用单根K线做决策。三根以上K线判断反转点的准确率最高（启明星/黄昏星80%）。

### 3. 横向整理过滤

区间跨度大于设定参数 → 认定为横向整理 → **不启动趋势线/拐点线转向**，防止来回止损。（第二章）

### 4. 扩涨趋势特殊处理

- 扩涨三角形中，保持原趋势线不变，不启动拐点线转向
- 需熟练识别扩涨三角形的3浪结构、时间点选择等特征（第三章）

### 5. 浪型结构的概率预判

- 3浪 → 反转概率仅34%，重心守住支撑/阻力
- 5浪 → 反转概率85%，启动转向操作
- 趋势12345调整浪（23%占比）：调整浪中出现5浪结构，需客观面对

## 六、多时间框架协同

### 1. 交易类型的参数区别（第八章）

| 交易类型 | 持仓时间 | 交易周期 | 风险金比率 | 交易次数设定 |
|----------|----------|----------|------------|--------------|
| 头寸交易（Position） | 5天以上 | 1小时 | 50% | 5次 |
| 日交易（Day Trading） | 约6小时 | 5分钟/15分钟 | 30% | 10次 |
| 抢帽子（Scalper） | 极短 | 1分钟以下 | - | - |

### 2. 大小周期关系

- **大趋势是未来方向，小趋势是交易方向**
- 大周期确定趋势方向，小周期寻找精确入场点
- 小趋势反转时，先尝试性入场（小止损搏大波段）
- 不同时间框架所用工具相同，参数设定不同

## 七、资金管理（第八章）

### 核心公式

```
F = CI × R / n

F  = 每次交易允许亏损额度
CI = 资金总投入
R  = 风险金比率（日交易30%，头寸交易50%）
n  = 交易次数（日交易10次，头寸交易5次）
```

**实例**：$20,000账户，日交易 → $20,000×30%÷10 = $600/笔

### 核心原则

1. 每笔亏损额度上限固定，**不因行情变化而放松**
2. 趋势明确时加大资金，趋势不明显时减少
3. 止损不能随意移动（尤其不能远离）

## 八、反转形态（第七章）

| 形态 | 特征 | 反转概率 | 交易策略 |
|------|------|----------|----------|
| 箱型顶部反转 | 5次以上震荡，2或4破高后快速回箱体 | >80% | 激进交易 |
| 大5小5反转 | 大级别5浪+小级别5浪回调 | 高 | 78.6%区域卖出 |
| V形反转 | 加速上升后对称快速下跌 | 高 | 提前转向避免被动 |
| 扩涨三角形 | 一浪高过一浪，同时一浪低过一浪 | >90% | 确认方向后顺势 |

## 九、与利弗莫尔关键点法的异同

### 相似之处

1. **追随趋势**：两者都强调识别趋势、顺势而为，不做逆势交易
2. **突破入场**：利弗莫尔的价格突破关键点（前期高/低点）与趋势交易法突破分界点A/拐点线逻辑相通
3. **金字塔加仓**：利弗莫尔用金字塔加码检验判断正确性，趋势交易法同样采用
4. **止损纪律**：两者都强调明确的止损，截断亏损让利润奔跑
5. **不预测只跟随**：利弗莫尔说"市场总是对的"，趋势交易法认为任何预测准确率趋于50%

### 核心差异

| 维度 | 利弗莫尔关键点法 | 趋势交易法（鹿希武） |
|------|-----------------|-------------------|
| **理论基础** | 市场心理+经验直觉 | 概率论+数理统计 |
| **工具体系** | 关键点（价格突破） | 趋势线+拐点线+分界点A+K线+波浪理论多工具协同 |
| **入场精确度** | 较粗糙，依赖经验 | 多工具交叉验证，精确到K线反转形态 |
| **浪型视角** | 无波浪理论 | 内置独创波浪理论（含12345调整浪） |
| **出场逻辑** | 保本点移动+反转确认 | 分界点A/拐点线系统化转向，5浪后启动 |
| **反转形态** | 无系统分类 | 箱型/大5小5/V形/扩涨三角形等分类处理 |
| **时间框架** | 单一 | 多时间框架（头寸/日交易/抢帽子） |
| **量化程度** | 定性为主 | 大量统计数据和概率参数（如85%反转率） |

### 趋势交易法对利弗莫尔体系的改进

1. **去主观化**：将关键点转化为客观的分界点A和拐点线，减少人为判断
2. **增加过滤**：通过K线形态确认突破有效性，降低假突破概率
3. **系统化决策树**：明确每个场景的应对策略，前后规则一致
4. **概率计算**：用统计数据证明盈亏比决定胜负，而非预测准确率

## 十、对A股/港股的适用性

### 作者观点

- **股票市场走势相对简单**：鹿希武认为股票走势比外汇单纯，变化少，更容易把握。"任何市场，只要存在，就有它存在的道理。作为交易员，关心的应该是品种是否具有波动性。"
- **市场越不规范，机会越大**：作者用中国化学（601117）和民生银行（600016）等A股实例验证方法
- **警示**：A股投资者最大问题是**风险控制意识差，没有止损习惯**。行情明显破位、趋势翻转时缺乏壮士断臂精神
- **实战验证**：
  - 2007年12月预测上证指数将跌至1768点（实际2008年10月跌至1664.93点）
  - 2008年12月预测上证底部完成于1664点，未来上升目标3470点

### 适配建议

| 适配要素 | 说明 |
|----------|------|
| T+1制度 | 日交易周期需调整为日线级别，抢帽子策略不适用 |
| 无做空机制（原书时代） | 仅适用上升趋势交易；如有融券/期货/期权可做空 |
| 政策驱动 | 需结合基本面，但趋势交易法本身不依赖基本面分析 |
| 波动特性 | A股趋势性强但调整剧烈，建议放大止损参数 |
| 港股适用 | 港股波动规律与外汇更接近，更易直接套用 |

## 附：核心工具决策链

```
读图 → 数浪（确定行情阶段） → 画趋势线/拐点线 → 找出分界点A
→ 判断方向（上升/下降/横向） → 确认入场区域 → 等待K线形态确认

```
