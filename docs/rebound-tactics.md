# 做T执行战术文档（正T/倒T）

> 前提参数来源：规格 2026-08-24-rebound-risk-gate-design.md（#9 止损止盈与大盘闸门）。
> 定位：反弹引擎的**执行层战术**，不改变主仓位的止损/止盈/时间止损纪律；做T 只作用于"底仓日内回转"，用于摊薄成本、降波动。
> 边界：不做分钟级模型（intraday_minute 历史浅、仅池内）；做T 依赖盘中判断，属人工执行范畴，引擎只提供纪律参数。

## 0. 适用前提（引擎闸门先行）

- 只有**已持有**反弹引擎信号的底仓才可做T（做T 不产生新标的，只回转已有仓位）。
- regime 闸门：#9 §5.1——**BEAR/VOLATILE 禁做正T**（追涨禁区）；SIDEWAYS 只做温和正T；BULL 可做正T。
- 情绪闸门：#9 §5.2——hot/warm 偏正T（低吸追涨）；cold/cool 偏倒T（高抛，情绪冰点反弹无力）。
- 极端警报（跌停家数>200 / 连板崩塌）触发当日：**禁止做T**，只执行组合级降仓/清仓。

## 1. 正T（先买后卖）— 摊低底仓成本

**适用**：hot/warm 情绪 + 非 BEAR/VOLATILE regime；底仓处于止损/止盈纪律内。

1. 底仓 = 反弹引擎买入的仓位（≤15% 单票，规格 #9 §4）。
2. 盘中低点（分时创新低不破、缩量企稳）买入 **1/3 ~ 1/2 底仓量** 的新仓。
3. 当日冲高（分时新高、放量滞涨）卖出**同等数量的旧仓**（T+1 下当日买入的次日才能卖，故卖出的是昨日及更早的底仓）。
4. 当日了结原则：若低吸后未冲高，**尾盘（14:45 后）把当日新仓平掉**（不隔夜留做T仓），底仓不变。
5. 日内止损：新仓买入后跌破当日低点或买入价 −1% → 当日尾盘无条件平新仓。

**净效果**：底仓数量不变，成本下降（低吸高抛差价）；若判断错误（低吸后继续跌），新仓在尾盘平掉，损失限定在日内差价 + 1% 日内止损。

## 2. 倒T（先卖后买）— 降低持仓风险

**适用**：cold/cool 情绪 或 盘中急跌（分时放量下杀）；底仓浮盈但担心回吐。

1. 冲高（分时新高/放量滞涨）时卖出 **1/3 ~ 1/2 底仓**。
2. 当日回落企稳（缩量止跌、分时不创新低）买回同等数量。
3. 若卖出后未回落（卖飞）：**次日开盘竞价买回**（追回底仓，接受小差价损失，纪律优先于成本）。
4. 倒T 日内止损：买回动作以"当日或次日开盘"为限，不无限等待。

**净效果**：高位减仓兑现浮盈，低位接回，底仓不变；卖飞时用"次日竞价买回"保证底仓完整（不做T 的仓位纪律被破坏）。

## 3. 与主仓位纪律的衔接（#9 §1–§3）

| 纪律 | 做T 时的处理 |
|------|--------------|
| 止损（超跌族=破买入日最低价 / 反包族=破MA20 或 −5%） | **做T 不豁免主仓止损**；触发即清主仓，做T 仓同日了结 |
| 首目标止盈（+5%/+8% 出 1/2） | 到达首目标后停止做T（剩余仓位进入移动止盈，回撤 4% 走） |
| 时间止损（超跌 5 日 / 反包 3 日，<+2% 走） | 时间止损触发前 1 日停止做T，准备清仓 |
| 移动止盈（新高后回撤 4%） | 回撤期间**禁做正T**（趋势可能转弱），只可倒T 减仓 |

## 4. 仓位与频率约束

- 单日做T 量 ≤ 底仓的 1/2；同一标的单日做T 次数 ≤ 2 次（过频增加摩擦成本）。
- 做T 成本按单边 ≈0.3% 计入（佣金万三 + 印花税卖出 0.05% + 滑点）——**做T 差价 < 0.6% 不划算，放弃**。
- 单日做T 标的 ≤ 3 只（精力约束）。

## 5. 时间窗口

- 正T 低吸窗口：开盘 30 分钟（情绪充分释放后的回踩）或尾盘（14:00–14:45 的日内低点确认）。
- 倒T 高抛窗口：开盘冲高（9:45–10:15 常见情绪高点）或盘中放量急拉滞涨点。
- 尾盘 14:45 后：只做当日了结，不开新做T 仓。

## 6. 记录与复盘

- 每次做T 记入 recommendation_track 之外的做T日志（日期/标的/方向/买卖价/差价/成本），供 #11 回测与复盘校准做T 参数。
- 月度复盘：正T/倒T 胜率、单笔差价分布、做T 对总收益的贡献——若做T 整体拖累（扣费后负贡献），**暂停做T**（纪律优先）。
