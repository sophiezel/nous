# Rebound 引擎校准迭代报告（第一轮）— 结论：无稳健样本外边际

> 对应 ticket: 校准迭代第一轮（验收 FAIL → 调参重验）(#13)
> 日期: 2026-08-25 ｜ 纪律: 校准只用 2020–2023，验收只看 2024–2026（#6 规格）

## 1. 方法

- 参数扫描：25+ 变体 × 2 轮（min_gain / 时间止损天数 / 反包止损宽度 / 移动止盈 / 市场退出阈值 / 每日票数 / **score 门槛** / **限价单入场**），目标=校准段 Sharpe（#8 §6）。
- 修复实现 bug 3 处（买入日止损误触发、首目标出半缺失、partial 未接线）。
- 诊断：费用敏感性、入场时点（信号日收盘 vs 次日开盘）、限价单模型。

## 2. 校准段（2020–2023）关键轨迹

| 配置 | 笔数 | 胜率 | PF | 收益 | Sharpe | 回撤 |
|---|---|------|-----|------|--------|------|
| 初值（未校准） | 1018 | 53.5% | 0.84 | −43.2% | −0.62 | 54% |
| combo2（天数+1, 止损−8%） | 910 | 57.5% | 0.94 | −16.3% | −0.13 | 42% |

关键结构杠杆：**score 门槛**（降换手）与**限价单入场**（拒追高，次日开盘 ≤ 信号日收盘×1.05 才成交，不违反无后视镜）。费用 0.3%/边下，毛边际为正但换手率必须压到很低才能存活。

## 4. 结论（结构性，非参数问题）

1. **无稳健样本外边际**：亏损均匀分布在每个样本外子期（非股灾集中），任何闸门/参数无法修复。
2. **校准过拟合**：样本内 Sharpe +0.43 → 样本外 −1.33；调参后的配置比未校准更差 OOS。
3. **信号设计上限**：胜率 61% 下盈亏比结构性封顶 ~0.74（首目标出半+时间止损压住盈利，止损 −8% 放大亏损），PF≥1.5 不可达。
4. 分族提示：超跌族 OOS 胜率 64.1% vs 反包族 45.2%——均值回归端可能残存边际，但样本小（39 笔）不能定论。

## 5. 资产价值（不因结论失效）

- 事件驱动回测框架（`rebound_backtest.py`：PIT/费用/限价单/全退出规则）——可复用于任何信号设计。
- 验收脚本与报告管线（`run_acceptance_rebound.py`）——A1–A6/P1–P6 全自动。
- 诚实负结果：两信号族（游资语义移植）在次日开盘/限价入场 + 0.3% 费用下无边际。
