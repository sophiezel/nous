# 右侧交易算法蒸馏（设计草案）

> 目标：把「确认后再买」的右侧逻辑蒸馏成可验证、可分层、可接到 Nous 数据表的因子与 setup。
> 边界：本规格描述 **右侧 / 趋势确认**；现有 `rebound` 超跌族属 **左侧 / 均值回归**，两套不得混权重。
> 证据原则：只引用可指名来源；未独立复现的券商回测数字标为「二手引用，需自建 WF 复核」。

## 0. 总原则（资金安全）

> **宁可错过，不可做错。** 右侧引擎服务的是真金白银，精确率优先于召回率。
> 不确定 → 不输出；闸门失败 → 空仓；缺资金/质量数据 → 当作不合格而非中性。
> 未通过 OOS 验收门槛（胜率/盈亏比/双窗口）前，输出只可标「研究观察」，不可当交易指令。

## 0.1 左右侧分界（硬约定）

| | 左侧（Left） | 右侧（Right） |
|--|-------------|--------------|
| 语义 | 跌过头接飞刀 / 抄底 | 趋势已确认再跟 |
| 典型触发 | RSI 超卖、连跌转阳、布林下轨 | N 日新高突破、均线多头回踩收回、相对强度领先 |
| Nous 现有 | `rebound` oversold（已校准） | `short_term` 徐翔/赵老哥/作手新一；`trend` 金叉；**缺独立右侧引擎** |
| 失败模式 | 下跌中继、假企稳 | 假突破、震荡磨损、涨停追不到 |

**闸门建议**：同一标的同一日不可同时输出左侧+右侧信号；regime=BEAR/VOLATILE 时右侧仓位上限收紧或只允许「慢系统」。

## 1. 可验证模式族（Pattern Cards）

### P1. Donchian / 海龟通道突破（经典趋势跟随）

- **规则**：收盘突破过去 N 日最高价做多；退出用更短 M 日最低价；仓位按 ATR(N) 风险单位；可选「上一次同向突破盈利则跳过」过滤器（System 1）。
- **参数基线**：快系统 N=20/M=10；慢系统 N=55/M=20（Curtis Faith / Turtle 公开规则）。
- **证据**：规则完全公开、可机械复现；趋势跟随学术上有 Time-Series Momentum（Moskowitz, Ooi, Pedersen, *JFE* 2012）支撑「1–12 月自身收益延续」。
- **A 股适配**：T+1、涨跌停不可成交、一字板剔除；只做多；用次日开盘成交；过滤日均额与 ST。
- **Nous 数据**：`stock_daily` 即可；ATR 自算。
- **失败**：震荡市胜率常 <40%，靠少数大趋势赚钱；需长样本 WF。

### P2. 均线多头 + 回踩确认（A 股实务量化高频写法）

- **规则**：MA5>MA10>MA20>MA60（或 +MA120）；斜率向上；价格回踩 MA10（昨低破、今收收回）且未破坏更长均线；可选缩量回踩。
- **证据**：BigQuant 等平台有完整条件式实现；属实务共识，**非顶级期刊证据**——必须用 Nous 自建 OOS。
- **A 股适配**：次日开盘买；卖出可用 MA5 下穿 MA40/60；剔除 ST、上市不足 60 日。
- **Nous**：`stock_daily`；与现有 `trend_scores` 互补（金叉是事件，多头排列是状态）。

### P3. Dual Momentum / 绝对+相对动量

- **规则**：截面选相对最强（行业或个股 12–1 月动量）；再要求自身绝对动量 >0（或相对无风险利率/现金）。
- **证据**：截面动量 Jegadeesh–Titman；时间序列动量 *JFE* 2012；Dual Momentum（Antonacci SSRN）把两者组合，绝对动量主要用于降回撤。
- **A 股适配**：A 股动量有「反转+动量」混杂，建议用 **行业层做相对、个股层做突破确认**，避免裸追 1 月最强。
- **Nous**：行业收益需申万 PIT（`industry_pit` / t5 主源）；个股 `stock_daily`。

### P4. 板块相对强度 + 资金共振（RRG / 成交占比）

- **规则**：行业处于相对强度「领先」象限（RS-Ratio 与 RS-Momentum 双强）；叠加行业成交占比趋势向上、短期热度与价格同向；可选北向连续净流入。
- **证据**：2026 券商指数化配置系列有 RRG+扩散指标行业轮动回测（二手引用，需复核）；资金流系列强调「成交占比趋势 + 短热度 + 价格」三共振。
- **Nous**：`sector_fund_flow_daily`、行业指数日线、`hsgt_sector_daily`；`theme_auto_pools` 可作题材层但当前滞后严重（停在 2026-07-17）。

### P5. 产业链景气验证 → 技术右侧确认（中观→微观）

- **规则**：上游价格/中游库存利润/下游需求分项验证景气升温（开源证券「景气验证」框架思路）；个股再等 **P1 或 P2** 技术确认才开仓。
- **证据**：中观景气择时有策略研究传统；Nous 已有 `pvglass` 全链路样板与供应链位置因子规格（#20）。
- **Nous**：`stock_chain_segment`、供应链边、行业景气指标；**先做 1–2 条聚焦链（光伏玻璃/半导体）**，勿一次全市场。

### P6. 短线情绪右侧（龙头/反包）— 与投资级右侧隔离

- **规则**：徐翔高开、赵老哥二板、作手新一放量站上 MA20（已在 `short_term.py`）。
- **证据**：游资方法论编码，OOS 需严格；校准记录显示反包族曾关闭。
- **定位**：**交易级右侧**，不进「投资级右侧」主引擎；单独仓位与时间止损。

## 2. 多层因子表

### 2.1 宏观（Regime Gate，非个股打分主项）

| 因子 | 领先性 | 口径 | Nous 表/源 | 坑 |
|------|--------|------|------------|----|
| 流动性：M2/社融同比、LPR | 领先~滞后混 | 同比/环比 | 宏观表（meituan 已用 PMI/M2/LPR） | 发布时滞，必须 as_of |
| 增长：制造业 PMI、工业增加值 | 同步偏领先 | 荣枯线 50 | 同上 | 修订值 |
| 价格：CPI/PPI | 同步 | 同比 | 同上 | 与商品链交叉 |
| 风险偏好：VIX/美元/美债 | 同步 | z-score | `index_global_daily` | 外溢非线性 |
| 投资时钟阶段 | 滞后综合 | 增长×通胀×流动性 | 自建状态机 | 中国直接套美林易失效 |

**用法**：只做 **仓位乘数 / 可否开新右侧仓**，不做个股排序主分。

### 2.2 微观 / 公司质量（Filter）

| 因子 | 领先性 | 口径 | Nous | 坑 |
|------|--------|------|------|----|
| PE/PB 极端剔除 | 过滤 | PE>0 且非天文、PB 合理带 | `stock_fundamental` | 无完整 PIT 财报 → 回测弱 |
| 市值/流动性 | 过滤 | 总市值、20 日均额 | fundamental + daily | — |
| 盈利意外/增速 | 领先 | SUE、营收同比 | 缺稳健 PIT → Phase2 | 前视 |

### 2.3 技术面（核心确认）

| 因子 | 类型 | 口径 | 用途 |
|------|------|------|------|
| Donchian 突破 | 事件 | close > max(high, N) 且用前 N 根（不含当日） | P1 入场 |
| 均线堆叠 | 状态 | MA5>10>20>60>120 | P2 前提 |
| 回踩收回 | 事件 | 昨低<MA10 且今收>MA10 | P2 入场 |
| 量能确认 | 同步 | 量比≥1.2～1.5 或突破日放量 | 假突破过滤 |
| ATR / N | 风险 | Wilder ATR20 | 止损与仓位 |
| MACD 零轴上/金叉 | 确认 | 已有 `trend` | 加分非必需 |
| 距 20/60 日高点 | 状态 | dist_high | 临界突破 vs 已突破 |
| 未过度延伸 | 过滤 | close/MA20 ≤ 1.12～1.15 | 防追高 |

### 2.4 资金面

| 因子 | 领先性 | 口径 | Nous | 坑 |
|------|--------|------|------|----|
| 主力净流入 | 同步偏领先 | `main_net` 近 3/5 日累计 | `fund_flow_stock` | 历史短；`main_pct` 常空 |
| 龙虎榜净买 | 同步 | 近 5 日 net_amount | `lhb_daily` | reason 嘈杂 |
| 融资余额变化 | 同步 | 日环比 | `margin_daily` | 滞后一日常见 |
| 北向个股 | 弱 | 连续净买 | `hsgt_stock_daily` | 披露制度变化 |
| 北向行业 | 中 | 连续 3–5 日净买/市值 | `hsgt_sector_daily` | 需标准化 |

### 2.5 板块共振

| 因子 | 口径 | Nous |
|------|------|------|
| 行业相对收益 | 20/60 日超额 vs 基准 | 行业指数 + PIT 归属 |
| RRG 象限 | RS-Ratio / RS-Mom | 自建于行业指数 |
| 行业成交占比趋势 | 占比 MA 差 | `sector_fund_flow_daily` |
| 题材热度 | theme score / 涨停数 | `theme_auto_pools`（需先修好滞后） |
| 广度 | 行业内上涨家数占比 | 日线截面 |

### 2.6 行业 / 上下游传导

| 因子 | 口径 | Nous 现状 |
|------|------|-----------|
| 链强度 | 链内成分 5 日收益中位数 | 规格 #20 已定义 |
| 节点位置 | 上/中/下游 ordinal | `stock_chain_segment` |
| 上游价格 | PPI/现货 | pvglass 样板；其他链待接 |
| 中游库存/利润 | 库存天数、毛利率 | 行业专项 |
| 下游需求 | 销量/开工 | 行业专项 |
| 景气验证分 | 需求−成本抑制+宏观验证 | 研究层，非日频交易 |

**右侧用法**：景气升温 = **观察池扩容**；个股仍需 P1/P2 技术确认（中观领先、微观确认）。

## 3. 推荐合成 Setup（可回测）

| ID | 名称 | 入场 | 门控 | 退出 | 优先级 |
|----|------|------|------|------|--------|
| **RS1** | 慢突破 | 55 日 Donchian 收盘突破 + 量比≥1.2 | 宏观非危机；流动性 OK；非 ST | 20 日低点或 2ATR | **Phase1** |
| **RS2** | 多头回踩 | 四线多头 + 回踩 MA10 收回 + 未破 MA20 | 行业 20 日相对收益>0 | MA5 死叉 MA40 或破 MA20 | **Phase1** |
| **RS3** | 板块共振突破 | 行业领先象限 + 个股 20 日突破 | 行业资金占比趋势>0 | 行业跌出领先或个股破 MA20 | Phase2（需主题/行业数据新鲜） |
| **RS4** | 景气链确认 | 聚焦链景气分上升 + RS2 | 链强度>0 | 景气回落或技术破位 | Phase2（先光伏/半导体） |
| **RS5** | 短线反包 | 现有 short_term 规则 | 情绪非 cold（与现 gate 对齐） | 时间止损 3–4 日 | 独立交易桶 |

评分建议（投资级 RS1–RS4）：

```
score = 0.35*TechConfirm + 0.25*SectorRS + 0.20*Capital + 0.10*QualityFilter + 0.10*ChainBonus
```

门控失败 → 直接剔除，不打分。

## 4. 与现有 Nous 的关系

| 组件 | 关系 |
|------|------|
| `rebound` oversold | **并列**左侧引擎，不合并权重 |
| `rebound` strong | 可映射到 RS5；校准曾关闭，右侧主引擎不要依赖它 |
| `screen` / 海鹰 F3 | 提供质量与动量粗筛，作 RS 观察池 |
| `trend` / `soul` MA200 | 作确认子分或长线过滤 |
| `meituan_reversal` | 单标的多层样板；宏观/利率层可抽象为 Regime Gate |
| `pvglass` + supply-chain spec | RS4 样板 |

## 5. 验证协议（最低标准）

- 校准窗 / OOS 窗拆分（建议对齐 rebound：2020–2023 / 2024–今）
- 防前视：突破用「昨日为止的 N 日高」；行业归属用 PIT
- A 股微观结构：T+1、涨跌停、费用滑点
- 报告：胜率、盈亏比、Sharpe、MaxDD、年化、交易次数、分年度、分市况（牛/震/熊）
- 拒绝标准：OOS Sharpe 显著劣于买入持有同池，或仅单一年贡献全部收益

## 6. 数据缺口（阻塞项）

1. `theme_auto_pools` / `theme_scores` 停更（~2026-07-17）→ 阻塞 RS3 题材层
2. `stock_fundamental` 缺稳健 PIT → 质量过滤仅当日可用
3. 供应链边覆盖有限 → RS4 仅聚焦链
4. 行业指数日线若不全 → RRG 需先补齐

## 7. 开放决策（待你确认）

见对话中的选项：先落地 Phase1（RS1+RS2）还是先修主题数据再上 RS3，或先做光伏链 RS4 样板。


## 8. 决议（2026-09-18）

选型问题超时未答 → **默认 Phase1**：落地 RS1 + RS2 + 指数绝对动量闸门。

- 模块：`src/nous/engine/screening/right_side.py`
- 配置：`config/right_side.yaml`
- CLI：`nous right-side [--date] [--top N] [--save]`
- 与 `rebound` 超跌族互斥；不自动开启 RS3/RS4（待主题/产业链数据）。


## 9. 高精度 Phase1 收紧（2026-09-18 晚）

用户明确：模式必须大概率正确，宁可不要也不能错。

| 项 | 旧（召回偏松） | 新（精确优先） |
|----|----------------|----------------|
| 指数闸门失败 | 降权仍输出 | **空列表，无交易信号** |
| 量比 RS1 | 1.2 | **1.8** |
| 延伸上限 | 1.15×MA20 | **1.10×MA20** |
| RS2 均线 | 4 根 | **5 根含 MA120** + 回踩缩量 + 深度限制 |
| 资金 | 加分 | **近5日主力净流入≥0，缺数据剔除** |
| 质量 | 弱过滤 | **负PE/PE>120/市值<50亿剔除** |
| 输出 | top30 | **最多 8，且 score≥72，confluence≥3** |
| 验收 | 未强制 | OOS 胜率≥52%、PF≥1.3、双窗口、最少40笔 |


## 10. 验收结果（2026-09-18）

- 命令：`nous right-side-accept --stride 1`
- **未通过**，`config/right_side_runtime.json` → `trade_enabled=false`
- 主因：`stock_daily` 仅 253 个交易日（<400）；校准窗几乎无满 160 根K的标的；OOS 仅 2 笔，WR=50%，PF=0.05
- 结论：在补齐更长日线并重新验收通过前，右侧输出只作研究观察，不开放交易态。
