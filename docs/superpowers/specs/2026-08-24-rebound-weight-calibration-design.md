# 短期反弹引擎 — 权重体系与校准流程（决议规格）

> 决议来源：ticket [权重体系与校准流程](https://github.com/sophiezel/nous/issues/8)，grilling 7 问全部按推荐通过（2026-08-24）。
> 事实依据：docs/research/t2-weight-distillation.md（业内权重区间与校准方法）、2026-08-24-rebound-factor-signal-design.md（因子清单 #7）、2026-08-24-rebound-backtest-acceptance-design.md（验收框架 #6）。

## 1. 权重体系形态（Q1）

- **分族两套权重**：超跌族（均值回归）与反包族（续攻）因子集完全不同（#7 §3/§4），各自独立权重。
- **共享因子**：资金（龙虎榜净买）、板块热度——两族都使用，但权重占比不同。
- 排序分 = 族内因子分 + 共享因子分，归一化到 100。

## 2. 线性分组成（Q2）

| 因子 | 定位 |
|------|------|
| 超跌 / 量能 / 资金 / 板块 | **线性排序分**（唯一参与加权打分的） |
| 情绪 | gate（#7 §5：cold/cool 放行抄底、hot/warm 放行追涨），**不进线性分** |
| 宏观 / regime | gate + 仓位乘数（#9），**不进线性分** |
| 财报 | 硬过滤（#7 §7），**不打分** |

## 3. 权重初值表（Q3）

### 3.1 超跌族（排序分 = 100）

| 类 | 权重 | 因子明细 |
|----|:----:|----------|
| 超跌 | **70** | K1_ret_5d（5日收益）30 + K6_price_position_20（20日区间位置）20 + K6_ma_gap_20（MA20乖离）15 + 企稳确认（不再创新低/下影线，加分项）5 |
| 量能（缩量衰竭） | **20** | 量/5日均量 <0.7 加分（抛压枯竭） |
| 资金（龙虎榜净买） | **7** | lhb_daily 近N日上榜且净买为正 |
| 板块热度 | **3** | 行业/概念截面热度（当日） |

> 超跌合计 70%，呼应 t2 证据链（AlphaReversal 归并后超跌≈50%、区间可至 40–50%，此处取偏保守的 70 含企稳确认加分）。

### 3.2 反包族（排序分 = 100）

| 类 | 权重 | 因子明细 |
|----|:----:|----------|
| 强势（连板/涨停梯队） | **40** | 连板数、近N日涨停次数 |
| 量能加速 | **30** | 量比、放量倍数 |
| 资金（龙虎榜净买） | **20** | 同上（续攻票最关键，权重最高档） |
| 板块热度 | **10** | 同上 |

### 3.3 用户倾向（Q3 确认）

- 未提出额外倾向 → 按上表初值执行。校准网格以初值为中心 ±10pp。

## 4. 校准方法（Q4）

**两阶段校准**（只在校准段 2020–2023 进行，样本外 2024–2026 仅验收，#6 已定）：

1. **因子层：ICIR 加权**（t2 §3.3 方法）：
   - `w_i = ICIR_i / Σ ICIR_i`，剔除 ICIR < 0.3 的因子（在校准段计算）；
   - 单因子 IC 必须 >0（负 IC 因子翻转方向或剔除，Q5）。
2. **族层：网格搜索**：族权重在初值 ±10pp 网格（步长 5pp），目标 = 校准段 Sharpe_winsorized 最大化（Q6）。
3. 贝叶斯优化（Optuna 类）列为 **V2 可选**，首版不用（可解释性优先）。

## 5. 权重范围约束（Q5）

| # | 约束 |
|---|------|
| C1 | 单因子族内权重 ≤ 40%（防单因子主导） |
| C2 | 族层权重相对初值偏移 ≤ ±15pp |
| C3 | 单因子 IC > 0（校准段；负 IC 翻转或剔除） |
| C4 | ICIR < 0.3 的因子剔除 |
| C5 | 权重漂移监控（复用 engine/ml/drift.py）：上线后监控因子 IC 漂移，漂移超阈值告警 |

## 6. 校准目标函数（Q6）

- **目标**：校准段 `Sharpe_winsorized` 最大化（+ C3 IC>0 约束）。
- **明确不当目标**：胜率/PF（它们是**验收口径**，样本外 A1–A3，直接优化验收指标本身是过拟合陷阱）。
- 参考输出：校准段 vs 样本外段的权重敏感性表（权重±5pp 的指标变化）。

## 7. 静态权重 + regime 仓位乘数（Q7）

- 首版：**静态权重**（§3 表），regime 只作仓位乘数/闸门（#9 定具体触发与档位）。
- 不复用现有 `adaptive_weights.py::REGIME_CONFIGS` 的 factor_weights 做动态切换——该配置是"趋势/价值"语境、非反弹语境；动态切换翻倍校准面、增加过拟合风险。
- REGIME_CONFIGS 的 `position_limit/max_single_weight/stop_loss_atr_mult` 结构可借鉴（#9 复用其形态）。

## 8. 落点（实现形态）

- 配置文件：`config/rebound_weights.yaml`——两族权重表（§3）+ 范围约束（§5）+ 校准日志（每次校准的窗口/目标/结果）。
- 引擎实现时读取；校准脚本输出权重版本号，回测/验收报告关联权重版本（可复现）。

## 9. 与其它 ticket 的接口

- **止损止盈与大盘闸门规则 (#9)**：regime 仓位乘数与止损参数可入同一 `config/rebound_weights.yaml`（或独立 `config/rebound_risk.yaml`）；REGIME_CONFIGS 的 position_limit 结构作参考。
- **回测验收 (#6)**：验收数字只看样本外；权重校准结果（权重版本）作为验收报告上下文。
- **引擎实现**：读取 §8 配置；权重版本记录进模型注册（model_registry 表可复用）。
