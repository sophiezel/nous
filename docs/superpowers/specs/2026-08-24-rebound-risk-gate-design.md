# 短期反弹引擎 — 止损止盈与大盘闸门规则（决议规格）

> 决议来源：ticket [止损止盈与大盘闸门规则](https://github.com/sophiezel/nous/issues/9)，grilling 6 问全部按推荐通过（2026-08-24）。
> 事实依据：2026-08-24-rebound-factor-signal-design.md（卖出触发形态 #7 §9）、config/default.yaml（现有 trading 参数）、engine/ml/market_regime.py（regime 分类）、engine/ml/adaptive_weights.py::REGIME_CONFIGS（仓位档位参考）。

## 1. 止损规则（Q1，分族）

| 信号族 | 止损规则 |
|--------|----------|
| 超跌族 | 破**买入日最低价**止损（方新侠语义移植）；若买入日最低价距买入价 <1%，放宽到 买入价−2×ATR（防极紧扫损） |
| 反包族 | **破 MA20 或 买入价−5%**，孰先触发即走 |

- ATR 用买入日 ATR(14)；基准 `atr_multiplier = 2.0`（config 现有值）。
- 止损锚点用**买入日**而非信号日（#7 §8 买入=次日开盘，避免信号日低点在买入价下方导致秒止损）。
- config 现有 `stop_loss_pct=0.08` 作反包族兜底（买入价−8%）参考，实际用 −5%（更严）。

## 2. 止盈规则（Q2，分批 + 移动）

| 信号族 | 首目标 | 到价动作 | 剩余仓位 |
|--------|--------|----------|----------|
| 超跌族 | **+5%**（方新侠原版） | 出 1/2 | 移动止盈：收盘创新高后回撤 **4%** 走 |
| 反包族 | **+8%**（续攻弹性大） | 出 1/2 | 同上 |

- 极端强势（连板/涨停延续）：移动止盈优先于首目标（不提前出 1/2）。

## 3. 时间止损（Q3）

| 信号族 | 持有 N 日 | 判定 | 动作 |
|--------|:---------:|------|------|
| 超跌族 | **5 日** | 累计收益 < **+2%** | 第 5 日收盘卖出（反弹不启动就走） |
| 反包族 | **3 日** | 累计收益 < **+2%** | 第 3 日收盘卖出（续攻票时间敏感） |

## 4. 仓位规则（Q4）

- 单票 ≤ **15%**（config 默认 30% 对反弹票偏宽；反弹票波动大）
- 单板块 ≤ **30%**（config 默认 50% 偏宽；反弹策略板块集中）
- 单日建仓 ≤ **5 只**
- 总仓位上限由 regime 闸门决定（§5.1）
- 参考：config `trading.max_position_pct=0.30 / max_sector_pct=0.50` 为本引擎覆盖值

## 5. 大盘环境闸门（Q5，三层）

### 5.1 第一层：regime 总仓位（市场状态 → 仓位上限）

- 分类器：复用 `market_regime.py::label_regime`（沪深300 的 20日涨 + 波动率 → BULL/BEAR/SIDEWAYS/VOLATILE，规则透明可解释，非黑箱）。
- 档位（参考 REGIME_CONFIGS 0.95/0.60/0.40/0.30，反弹语境下调）：

| regime | 判定（沪深300） | 总仓位上限 |
|--------|-----------------|:----------:|
| BULL | 20日涨 >10% 且波动率 <30% | **90%** |
| SIDEWAYS | abs(20日涨) <5% 且波动率 <20% | **60%** |
| VOLATILE | 波动率 >35% | **30%** |
| BEAR | 20日涨 <−10% | **20%** |

### 5.2 第二层：情绪 gate（族级开关）

- #7 §5 已定：cold/cool 放行超跌族（置信度+10）、hot/warm 放行反包族（置信度+5）。
- 叠加：**BEAR 或 VOLATILE regime 下，超跌族直接不做**（接飞刀禁区——熊市/高波动下"超跌"多是下跌中继）。
- 反包族在 cold/cool 下不做（情绪冰点无接力资金）。

### 5.3 第三层：组合级退出（极端信号）

- 触发条件（任一）：
  - 单日跌停家数 > 阈值（如 >200，市场级，sentiment_cache 可算）；
  - 连板高度崩塌（最高连板数从前一日 ≥5 骤降到 ≤2，limit_up_sentiment / sentiment_cache）；
- 动作：当日降仓 50%；连续 2 日触发 → 清仓。

## 6. 做T执行战术文档（Q6）

- 本票的止盈止损参数（§1–§3）作为**做T执行战术（正T/倒T）的前提**。
- 战术文档（正T：底仓+日内低吸高抛；倒T：先卖后买；与止盈止损的衔接）由**引擎实现阶段**产出（见 fog 毕业的 引擎实现与 CLI 落地 ticket）。
