# 短期反弹引擎 — 因子清单与买卖点规则（决议规格）

> 决议来源：ticket [因子清单与买卖点规则](https://github.com/sophiezel/nous/issues/7)，grilling 7 问全部按推荐通过（2026-08-24）。
> 事实依据：docs/research/t1-data-inventory.md（数据可得性矩阵）、t2-weight-distillation.md（权重蒸馏草案）、t3-short-term-audit.md（short_term.py 能力盘点）。

## 1. 引擎架构：两个信号族，共享风控层

| 信号族 | 物种 | 语义来源 | 触发逻辑 |
|--------|------|----------|----------|
| **超跌反弹族** | 均值回归（跌过头弹回来） | 方新侠规则（t3 §3 Rule5） | 硬触发进候选池 → 连续型超跌分排序 |
| **强势回调反包族** | 续攻（热门票回调后再攻） | 徐翔/赵老哥/作手新一（t3 §3） | 规则触发进候选池 → 连续型强势分排序 |

两族共享：硬过滤（§2）、情绪 gate（§5）、资金/板块截面因子（§6）、财报硬过滤（§7）、买入节点（§8）、卖出触发（§9）、风控层（#9）。

## 2. 硬过滤（Stage 1，不过滤不进池子）

| # | 规则 | 实现要点 |
|---|------|----------|
| F1 | ST/退市风险剔除 | `stock_basic.name LIKE '%ST%'`（t1: 库内无 ST 标志列，只能猜） |
| F2 | 停牌剔除 | 当日成交额=0 / 无当日 bar |
| F3 | 一字涨停不可成交剔除 | 推断涨停（涨幅≥对应板块涨停线×0.995，t3 `_is_limit_up` 语义）且 `open==high==low==close` 判一字板 |
| F4 | 流动性门槛 | 近5日日均成交额 ≥ 5000 万（可配置） |
| F5 | 上市天数 ≥ 60 | ⚠️ t1: `stock_basic` 无上市日期 → 用 `stock_daily_all` 该 symbol 最早 `trade_date` 近似（标注不精确）；或补上市日期数据 |
| F6 | 涨跌幅限制>10% 标的（创业板/科创/北交所） | 可选开关，**默认参与**，止损参数相应放宽（#9） |

## 3. 超跌反弹族（均值回归）

### 3.1 硬触发（进候选池）—— 方新侠语义移植（修复 t3 §9.1 数据窗口 bug 后）

| # | 条件 | 阈值 |
|---|------|------|
| T1 | 连跌天数 | 近 3 日日收益均 <0 |
| T2 | 超卖 | RSI(14) < 30 |
| T3 | 当日转阳 | close > open |
| T4 | 放量确认 | 量比（今量/近5日均量）> 1.5 |

### 3.2 连续型排序分（池内加权排序；权重 #8 校准）

| 因子 | 口径（t1 推荐，因子快照现成列） | 方向 |
|------|--------------------------------|------|
| 5日收益 | `K1_ret_5d`（未复权，窗口≤20日规避除权失真） | 越负越好 |
| 20日区间位置 | `K6_price_position_20` = (close−low20)/(high20−low20) | 越低越超跌 |
| MA20 乖离 | `K6_ma_gap_20` = (close−MA20)/MA20 | 负乖离越大越好 |
| 缩量衰竭 | 量/5日均量 < 0.7（抛压枯竭，加分项） | 越低越好 |
| 企稳确认 | 不再创新低（close > 前 N 日最低）或 下影线比例 > 阈值（加分项） | 是则加分 |

## 4. 强势回调反包族（续攻）

### 4.1 规则触发（任一命中进候选池）—— t3 §3 语义移植

| 规则 | 触发条件 | 阈值 |
|------|----------|------|
| 徐翔式 | 昨日涨停 + 今日高开 | 高开 >3%；成交额/总市值 > 0.5%（无封单数据，用成交额近似） |
| 赵老哥式 | 首板放量 + 二板缩量加速 + 二板涨停 | 首板量/前5日均量 ≥2.0；二板量/首板量 <0.8 |
| 作手新一式 | 今日大涨 + 放量 + 站上均线 | 涨幅 >5%；量比 >2.0；close > MA20 |

### 4.2 连续型排序分

| 因子 | 口径 | 方向 |
|------|------|------|
| 连板/涨停梯队 | 连板数、近 N 日涨停次数（`_get_consecutive_limit_up_count` 语义） | 高好 |
| 量能加速 | 量比、放量倍数 | 高好 |
| 资金净买 | 龙虎榜净买（§6） | 正好 |
| 板块热度 | 截面因子（§6） | 高好 |

## 5. 情绪 gate（市场级，两族共用；门控非加分）

- 数据源：`sentiment_cache`（2020+，t1 实测可用）——涨停家数、涨跌家数比、连板高度；`limit_up_sentiment` 的炸板率/连板高度（2026-04+，注意日期格式 `YYYYMMDD` 需统一）。
- 语义（t3 §4 炒股养家周期移植）：
  - **cold/cool**：放行**超跌反弹族**抄底（置信度 +10）
  - **hot/warm**：放行**追涨反包族**（置信度 +5）
- ⚠️ `zt_daily_pool`/`limit_up_premium`（涨停梯队/溢价）停更于 2026-05-22 → **回测只用 sentiment_cache**；恢复采集作为数据任务。

## 6. 资金/板块截面因子

| 因子 | 数据源（t1 实测） | 用法 |
|------|-------------------|------|
| 龙虎榜净买 | `lhb_daily` 2015+（真实、可回测） | 近 N 日上榜且净买为正 → 加分（`reason` 口径 100+ 种需归一化） |
| 主力净流入 | `fund_flow_stock` 仅 ~10 个月 | 近期增强因子；**回测缺失段自动降权**（用 `main_net`，勿用 96% 空的 `main_pct`） |
| 北向个股 | 估算值（2024-08 后停披露，TOP50×K 推算） | 仅弱代理，不进核心分 |
| 板块热度 | `stock_industry_multilevel` + `stock_concept_map` 当前快照（**无 point-in-time**） | 仅当日截面因子；回测标记弱化/剔除（前视风险） |

## 7. 财报硬过滤（不进打分）

- `stock_fundamental` 仅当前滚动快照（roe 89% 空、dividend_yield 93% 空，t1 实测）→ 只做当日过滤：PE/PB 极端值剔除、明显亏损剔除。
- 不做历史因子（无 point-in-time 历史财报，做历史回测有前视偏差）。

## 8. 买入节点（择时）

- 信号日**收盘后**计算（只用当日收盘前可得数据，防后视镜）。
- 默认：**次日开盘买入**（T+1 干净、零前视；t2 建议 AlphaReversal 同款）。
- 分批建仓：可配置（默认关）；盘中人工执行可参考"企稳确认"细节（§3.2 加分项）微调。

## 9. 卖出触发逻辑（形态；参数值 #9 校准）

| 类型 | 触发逻辑 |
|------|----------|
| 目标止盈 | 首目标收益（区间待 #9 定）+ 移动止盈（创新高后回撤 X%） |
| 破位止损 | 超跌族：破**信号日最低价**（方新侠语义）；反包族：破 MA20 或买入价 −5% |
| 时间止损 | 持有 N 日收益 < 阈值即走（N 待 #9） |
| 组合级退出 | 市场情绪退潮（炸板率升高/连板高度回落，§5 指标反向）→ 降仓/清仓 |

## 10. 实现时须处理的数据缺口（t1 §6 摘要）

1. 上市日期缺失 → `stock_daily_all` 最早 trade_date 近似（F5）。
2. 全库未复权 → 所有因子窗口 ≤20 日；长窗口因子（60d）禁止用于超跌分。
3. 涨停/一字板无标志列 → 按板块涨跌幅限制推断（F3）。
4. 行业/概念映射无 point-in-time → 板块因子仅当日截面（§6）。
5. 北向个股为估算值 → 不作核心资金因子（§6）。
6. 涨停梯队/溢价表停更 2026-05-22 → 回测只用 sentiment_cache（§5）。
7. `margin_daily`/`margin_short_daily` 有重复行/空行 → 按日去重聚合后才可用（全市场级，仅作情绪代理）。
