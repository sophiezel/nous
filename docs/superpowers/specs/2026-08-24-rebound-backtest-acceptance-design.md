# 短期反弹引擎 — 回测验收纪律与验收脚本设计（决议规格）

> 决议来源：ticket [回测验收纪律与验收脚本设计](https://github.com/sophiezel/nous/issues/6)，grilling 9 问全部按推荐通过（2026-08-24）。
> 事实依据：docs/research/t1-data-inventory.md（数据坑清单）、2026-08-24-rebound-factor-signal-design.md（成交假设 §8）、现有回测引擎能力盘点（engine/backtest/）。

## 0. 现有引擎可复用基础（盘点结论）

| 能力 | 位置 | 复用方式 |
|------|------|----------|
| PurgedWalkForward / CPCV | `engine/backtest/walk_forward.py` / `cross_validator.py` | 滚动交叉验证直接复用 |
| PointInTimeDataHandler | `engine/backtest/data_handler.py` | 全部因子/行情按日截断，防前视 |
| T+1 / 涨跌停 / 停牌 / 成本 | `engine/backtest/a_share_constraints.py` | 直接复用 + 补充一字板约束（§5） |
| PIT 宇宙（幸存者偏差） | `engine/backtest/survivorship.py::get_tradeable_universe` | 直接复用 |
| 指标与 integrity_flags | `engine/backtest/metrics.py::calc_metrics` | 复用 TRUSTED 机制，扩展交易级指标（§1） |
| 基线策略 | `engine/backtest/strategies.py::STRATEGIES`（海鹰F3/龙脉TRL/鳄鱼派） | 直接跑基线 |

## 1. 验收指标口径（Q1）

| 指标 | 口径 |
|------|------|
| 胜率 | 单笔平仓交易胜率：扣费后净盈亏 >0 记赢；跌停卖不出顺延至实际成交日 |
| 期望 | 平均每笔净收益（%） |
| 盈亏比 PF | 总盈利 / 总亏损（按单笔） |
| 统计显著性 | 样本外平仓交易笔数 **≥100**；验收报告给出胜率的 95% 置信区间（正态近似或 Wilson） |
| 参考指标（不设硬门槛） | Sharpe、Sharpe_winsorized、Sortino、年化收益、换手率 |

> 交易级指标当前 `calc_metrics` 未覆盖（现有以净值曲线为主），验收脚本需在 trades_log 上新增统计。

## 2. 验收数字（硬门槛，Q2）

| # | 约束 | 阈值 |
|---|------|------|
| A1 | 单笔平仓胜率 | ≥ 55% |
| A2 | 盈亏比 PF | ≥ 1.5 |
| A3 | 期望 | > 0（扣费后） |
| A4 | 样本外最大回撤 | ≤ 20% |
| A5 | 样本外平仓交易笔数 | ≥ 100 |
| A6 | integrity_flags.TRUSTED | = true（无收益尖刺/空曲线/非法净值） |

- Sharpe/Sortino 仅作报告参考，不设硬门槛（短周期 alpha 年化 Sharpe 天然偏低，设门槛不诚实）。
- 全部为自动检查项：任一 FAIL 即验收不通过，不走人工豁免。

## 3. 回测窗口与样本切分（Q3）

- **主窗口**：2020-01-01 ~ 2026-08-21（t1 实测 2020 宇宙 4,010 只，相对完整）。
- **固定切分**：校准段 2020–2023（权重/参数网格）／样本外段 2024–2026（验收数字只看此段）。样本外自然覆盖 2024-02 小盘股灾、2024-09 政策行情、2025 震荡等极端样本。
- **双轨稳健性**：PurgedWalkForward 滚动验证（purge 标签 = 持仓期，短周期 1–20 日，purge 20 交易日）作为交叉验证补充，不作为验收主判据。
- 2018–2019 仅作扩展参考段（标注幸存者偏差较重），不计入验收。

## 4. 费用模型（Q4）

| 项 | 费率 |
|----|------|
| 佣金 | 0.03%（万三） |
| 印花税 | 卖出 0.05%（2023-08 后现行税率；买入 0） |
| 滑点/冲击 | 0.25%/边 |
| **单边合计** | **≈0.3%**；双边 ≈0.6% |

- 一字板/涨停附近**不设额外滑点惩罚**——因为按 §5 直接判不可成交（买不进就不存在成交滑点）。
- 停牌后复牌日按实际价格成交（不特殊惩罚）。

## 5. 不可成交与停牌（Q5）

- **复用**：涨停买不进（`limit_up_filter`，含四舍五入容差）、跌停卖不出（`limit_down_check`）、T+1（`t_plus_1_check`）、停牌（无价格 → last_known 持仓不动，禁止零收益卖出）。
- **新增（#7 规格 F3 延伸）**：
  - 信号日为一字板（open==high==low==close 且涨幅达涨停线）→ 候选不可买；
  - 次日开盘买入时开盘价触及涨停价（涨幅 ≥ 涨停线×0.995）→ **买入不可成交**，跳过（可配置为顺延一日，默认跳过）；
  - 卖出同理：跌停价卖不出 → 顺延至可卖日（若连跌停超 N 日按 last_known 估值标记）。

## 6. 幸存者偏差处理（Q6）

- 主窗口 2020+ 接受局限（退市股在历史分区中缺失，`get_tradeable_universe` 的 PIT 宇宙基于现有数据）。
- 验收报告**必须声明**：历史分区为当前存活股回填，退市股缺失导致的幸存者偏差方向 = 高估收益。
- 补退市股历史数据记为**可选数据任务**（可另开 ticket，不阻塞本引擎验收）。

## 7. 基线对比（Q7）

| 基线 | 来源 | 报告项 |
|------|------|--------|
| 海鹰F3 / 龙脉TRL | `strategies.py::STRATEGIES` 注册表 | 同窗口跑基线，对比胜率/收益/回撤 |
| 沪深300 / 中证500 / 中证1000 | `engine/backtest/benchmarks.py` | 超额收益、信息比 |
| short_term.py | 不入基线 | 死模块（t3），其规则语义已移植进 #7 信号族 |

- 验收报告含：相对各基线的超额收益、信息比、胜率差异。

## 8. 前视因子剔除（自动检查项，Q8）

| # | 检查 | 处理 |
|---|------|------|
| P1 | 因子快照 K7_*（基本面） | **剔除**（t1: 当前值合并到全历史，前视） |
| P2 | 板块因子 | 仅当日截面使用；回测段标记弱化/剔除（#7 已定，无 point-in-time） |
| P3 | 北向个股（估算值） | 不得作核心因子（#7 已定） |
| P4 | 全因子数据 | 经 PointInTimeDataHandler 按日截断，只用当日收盘前可得数据 |
| P5 | 因子窗口 | ≤20 日（全库未复权，长窗口失真，t1） |
| P6 | 成交时点 | 信号日收盘后计算 → 次日开盘成交（#7 §8，零前视） |

- 以上每项为验收脚本自动检查，FAIL 即验收不通过。

## 9. 验收脚本形态（Q9）

- 入口：`scripts/run_acceptance_rebound.py`（对齐 `scripts/run_acceptance_v2.py` 风格：可重复运行、退出码=验收结果、stdout 摘要）。
- 输出：`docs/acceptance/rebound_acceptance_YYYYMMDD.md` 验收报告，含：
  1. 约束检查清单（A1–A6、P1–P6，每项 PASS/FAIL + 实测值）
  2. 指标表（校准段 + 样本外段分开）
  3. 基线对比表（海鹰F3/龙脉TRL/三指数）
  4. 交易统计（笔数、胜率置信区间、盈亏分布）
  5. 局限声明（幸存者偏差、未复权、北向估算、板块 point-in-time）
- 复用引擎 `integrity_flags/TRUSTED` 机制；验收数字只看**样本外段**。

## 10. 与其它 ticket 的接口

- **权重体系与校准流程 (#8)**：权重网格/贝叶斯校准只在校准段（2020–2023）进行，验收数字只看样本外（2024–2026）；校准不得触碰样本外数据。
- **止损止盈与大盘闸门规则 (#9)**：参数同样在校准段内网格搜索，样本外验证。
- **引擎实现**：反弹引擎接入 `STRATEGIES` 注册表（t3 §11）或 signal_engine 式独立评估器；验收脚本按本规格驱动。
