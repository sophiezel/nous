# T5 申万历史行业分类（point-in-time 行业归属）数据源探源

> 状态：已实测（curl / akshare 1.18.63 / 直接下载解析 xls / 用 sqlite3 核对 nous 库），非印象流。
> 验证日期：2026-08-26。对应 issue #1「短期反弹选股模型 — 在 nous 落地 rebound 引擎」子任务：行业/周期位置因子的 PIT 数据源。
> 结论先行：**存在官方免费、结构化、日更的 PIT 行业归属主源**——申万宏源研究所 `StockClassifyUse_stock.xls`（每股每段行业的「计入日期」start_date，12,903 行 / 5,912 股 / 历史可回溯至 1990）。巨潮 `stock_industry_change_cninfo` 作为多标准交叉验证备源。东财板块/申万指数只有当前快照、无完整 PIT。聚宽/米筐有 PIT API 但需账号权限、本机无法无账号实测。**「年末快照近似 PIT」在正常年份可行（L1 错误率 <2%），但在分类改版年份（2011/2014/2021）必须用真实 PIT 数据，尤其 2014 年 L1 错误率高达 30%。**

## 1. 主源：申万宏源研究所 `StockClassifyUse_stock.xls`（✅ 推荐）

### 1.1 接口与可达性

- **URL**：`https://www.swsresearch.com/swindex/pdf/SwClass2021/StockClassifyUse_stock.xls`
- **akshare 封装**：`stock_industry_clf_hist_sw()`，源码见 akshare 1.18.63（函数名同名，URL 即上述地址）。
- **实测可达性**：
  - 裸 `curl`（默认 UA）→ **HTTP 508**（WAF 拦截）。
  - 带浏览器 UA + `Referer: https://www.swsresearch.com/` → **HTTP 200，1,164,288 字节，`application/vnd.ms-excel`**，连续 3 次成功。
  - 结论：可达，但**必须带浏览器 UA + Referer**，否则被 508/403 拦。
- **成本**：免费、无需 key、无需登录。
- **更新频率**：文件头 `Last Saved Time/Date: Tue Aug 25 07:55:19 2026`（实测），即**日更**（验证前一日 2026-08-25 仍有更新）。
- **稳定性**：swsresearch.com 官方域名（IP 202.122.119.203，Tengine），长期稳定；唯一风险是反爬策略（需正确 UA），akshare 已封装此头。

### 1.2 数据结构（实测解析）

文件为 OLE2 `.xls`（code page 936），`pd.read_excel`（xlrd 2.0.2）解析成功，**12,903 行 × 4 列**：

| 列名 | 语义 | 实测样例 |
|------|------|----------|
| `股票代码`（symbol） | 6 位 A 股代码 | `000001` |
| `计入日期`（start_date） | **该股进入该行业的生效日（PIT 关键字段）** | `1991-04-03` / `2014-02-21` / `2021-07-30` |
| `行业代码`（industry_code） | 申万 2021 版 6 位行业码 | `440101` / `480101` / `480301` |
| `更新日期`（update_time） | 申万最后更新该记录的时间 | `2015-10-27` / `2024-09-27` / `2025-12-15` |

akshare 封装将列重命名为 `symbol / start_date / industry_code / update_time`，并把 `start_date`/`update_time` 转成 date 类型（`stock_industry_clf_hist_sw` 源码）。

### 1.3 覆盖度（实测统计）

| 指标 | 实测值 |
|------|--------|
| 总行数 | 12,903 |
| distinct symbol | 5,912 |
| distinct industry_code（L3） | 553 |
| distinct L1（行业代码前 2 位） | 38（含 7 个已退市/改版旧码） |
| `start_date` 范围 | 1990-01-01 ~ 2026-08-21 |
| `update_time` 范围 | 2015-10-26 ~ 2026-08-21 |
| 每股市行业段数 | 均值 2.18，中位数 2，最大 10 |

**PIT 语义**：每股有多行，每行是该股在 `[start_date, 下一行 start_date)` 区间内的行业归属。任意交易日 T 的行业 = `start_date ≤ T` 的最新一条（`max(start_date) where start_date ≤ T`）。这就是 point-in-time 归属，可直接消除 t1 报告（`docs/research/t1-data-inventory.md` §3.7）指出的「`stock_industry_multilevel` 只有当前快照、`start_date` 全空」的前视污染。

### 1.4 关键数据质量注意点（实测发现，必须读）

1. **历史记录是 2015 年回填的**：`update_time` 最早集中在 2015-10-26/27（4,025 行），说明 2015 年之前的行业归属是申万 2015 年**回溯重建**的，`计入日期` 是「生效日」（调整公告的生效日），而非当时的「公告日」。对量化 PIT 而言这是可接受口径（业界通用），但严格意义上生效日可能略晚于公告日数天，存在极小的「公告前用新分类」风险。
2. **代码体系与 nous 现库不一致**：本文件用**申万 2021 版行业分类码**（如 `480301`），而 nous 现库 `stock_industry_multilevel.industry_code` 用**申万指数码 801xxx**（如 `801783` 股份制银行，`source='cninfo_sw'`，见 `sqlite3 ~/nous-data/screener.db`）。接入时需做「2021 分类码 → 名称 → 801 指数码」的映射，或干脆在因子层统一改用 2021 分类码（见 §4 代码对照）。
3. **`start_date` 年度分布剧烈不均**（改版年份集中重分类）：2011 年 523 条、2014 年 1,141 条、2021 年 3,048 条（其中 3,021 条集中在 2021-07-30 一天）。这是「年末快照近似」误差的根源（§5 详评）。

## 2. 巨潮资讯 cninfo（✅ 交叉验证备源 + 名称映射源）

### 2.1 `stock_industry_change_cninfo`（单股行业变更，p_stock2110）

- **可达性**：✅ 实测成功。需 cninfo.js 的 `getResCode1` 生成 `Accept-Enckey` 头（akshare 用 `py_mini_racer` 执行 JS challenge；`py_mini_racer` 是 akshare 的传递依赖、本机已装，nous 代码 `src/nous/data/collectors/fetchers/fund_flow.py:18` 的 `from py_mini_racer import MiniRacer` 已在使用同款技术栈生成同花顺 hexin-v）。
- **结构**（实测 `symbol='000001'`，5 行 × 11 列）：`证券代码 / 机构名称 / 分类标准 / 分类标准编码 / 行业编码 / 行业门类 / 行业次类 / 行业大类 / 行业中类 / 变更日期 / 新证券简称`。
- **覆盖多标准**：实测单股返回 5 条，横跨 `巨潮行业分类标准(008002)`、`中证行业分类标准(旧)(008019)`、**`申银万国行业分类标准(008003)`**、`中证行业分类标准(008014)`、`中国上市公司协会上市公司行业分类标准(008001)`。即**同一接口可交叉验证多个分类标准的行业变更**。
- **申万记录示例**（000001）：`行业编码=S480301`，`变更日期=2021-07-30`，`行业门类=银行 / 次类=股份制银行Ⅱ / 大类=股份制银行Ⅲ`。
- **⚠️ 缺陷（实测）**：
  1. **单股查询**：接口一次只返回一只股票（`scode` 参数），全市场 5,912 股需逐股遍历 → 维护成本中、易触发 cninfo 限流。
  2. **申万历史不完整**：000001 的申万记录只有 `2021-07-30` 一条，缺失主源 xls 中的 `1991-04-03`（440101）、`2014-02-21`（480101）两条。说明 cninfo 的申万变更记录**只覆盖 2021 版切换之后**，不能替代主源的历史深度。
- **用法建议**：作为主源的**交叉验证**（抽查某股某日的归属是否一致），或当主源临时不可用时做近端（2021+）兜底。

### 2.2 `stock_industry_category_cninfo`（申万分类树，p_public0002）

- **可达性**：✅ 实测成功。`symbol='申银万国行业分类标准'`（映射 `008003`）。
- **结构**（实测 512 行 × 8 列）：`类目编码 / 类目名称 / 终止日期 / 行业类型 / 行业类型编码 / 类目名称英文 / 父类编码 / 分级`。
- **层级**：`S`（根）→ `S11` 农林牧渔（L1，31 个）→ `S1101` 种植业（L2，134 个）→ `S110101` 种子（L3，346 个）。
- **关键字段 `终止日期`**：实测全为 `NaT`（当前快照接口不返回已停用码的终止日期），但**字段存在**，说明 cninfo 底层有行业码的 PIT 终止信息，仅当前接口未暴露。
- **用途**：**2021 分类码 → 名称的映射表**。`S` + 6 位 = 主源 xls 的 `行业代码`（如 xls `480301` ↔ cninfo `S480301` = 股份制银行Ⅲ）。31 个 L1、134 个 L2 名称**全部可映射**。

## 3. 东财行业板块（❌ 无 PIT，仅当前快照）

- **接口**：akshare `stock_board_industry_name_em`（板块列表）、`stock_board_industry_cons_em`（当前成分）、`stock_board_industry_hist_em`（板块 K 线，非成分历史）。
- **底层**：`https://<n>.push2.eastmoney.com/api/qt/clist/get`（板块列表/成分）、`push2his`（K 线）。
- **实测可达性**：
  - 成分接口 `fs=b:BK1027`（小金属）→ **HTTP 200**（27 只成分）。
  - 板块列表接口 `fs=m:90 t:2 f:!50` → 多次 `HTTP 000`（connection reset），东财 push2 对非浏览器/高频请求**限流明显**；`push2delay` 主机可达但返回内容与参数不符（未过滤 `t:2`）。nous 生产已在用 `push2delay/push2/82.push2` 三主机轮换（`src/nous/data/collectors/unified.py:59`，见 t4 报告），此处不再展开。
- **PIT 结论**：`cons_em` 只给**当前成分**，`hist_em` 是板块指数 K 线（`secid=90.BK1027`），**均无历史成分/分类日期字段**。不适用于 PIT 行业归属。
- **东财概念板块历史成分**：akshare 仅有 `stock_board_concept_name_em / cons_em / hist_em`，同样无历史成分。**不可行**。

## 4. 申万指数 API（🟡 行业收益可用，PIT 成分不完整）

- **接口**（swsresearch 后端，均 `verify=False` 直连可 200）：
  - `index_component_sw(symbol='801030')` → `https://www.swsresearch.com/institute-sw/api/index_publish/details/component_stocks/`
    - 实测返回 410 只基础化工成分，列：`序号/证券代码/证券名称/最新权重/计入日期`。
    - **`计入日期`（beginningdate）字段存在**，但实测大部分 = `2021-12-13`（申万指数 2021 年重构日），且**只有当前成分 + 最近一次计入日期，无退出日期、无历史已退成分** → 不构成完整 PIT。
  - `index_hist_sw(symbol='801030', period='day')` → `.../index_publish/trend/`
    - 实测返回 6,439 行，1999-12-30 ~ 2026-08-21，字段 `代码/日期/收盘/开盘/最高/最低/成交量/成交额`。**指数价格历史**，可用于行业收益/动量聚合，但无成分 PIT。
- **用途**：行业**收益/强弱/动量**因子（与 `stock_industry_multilevel` 当前快照 JOIN 聚合，或直接用 801 指数价），但不能单独提供行业归属 PIT。
- **官网 swsindex.com**：DNS 解析到 222.73.228.201（上海电信），但连接 **HTTP 000 不可达**（大陆 IP 限制或站点下线），不作为数据源。

## 6. 「用年末快照近似 PIT」的误差评估（实测，基于主源 12,903 行）

> 方法：对每年 Y，用「Y-1 年 12-31 的行业快照」作为 Y 年全年的近似；某股在 Y 年内某日被错误分类 = 该股在 (Y-1-12-31, T] 内发生行业变更。错误率 = 错误 stock-day ÷ 当年股票宇宙 × 242 交易日。分「代码级」（任何 6 位码变化，含改版重编码）与「L1 级」（一级行业真实变更，剔除仅改版重编码）两档。

### 6.1 行业变更事件年度分布（含改版重编码）

| 年份 | 变更事件数 | 说明 |
|------|-----------|------|
| 2010 | 56 | 正常年度调整 |
| **2011** | 523 | 申万 2011 版分类调整（集中在 2011-10-10、2011-01-10） |
| **2014** | 1,141 | 申万 2014 版分类调整（集中在 2014-02-21，899 条） |
| **2021** | 3,048 | 申万 2021 版大改版（3,021 条集中在 2021-07-30） |
| 其余年份 | 10 ~ 280 | 正常年度调整 |

### 6.2 年末快照近似错误率（stock-day 级）

| 年份 | L1 级真实变更数 | 股票宇宙 | **L1 级错误率** | 代码级错误率（含改版） |
|------|----------------|---------|----------------|----------------------|
| 2010 | 47 | 2,122 | 1.83% | 2.12% |
| 2011 | 151 | 2,399 | 3.12% | 8.11% |
| 2014 | 950 | 2,680 | **30.21%** | 36.40% |
| 2015 | 82 | 2,895 | 1.20% | 1.36% |
| 2016 | 9 | 3,159 | 0.19% | 0.21% |
| 2019 | 136 | 3,888 | 1.60% | 2.37% |
| 2020 | 32 | 4,292 | 0.27% | 0.28% |
| 2021 | 660 | 4,862 | 5.75% | 26.45% |
| 2022 | 168 | 5,276 | 1.41% | 2.32% |
| 2023 | 71 | 5,590 | 0.63% | 1.03% |
| 2024 | 84 | 5,693 | 0.65% | 1.06% |

### 6.3 结论

1. **正常年份（绝大多数）**：年末快照近似 PIT 的 L1 级错误率 **<2%**，行业/周期位置因子完全可用。
2. **三个分类改版年份是误差黑洞**：
   - **2014**：L1 错误率 **30.21%**（899 只股在 2014-02-21 一天改换一级行业）——年末快照在该年**不可用**。
   - **2021**：L1 错误率 5.75%、代码级 26.45%（3,021 只股在 2021-07-30 一天重分类）——**必须用真实 PIT**。
   - 2011：L1 错误率 3.12%（96 只在 2011-10-10 改换）。
3. **实操建议**：反弹引擎若回测区间覆盖 2014 或 2021（尤其 2021，正是现有因子快照回测起点 2015 之后的核心区间），**不要用年末快照近似**，直接导入 §1 主源的 PIT 段式归属；若回测仅覆盖 2016+（避开 2021 前半年），年末快照近似误差 <2%，可接受。
4. **改版年份是已知的**（2011 / 2014 / 2021，具体生效日 2011-10-10、2014-02-21、2021-07-30），可针对性处理：在这些年份前/后分别取快照，其余年份用年末快照。

nous 现库与主源 PIT 文件的行业码体系不同，接入必须处理：

| 体系 | 代码样例 | 名称 | 来源 |
|------|----------|------|------|
| **申万指数码（nous 现库）** | `801780` 银行(L1)、`801782` 国有大型银行Ⅱ(L2)、`801783` 股份制银行Ⅱ(L2) | `industry_tree` 表（`source='cninfo_sw'`，`sqlite3 ~/nous-data/screener.db`） | 申万指数体系 |
| **申万 2021 分类码（主源 xls）** | `480301` 股份制银行Ⅲ、`440101`、`710202` | §2.2 cninfo 分类树（`S`+6 位） | 申万 2021 版行业分类 |

- **映射方法**：xls `行业代码`（6 位）→ 加 `S` 前缀 → cninfo 分类树查名称（L1/L2/L3）→ 按名称对齐 nous 的 `industry_tree.industry_name`（或改用 2021 码作为因子层的行业主键）。
- **注意**：xls 的 553 个 L3 码中，有 **215 个无法映射到 cninfo 当前 346 个 L3 码**（已停用的旧 L3 码）；但 **31 个 L1、134 个 L2 名称全部可映射**。行业/周期位置因子建议**在 L1（一级）或 L2（二级）层面使用**，映射缺口基本不影响；仅当需要 L3（细分子行业）时才需补历史码表。

## 8. 推荐方案

### 主源（直接落地）

| 数据 | 主源 | 接口/文件 | 落地点 |
|------|------|-----------|--------|
| **申万 PIT 行业归属** | 申万研究所 xls | `https://www.swsresearch.com/swindex/pdf/SwClass2021/StockClassifyUse_stock.xls`（akshare `stock_industry_clf_hist_sw`） | 新 fetcher：下载 xls → 解析 → 落表（schema 见下） |
| 申万 2021 码 → 名称 | 巨潮分类树 | `stock_industry_category_cninfo(symbol='申银万国行业分类标准')` | 静态映射表（31 L1 / 134 L2 / 346 L3） |

### 建议落表 schema（供 PIT 查询）

```sql
CREATE TABLE stock_industry_sw_pit (
    symbol TEXT NOT NULL,          -- 6 位代码
    start_date TEXT NOT NULL,      -- 计入日期（生效日，PIT 下界）
    industry_code TEXT NOT NULL,   -- 申万 2021 版 6 位码
    update_time TEXT,              -- 申万最后更新该记录时间
    source TEXT DEFAULT 'swsresearch',
    PRIMARY KEY (symbol, industry_code, start_date)
);
-- 任意交易日 T 的行业归属：
-- SELECT * FROM stock_industry_sw_pit
-- WHERE symbol=? AND start_date <= T ORDER BY start_date DESC LIMIT 1;
```

### 备源（降级/交叉验证）

- 巨潮 `stock_industry_change_cninfo`：主源失效时的近端（2021+）兜底 + 多标准交叉验证（逐股、低频、需 JS challenge）。
- 申万指数 API `index_component_sw` + `index_hist_sw`：行业收益/动量因子（与 PIT 归属无关的行业价格数据）。

### 明确不采用

- **东财行业/概念板块历史成分**：无历史成分接口，仅当前快照。
- **swsindex.com 官网**：大陆 IP 限制，HTTP 000 不可达。
- **聚宽/米筐**：有 PIT API 但引入账号/付费依赖，在免费官方主源可用时不作为首选（可留作长期兜底）。

## 9. 数据质量 Caveat（实测发现，实现时必须处理）

1. **历史记录 2015 年回溯重建**：`update_time` 集中在 2015-10-26/27，`计入日期` 是「生效日」非「公告日」，严格 PIT 存在数天「公告前用新分类」风险（业界普遍接受，但需知悉）。
2. **必须带浏览器 UA + Referer**：swsresearch.com 对裸 UA 返回 508，裸 HEAD 返回 502；GET + 正确头才 200。
3. **代码体系不一致**：主源用 2021 分类码，nous 现库用 801 指数码，需映射（§7）；L3 层有 215 个停用码无法从 cninfo 当前树映射，建议因子用 L1/L2。
4. **改版年份重分类集中**：2011-10-10 / 2014-02-21 / 2021-07-30 三个生效日贡献了绝大多数行业变更，回测与近似方案必须显式处理这三个日期。
5. **cninfo 单股接口局限**：`stock_industry_change_cninfo` 一次一只股、申万历史只覆盖 2021+，不能替代主源历史深度。
6. **东财 push2 限流**：板块列表接口多次 connection reset，生产需主机轮换 + 重试（nous 已有）。
7. **本机 SSL 证书**：homebrew Python 3.14 缺 GeoTrust 2022 中间证书，`requests` 直连 swsresearch 报 `CERTIFICATE_VERIFY_FAILED`；生产环境用系统证书链（curl 可验证）即可，或显式 `verify=/etc/ssl/cert.pem`。
