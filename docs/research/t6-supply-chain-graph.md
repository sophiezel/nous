# T6 A股产业链/上下游关系图谱数据源探源 — 反弹引擎「上下游辐射」因子

> 状态：已实测（curl / akshare 1.18.63 / 直接下载解析 HTML/JSON / sqlite3 核对 nous 库 / GitHub API），非印象流。
> 验证日期：2026-08-26。对应 issue #1「短期反弹选股模型 — 在 nous 落地 rebound 引擎」子任务：产业链节点与边的机器可读数据源。
> 结论先行：**当前无单一官方免费、结构化、全市场、带「环节→环节上下游边」的产业链数据源。** 现实是三段拼图：(1) **概念板块**是「概念(节点)→股票(归属)」二部图，可作「产业链节点」近似，但**没有环节间的上下游边**（同花顺 375 概念实测、东财接口存在但本机被限流）；(2) **主营构成 `stock_zygc_em`** 是「股票→主营产品/行业」带历史深度的结构化数据（中芯国际实测回溯至 2017），可从「主营产品」聚类出产业链环节，但同样**无上下游边**；(3) **开源 `ciuyity-lgtm/brainmap-pandora`** 是唯一实测拿到**股票级上下游边**（565 股 / 1807 条 supplier/customer/competitor 有向边）的机器可读源，但覆盖率低（55% 行业未分类、162 孤立节点）、单快照无更新机制、版权灰区。**推荐：概念板块作节点 + 主营构成聚类作环节标签 + brainmap 边表作种子边，三层合成；付费 Wind/Choice/iFinD 产业链图谱是唯一全市场权威「边」源，留作远期。**

> 本机环境说明：`akshare 1.18.63`（`pyproject.toml:25` 声明 `akshare>=1.14,<2.0`）。**东财 push2 系列主机（`*.push2.eastmoney.com`）从本机被 connection reset 限流**（与 t5 报告 §3 一致），但 nous 生产已在用 `push2delay/push2/82.push2` 三主机轮换（`src/nous/data/collectors/unified.py:63`，t4 报告已确认生产可用）；同花顺 `q.10jqka.com.cn` / `data.10jqka.com.cn` 本机可直接访问。以下所有「可达性」均为实测结果。

## 1. 概念板块作「产业链节点」近似（可行性评估）

### 1.1 同花顺概念板块（✅ 实测）

- **接口**：`stock_board_concept_name_ths()` → `http://q.10jqka.com.cn/thshy/`，逐页抓取（本机直连成功）。
- **实测结果**（2026-08-26）：**375 个概念**，两列 `name / code`（`code` 为 6 位数字概念码，如 `锂电池概念=300733`、`存储芯片=307940`、`比亚迪概念=308972`）。
- **关键结论 —— 概念列表是「平的」，无层级、无环节间上下游边**。375 个概念混三类语义：
  1. **产业链环节类**（可作节点）：`锂电池概念`、`储能`、`充电桩`、`存储芯片`、`BC电池`、`光模块`（经 `stock_board_concept_summary_ths` 出现的 `铜缆高速连接`/`光纤概念`/`AI PC` 等）；
  2. **公司/事件类**（不可作环节）：`比亚迪概念`、`宁德时代概念`、`阿里巴巴概念`、`长安汽车概念`、`国家大基金持股`；
  3. **题材/地域/财务类**（不可作环节）：`长三角一体化`、`西部大开发`、`低空经济`、`参股券商`、`创投`、`2026中报预增`。
- **成分股接口缺失**：akshare 1.18.63 的 `stock_feature/stock_board_concept_ths.py` 仅含 `name/info/index/summary` 四个函数（实测 `dir(ak)` + 源码核对），**无 `stock_board_concept_cons_ths`**（t4 报告 §2.4 提及的该函数名在本版本不存在，需注意）。成分股需自行抓取详情页 `http://q.10jqka.com.cn/gn/detail/code/{code}/`（实测 HTTP 200，HTML 内嵌 6 位股票代码列表，含分页）。
- **`stock_board_concept_summary_ths`（实测）**：返回最近 50 个新设/更新的概念指数，字段 `日期/概念名称/驱动事件/龙头股/成分股数量`。**这是「概念→驱动事件」的现成数据**，可用于反弹引擎的事件触发，但同样无环节间边。
- **结论**：同花顺概念 = 节点池（375 个，但需过滤出「环节类」概念），**不含边**。

### 1.2 东财概念板块（🟡 接口存在，本机被限流）

- **接口**：`stock_board_concept_name_em`（板块列表，`79.push2`）、`stock_board_concept_cons_em`（成分，`29.push2`，`fs=b:BKxxxx`），akshare 源码已核对（`stock/stock_board_concept_em.py`）。
- **实测可达性**（2026-08-26）：`79.push2`/`push2`/`82.push2`/`17.push2`/`29.push2`/`push2his` 六个主机 **全部 connection reset（HTTP 000 / curl 56）**；仅 `push2delay.eastmoney.com` 响应 200，但**忽略 `fs=m:90 t:3` 过滤**，返回全市场 64,541 只证券（期货/期权混入），无法用于取概念列表。与 t5 §3 结论一致：**东财 push2 对本机 IP 限流，生产环境经 `unified.py:63` 主机轮换可用**。
- **结构**（据 akshare 源码）：概念列表返回 `排名/板块名称/板块代码(BKxxxx)/总市值/上涨家数/下跌家数/领涨股票`；成分返回 `代码/名称/最新价/涨跌幅/市盈率` 等。同样是**「概念→股票」二部图，无环节间边**。
- **结论**：与同花顺概念同构 —— 节点近似可用（生产已通），**不含边**。概念总数东财约 300-400（本机未能取到精确值，待生产环境确认）。

### 1.3 nous 现有概念覆盖（实测核对）

- `sqlite3 ~/nous-data/screener.db`：`stock_concept_map` 仅 **70 概念 / 4,454 股 / 6,614 行**（实测 `COUNT(DISTINCT concept_name/symbol)`）。
- 现有 70 概念样例（实测按股数排序）：`AI算力(341)`、`新能源车(340)`、`医药(330)`、`化工(255)`、`软件开发(250)`、`汽车零部件(240)`、`AI光模块(177)`、`华为产业链(174)`、`半导体(173)`、`算力租赁(168)`、`光伏(166)`、`AI应用(131)`…
- **结论**：现有 70 概念是**围绕 AI/新能源观察池手工/半自动圈定**的（大量 AI 前缀），**远小于**同花顺 375 / 东财 ~300-400 的全市场概念。**「概念板块作节点」的落地第一步是把概念层从 70 扩充到全市场 300+，再标注哪些是「环节类」节点。**

### 1.4 概念作节点的可行性评分

| 维度 | 结论 |
|------|------|
| 节点覆盖 | ✅ 够用（全市场 300+ 概念，含锂矿/电池/整车、AI算力/光模块等典型环节） |
| 节点质量 | 🟡 需清洗（375 概念中约 1/3 是公司/题材/地域类，非环节） |
| 「边」 | ❌ **完全没有环节→环节的上下游边**（只有概念→股票归属） |
| 结论 | **概念只能回答「哪些股票属于同一环节」，回答不了「环节 A 在环节 B 上游」**。上下游传导（锂矿→电池→整车）必须另找边。 |

## 2. 主营构成 `stock_zygc_em`（聚类可行性评估）

### 2.1 接口与可达性（✅ 实测）

- **接口**：`stock_zygc_em(symbol='SZ300750')`，底层东财 F10 `emweb.securities.eastmoney.com/PC_HSF10/BusinessAnalysis`。**本机直连成功（F10 不属 push2，未被限流）**。
- **实测结构**（宁德时代 `SZ300750`，177 行 × 11 列）：列 `股票代码/报告日期/分类类型/主营构成/主营收入/收入比例/主营成本/成本比例/主营利润/利润比例/毛利率`。
- **`分类类型` 三值**（实测 distinct）：`按行业分类 / 按产品分类 / 按地区分类`。
- **「按产品分类」自由文本样例**（实测）：宁德时代 = `动力电池系统 / 储能电池系统 / 电池材料及回收 / 电池矿产资源`；中芯国际 = `集成电路晶圆制造代工 / 其他`。
- **历史深度**（实测 distinct 报告日期）：中芯国际 **2017-12-31 起 17 期**（半年+年报，最新 2025-12-31）；宁德时代 2024-06-30 起 6 期。深度因股而异，龙头通常 5-10 年。

### 2.2 从「主营产品」聚类出产业链环节 —— 可行性

| 维度 | 结论 |
|------|------|
| 可得性 | ✅ 免费、结构化、逐股可查 |
| 批量 | 🟡 **仅逐股接口**（`symbol` 单参，无批量版），全市场 ~5,600 股需 5,600 次调用，需限速（F10 接口较稳，非 push2） |
| 聚类可行性 | 🟡 **产品名是自由文本**（`动力电池系统` vs `锂离子电池` vs `锂电池`），需词典归一化或 LLM 聚类；「按行业分类」一列相对规整（接近申万行业）但粒度粗（如宁德时代=`电气机械及器材制造业`） |
| 「边」 | ❌ **只有「股票→主营环节」归属，无环节间上下游边** |
| PIT | ✅ 有 `报告日期`，可做「某报告期该公司主营什么」的 point-in-time |
| 结论 | 主营构成是**「环节标签」的好来源**（比概念更精确到产品），**但同样不产出边**。适合作为「概念板块节点」的**交叉验证/细分**，不适合独立解决上下游传导。 |

## 4. 开源产业链数据（✅ 实测，重点）

### 4.1 `ciuyity-lgtm/brainmap-pandora`（✅ 唯一实测拿到股票级「边」）

- **来源**：GitHub（`https://github.com/ciuyity-lgtm/brainmap-pandora`），MIT 协议，更新于 2026-06-15。作者自述「把 A股产业链变成 3D 银河系——565 只股票、1807 条产业链关系」。
- **数据形态**：单文件 `P01-brainmap-pandora/brainmap_pandora_v5.html`（196,515 字节），第 41 行内嵌 `window.D = {"nodes":[...],"edges":[...]}`（实测正则抽取 + JSON 平衡解析成功）。
- **节点 schema（实测）**：`{"id":"688981","name":"中芯国际","symbolSize":45,"value":"负向","industry":"半导体"}` —— `id`=6 位股票代码、`name`=名称、`industry`=行业标签、`value`=信号（`正向/负向/中性/N/A`）。
- **边 schema（实测）**：`{"source":"601012","target":"688223","relation":"customer"}`。
- **关系类型精确计数（实测 1807 条）**：

  | relation | 条数 | 语义 |
  |----------|------|------|
  | `competitor` | 737 | 竞品 |
  | `supplier` | 643 | 供应商 |
  | `customer` | 385 | 客户 |
  | `upstream` | 25 | 上游 |
  | `downstream` | 10 | 下游 |
  | `downstream,competitor` | 3 | 组合 |
  | `upstream,competitor` / `competitor,upstream` / `upstream,customer` | 2/1/1 | 组合 |

- **方向语义（实测推导）**：`source --relation--> target` 表示 **「target 是 source 的 relation」**。验证：中芯国际(688981) 与北方华创(002371) 之间同时存在 `688981 --supplier--> 002371`（北方华创是中芯国际的供应商，✓ 设备商）和 `002371 --customer--> 688981`（中芯国际是北方华创的客户，✓ 晶圆厂买设备）—— 两条边自洽。又如 `002466 天齐锂业 --customer--> 300750 宁德时代`（宁德时代是天齐锂业的客户，✓ 锂矿→电池）。
- **覆盖度（实测统计）**：

  | 指标 | 实测值 |
  |------|--------|
  | 节点 | 565（占 A股 5600+ 的 ~10%） |
  | 边 | 1,807 |
  | 已分类行业节点 | 252 / 565（**44.6%**；其余 233 个「待分类」+ 80 个「待分析」= 55.4% 无行业标签） |
  | 孤立节点 | 162（**28.7% 的节点无边**） |
  | 连通分量 | 174（最大分量 349 节点，为半导体/电子/新能源链主团） |
  | 平均度 | 6.4 |
  | 度 top10 | 中芯国际(57)、北方华创(45)、宝钢股份(41)、中国神华(40)、沪硅产业(35)、京东方A(35)、华虹公司(33)、华特气体(31)、比亚迪(31)、中微公司(30) |
  | 行业分布 | 半导体(22)、光伏(18)、锂电池(14)、PCB(14)、半导体设备(10)、电力(10)、电子元器件(10)、工程机械(8)、CXO(7)、创新药(7)、人工智能(7)… + 白酒/调味品/银行/保险/中药等消费金融链 |

- **数据质量 Caveat（实测发现）**：
  1. **单快照、无日期、无版本**：HTML 只有一份定稿，无历史，更新于 2026-06-15 后再无提交。
  2. **版权灰区**：README 明示「脑图数据自有版权」但仓库 License 为 MIT —— 代码 MIT、**数据版权声明冲突**，商用需谨慎。
  3. **反向重复边**：同一关系从双方视角各记一条（`A --supplier--> B` 与 `B --customer--> A` 并存），导入需去重/归一。
  4. **噪音边**：实测存在可疑边（如 `北方华创 --competitor--> 华特气体`：设备商 vs 特气材料商，关系存疑），需人工抽检。
  5. **覆盖偏科技/新能源**：主团为半导体/电子/新能源/光伏，消费/金融链稀疏（白酒 6、银行 6、保险 5），且 28.7% 节点孤立。

- **结论**：这是**当前唯一可免费直接拿到的「股票级上下游有向边」**，可作反弹引擎「上下游辐射」因子的**种子边表**，但必须：清洗反向重复边、剔除孤立/噪音节点、承认覆盖仅 ~10% 且偏科技链、把版权作为合规风险记录。

### 4.2 `benstartnow/chain-analyzer`（✅ 板块级上下游，7 行业链）

- **来源**：GitHub（`https://github.com/benstartnow/chain-analyzer`），MIT，更新 2026-08-11。README 称「25+ industries」但**实测 `scripts/chain_data.py`（363 行）仅 7 条行业链**：`电气设备 / 有色金属 / 电子 / 汽车 / 医药生物 / 食品饮料 / 机械设备`。
- **数据形态（实测）**：`INDUSTRY_CHAINS` Python dict，每条链含 `upstream(6 项) / midstream(6 项) / downstream(4-6 项)`，每项 = `{name, desc, sector(板块指数代码), sector_name}`。
- **板块指数代码（实测）**：12 个 `xxxxxx.TI`（同花顺/申万板块指数码），如 `885343.TI`=稀土永磁、`861013.TI`=机械制造、`885431.TI`=新能源汽车、`886069.TI`=人形机器人、`885700.TI`=军工。
- **性质**：这是**「板块(环节)→板块(环节)」的上下游边**（如 电子链：硅片/光刻胶/电子气体/靶材/设备 → 芯片设计/晶圆制造/封测/PCB → 下游），**但节点是板块指数而非个股**，粒度粗（仅 7 条链、~110 个环节节点），且为手工静态数据。
- **结论**：可作为**「环节→环节」边的参考框架**（验证「锂电池上游=锂矿/正极/负极/电解液/隔膜」这类先验），但覆盖太窄、无个股映射，不能单独落地。

### 4.3 `zhaoboy9692/ai-supply-chain-radar`（✅ AI 链专项研报，日更）

- **来源**：GitHub，16 star，更新 2026-07-29，日更。README 称「11 大环节：上游设备/材料 → EDA/代工 → 芯片设计 → 存储/HBM → 封测 → 光通信/CPO → PCB/连接 → 服务器/网络 → 电力散热 → 云/软件」，覆盖「336+ 只 200亿市值以上大票」。
- **数据形态（实测）**：`data-board_a.html`（511KB）/`index.html`（1.28MB）为 HTML 研报，数据源 **LongPort OpenAPI + yfinance**，多市场（美股/A股/港股/日韩台）。
- **结论**：是 **AI 产业链的「环节→股票」清单 + 信号评分**，非通用边表，但**环节框架（11 环节）可直接复用为 AI 链节点命名**。可作 AI 链专项参考，非通用数据源。

### 4.4 `naghceuz/stock-industry-chain`（🟡 LLM 生成，无静态数据集）

- **来源**：GitHub，MIT。README 自述：**「产业链由 Claude 联网研究整理成 JSON」**，`scripts/build.py` 注入模板生成 HTML，**无静态产业链数据集**，`examples/changjiang-cunchu.json` 仅作 schema 参考。

## 7. 推荐方案（三层合成）

### 落地路线（按优先级）

| 层 | 数据 | 来源 | 落地点 | 作用 |
|----|------|------|--------|------|
| **L1 节点（环节）** | 概念板块全量（从 70 → 300+） | 同花顺 `stock_board_concept_name_ths`（本机可用）+ 东财 `cons_em`（生产可用） | 新 fetcher 落 `stock_concept_map` 扩展 + 环节标记 | 回答「哪些股票属同一环节」 |
| **L2 环节标签（产品级）** | 主营构成 `stock_zygc_em`（按产品/行业，带报告日期 PIT） | 东财 F10 | 新 fetcher：逐股抓取 → 产品名归一 → 落表 | 对 L1 概念做**产品级细分/交叉验证** |
| **L3 边（上下游）** | brainmap-pandora 1807 边（种子）+ 商业图谱（远期） | GitHub + Wind/Choice（远期） | 新 fetcher：下载 HTML → 抽 JSON → 清洗（去反向重复、剔孤立）→ 落边表 | 回答「环节 A 在 B 上游」，供上下游辐射因子 |

### 上下游辐射因子的最小可用口径（建议）

1. **用 L3 边表**（清洗后）：对候选超跌股 `s`，沿边找其上游/下游/竞品股，计算这些关联股近 N 日涨跌，作为「上下游辐射强度」因子（如：上游涨价利好 → 下游成本承压利空；下游放量利好 → 上游补涨）。
2. **用 L1 节点近似兜底**（无边时）：对候选股所在概念，用「同概念其他成分股近 N 日平均涨跌」作为「板块辐射」近似 —— 这是**现有 `concept_signals.py`（`src/nous/engine/signals/concept_signals.py:30`）已在做的概念动量**，只是把它从「主线判断」升级为「个股辐射」。

### 明确不采用

- **akshare 产业链接口**：不存在。
- **纯概念作「边」**：概念只有节点+归属，**物理上无环节间边**，不能伪装成上下游传导。
- **付费终端**：首期不引入账号/费用依赖（Wind/Choice/iFinD 留作 L3 边表的最终权威补全）。

## 8. 数据质量 Caveat（实测发现，实现时必须处理）

1. **东财 push2 本机限流**：`*.push2.eastmoney.com` 全 connection reset（与 t5 §3 一致）；`push2delay` 可达但**忽略 `fs` 过滤**（返回全市场 64,541 只）。生产经 `unified.py:63` 主机轮换可用，本机开发需走生产链路或改 host。
2. **akshare 1.18.63 无 THS 概念成分接口**：`stock_board_concept_cons_ths` 不存在（t4 §2.4 的函数名有误），成分需自行抓 `q.10jqka.com.cn/gn/detail/code/{code}/` HTML。
3. **概念列表语义混杂**：同花顺 375 概念中约 1/3 是公司/题材/地域/财务类，作「环节节点」必须先过滤标注，否则「上下游辐射」会被「比亚迪概念」这类节点污染。
4. **brainmap 边表**：单快照（2026-06-15）、55.4% 节点无行业标签、28.7% 孤立节点、存在反向重复边和可疑噪音边（如设备商 vs 材料商标 competitor）、README「数据自有版权」与 MIT 冲突 —— 只能作种子，需清洗 + 合规评估。
5. **主营构成是逐股接口**：全市场 ~5,600 次调用；产品名自由文本需归一；「按行业分类」粒度粗。
6. **现有 nous 概念层很窄**：`stock_concept_map` 仅 70 概念（AI/新能源观察池），远小于全市场 300+，扩概念层是 L1 落地的第一步。
7. **无「边」数据的历史/PIT**：所有开源边表都是当前快照，无历史（无法回测「过去某日 A 是 B 上游」）—— 上下游辐射因子若回测历史，只能用「当前边近似」，存在轻微前视（产业结构变化较慢，可接受，但需知悉）。
