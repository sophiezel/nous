## 1. 光动百科 pvmeng.com（装机）— 三条互补枚举路径

### 1.1 站内搜索页（拿最新几期，最省事）

## 5. 光伏玻璃 2.0mm 价格：免费历史归档**不可枚举**（逐个实测）

| 源 | 实测结果 | 判定 |
| --- | --- | --- |
| `list1.mysteel.com/zhishi/gfbljg.html` | **http=200**, 57,722 B；含最新 10 天日度文章（260901–260914）+ gjcl 镜像 1 条（260914） | 仅最近 ~10 天；**无翻页**（`_2.html`→404、`page/2/`→404、`-2.html`→404） |
| `list1.mysteel.com/zhishi/gfblmrjg.html` | **http=200**, 54,476 B；www 侧链接是 **2025-06/07 旧文**（250620–250702），gjcl 侧 260909 | 新旧混杂、**无翻页** → 不可回填 |
| `search.mysteel.com/article.html?keyword=光伏玻璃` | **http=200**, 40,182 B，文章链接 **0**（JS/壳页） | 不可枚举 |
| `so.mysteel.com/search?keyword=光伏玻璃` | **http=000（连接失败）** | 不可用 |
| `www.oilchem.net/search/?keyword=…` / `/glass/` / `price.oilchem.net/` | 404 / 404 / 301 | 不可用 |
| `www.sci99.com/price/`（卓创） | **http=404**（516 KB 页面但 0 文章链接） | 不可用 |
| `www.100ppi.com/sf/` 与 `…/sf/day-2026-09-15.html` | http=200 但仅 **660 B** 空壳 | 不可用 |
| `hq.smm.cn/photovoltaic/list/12856` | http=200, 300,430 B，但文章链接仅 **1**（列表 JS 渲染）+ 已知正文登录墙 | 不可枚举 |

**结论**：玻璃 2.0mm 价格**没有免费可枚举的历史归档**。

- 能做的：① 期货/股价历史（第 4 节）用于回测收益腿；② mysteel 两个 list 页只提供最近 ~10 天，够**增量**不够回填；③ 月度「结算价」可继续走人工/seed（现有 `glass_settlement_price`）。
- **2.0mm 历史价格序列只能从本期开始向前累积**——这也解释了为什么现有 `backtest` 里玻璃价格信号样本为 0。

## 6. 落地建议（按性价比排序）

1. **招标先回填**（1 次请求 → 12–13 个月）：`taxonomy/term/5334` 摘要正则批次写库
2. **产业链价格回填**（7 次请求 → 12–14 个月周度）：taxonomy 7 个 term 逐篇跑现成 `energytrend.extract()`
3. **装机回填**（~30 次请求 → 18–24 个月单月）：pvmeng 搜索页 + 分类页 `page/N/` + 月归档补漏；逐帖 `_PVMENG_YTD_RE` → 差分
4. **电池产量回填**（~24 次请求 → ≥18 个月）：stats `index_N.html` 逐页 + `_STATS_CELL_RE`
5. **玻璃 2.0mm 价格**：放弃历史回填，只做增量（并在 backtest 报告中显式标注该腿样本为 0）
6. 建议实现为独立入口 `nous pv backfill [--source ...] [--since YYYY-MM-DD] [--dry-run]`，**与 `fetch` 分离**（回填是幂等重放，现状是增量），并复用现有解析器，避免第二套正则

**工程注意**

- 全部源都是「列表页 → 逐篇正文」两段式：**列表页解析要按日期倒序 + 关键词过滤 + 逐个探测**（pvmeng 分类页锚文本召回不稳、DataBM 频道页 JSON-LD 只给 5 篇，都是同一种坑）
- 请求要限速（pvmeng/mysteel 为普通站点），建议 0.5–1s 间隔 + 失败重试 2 次
- 回填写入要带 `source=backfill`，避免与日常增量的 `source` 互相覆盖（现有 PK 为 `(indicator_id, obs_date, source)`）

## 8. 复现命令（逐条可跑）

```bash

# 1. 装机：搜索页（37 帖 / 7 条 NEA 月度帖）

  | grep -oE 'https://www\.pvmeng\.com/20[0-9]{2}/[0-9]{2}/[0-9]{2}/[0-9]+/' | sort -u | wc -l   # → 37

# 2. 装机：分类页翻页（每页 +30，10 页 310 帖）
curl -s -A "$UA" -o /dev/null -w '%{http_code}\n' \
  "https://www.pvmeng.com/category/%e6%96%b0%e8%83%bd%e6%ba%90%e4%bf%a1%e6%81%af/page/2/"            # → 200

# 3. 装机：月归档补漏（2025/09 命中「1-8月份」帖）
curl -s -A "$UA" "https://www.pvmeng.com/2025/09/" | grep -oE '[^>]*风光装机总量[^<]{0,60}'           # → 16.9624亿千瓦||…2025年1-8月份

# 4. 电池产量：统计局分页（index_15 → 2025年12月份）
curl -s -A "$UA" "https://www.stats.gov.cn/sj/zxfbhjd/index_15.html" \
  | grep -oE 'title=.[^"'"'"']*规模以上工业增加值[^"'"'"']*' | head -1                             # → 2025年12月份

# 5. 招标：1 次请求拿多月
curl -s -A "$UA" "https://www.energytrend.cn/taxonomy/term/5334/" \
  | grep -oE '[0-9]{4}年[0-9]{1,2}月，国内光伏组件招标[0-9.]+GW'                                     # → 2026年8月…7.72GW 等

# 6. 产业链价格：taxonomy 归档（硅料 22 篇 / 电池片 21 篇）

for u in "https://list1.mysteel.com/zhishi/gfbljg_2.html" "https://www.oilchem.net/glass/" \

# → 404 / 404 / 404
```
